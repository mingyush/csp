## 📁 目录结构

```text
csp/
├── CSP-J1初赛/      真题 19 · 模拟 4 · 备考 8
├── CSP-J2复赛/      真题索引 · 模拟 1 · 备考 4
├── CSP-S1初赛/      真题 11 · 备考 5
├── CSP-S2复赛/      冲刺班 89 · 模拟考 70 · 题解 17 · 备考 5 · 真题 4
├── CSP-JS通用/      赛制纪律 · 初赛答题卡 · 防爆零清单 · STL 容器 · 考前清单 · 时间表 · 急救卡
├── NOI/             官方大纲（2023 / 2025 修订版）· NOI Linux 2.0 装机指南
├── 参考资料/        Hello 算法（第三方教程）
└── docs/            项目治理与隐私边界
```

**统一分类规则**：历年认证试题及答案归入「真题」；机构卷、仿真卷归入「模拟」；知识讲解、训练计划、课程大纲归入「备考」。四组目录结构一致，学会一个就懂全部。

**通用层的判据**：只对某一组或某一轮成立的材料留在组内；换组别、换轮次仍然成立的（赛制、考场纪律、文件读写与提交、语言级工具）收进 `CSP-JS通用/`。组内文档遇到通用内容只写链接，不复制正文——这条规则同时保证了 J 与 S 的规则不会各说一套。

**CSP-S2复赛 的额外构成**（2026 年新增，也是目前最重的部分）：

| 子目录             | 内容                                                               |
| --------------- | ---------------------------------------------------------------- |
| `题解/`           | 2021—2025 五年 20 题题解：`分册/` 按年份拆成 5 份（另有总览索引），合订本单篇留存；均由 `_parts/*.md` + `_build.py` 生成，可复现 |
| `2026S复赛冲刺班YU/` | 4 节课件 PDF；押题卷 01—03 按真实考场目录组织（试卷 + 测试数据 + 题解）                    |
| `2026S复赛模拟XES/` | 模考 1／2 的**按分数档拆解标程**、题面 Markdown、题面转换工具                          |

## 🛠️ 环境与工具

- **编译器**：GCC 7.5+（与 NOI 评测环境一致）
- **IDE**：Dev-C++、Code::Blocks、VS Code 均可
- **Linux 环境**：[NOI Linux 2.0 装机及使用指南](NOI/NOI-Linux/NOI-Linux2.0装机及使用.md)（国内选手常用虚拟机熟悉）
- **在线题库**：[洛谷](https://www.luogu.com.cn/)（国内题号最全）、[Codeforces](https://codeforces.com/)、[AtCoder](https://atcoder.jp/)
- **官方信息**：[NOI 官网](https://www.noi.cn/)（大纲、通知、各省要求）、[CCF](https://www.ccf.org.cn/)

常见参考书：《算法竞赛入门经典》（刘汝佳）、《算法竞赛进阶指南》（李煜东）、《信息学奥赛一本通》（董永建）。
