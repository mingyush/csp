├── 参考资料/        Hello 算法 · 答题卡说明

**统一分类规则**：历年认证试题及答案归入「真题」；机构卷、仿真卷归入「模拟」；知识讲解、训练计划、课程大纲归入「备考」。四组目录结构一致，学会一个就懂全部。

**CSP-S2复赛 的额外构成**（2026 年新增，也是目前最重的部分）：

| 子目录 | 内容 |
| --- | --- |
| `题解/` | 《CSP-S复赛真题题解（2021-2025）》合订本，由 `_parts/*.md` + `_build.py` 生成，可复现 |
| `2026S复赛冲刺班YU/` | 4 节课件 PDF；押题卷 01—03 按真实考场目录组织（试卷 + 测试数据 + 题解） |
| `2026S复赛模拟XES/` | 模考 1／2 的**按分数档拆解标程**、题面 Markdown、题面转换工具 |

## 🧭 三种典型用法

**① 从零开始系统备考** → 读[学习路径](#-学习路径)，按 0-6 / 6-12 月推进。

**② 只想稳过初赛** → 先看[考点分析与命题趋势](CSP-S1初赛/备考/CSP-S1初赛历年真题考点分析与命题趋势.md)定位重点，再用同目录的「7 天冲刺日程 / 3 天突击 / 考前 2 小时速记」按剩余时间选材料，最后刷近五年真题。

**③ 复赛冲分** → 先读[知识点体系与考场技巧](CSP-S2复赛/备考/CSP-S复赛知识点体系与考场技巧.md)建立框架，再用[逐题题解](CSP-S2复赛/题解/README.md)按题型精做，最后用模拟卷检验。

> 复赛标程按「分数档 + 做法」命名（如 `配对数组（70 分，O(nm)+全相等特判）.cpp`）。做完一套题对答案时，重点看**自己停在哪一档、下一档加了什么**，比只看满分代码有用。

## 🛣️ 学习路径

### 🌱 打基础（0—6 个月）

| 阶段 | 重点 | 对应材料 |
| --- | --- | --- |
| 第 1—2 月 | C++ 语法、输入输出、简单题 | 任何入门题库 |
| 第 3—4 月 | 计算机基础、程序阅读与完善 | [CSP-J1初赛/真题](CSP-J1初赛/真题/) |
| 第 5—6 月 | 排序／搜索／贪心、STL | [STL 容器选择](CSP-J2复赛/备考/CSP复赛必备--STL序列式容器的使用和选择.md)、[J 复赛知识点梳理](CSP-J2复赛/备考/CSP-J复赛知识点梳理2025.md) |

### 🚀 提高（6—12 个月）

| 阶段 | 重点 | 对应材料 |
| --- | --- | --- |
| 第 7—8 月 | 树、图、并查集、线段树 | [S 复赛知识点体系](CSP-S2复赛/备考/CSP-S复赛知识点体系与考场技巧.md) |
| 第 9—10 月 | 动态规划、图论、数学 | [逐题题解](CSP-S2复赛/题解/README.md) 按算法分类索引 |
| 第 11—12 月 | 整卷模拟、查漏补缺 | [S 复赛真题](CSP-S2复赛/真题/) + [模拟考](CSP-S2复赛/2026S复赛模拟XES/README.md) |

### ⏰ 一年节奏

初赛通常在 9 月、复赛在 10 月。可按「1—3 月补基础 → 4—6 月专项算法 → 7—9 月真题与初赛冲刺 → 10—12 月复赛与总结」推进；每周留一天固定复盘错题。

## 📝 必做真题顺序

**CSP-J 初赛**：2025 → 2024 → 2023 → 2022 → 2021（由新到旧，题型越新越贴近当下）

**CSP-S 初赛**：2025（社区整理版，含干净试卷版）→ 2024（完善程序「次短路」质量高）→ 2023（数论／分治成分重）→ 2022（字符串匹配、基数排序）→ 2021（补充）

**CSP-S 复赛**：先通读《知识点体系与考场技巧》→ 再按《历年真题综合分析与答题技巧》分专题突破 → 最后按 2025 → 2019 限时整卷模拟，重点打牢图论、DP、高级数据结构。

**CSP-J 复赛**：先读知识点梳理 → 按年份由新到旧 → 重点练算法应用题 → 归纳常见题型解法。

## 🛠️ 环境与工具

- **编译器**：GCC 7.5+（与 NOI 评测环境一致）
- **IDE**：Dev-C++、Code::Blocks、VS Code 均可
- **Linux 环境**：[NOI Linux 2.0 装机及使用指南](NOI/NOI-Linux/NOI-Linux2.0装机及使用.md)；建议先用虚拟机熟悉
- **在线题库**：[洛谷](https://www.luogu.com.cn/)（国内题号最全）、[Codeforces](https://codeforces.com/)、[AtCoder](https://atcoder.jp/)
- **官方信息**：[NOI 官网](https://www.noi.cn/)（大纲、通知、各省要求）、[CCF](https://www.ccf.org.cn/)

推荐书目：《算法竞赛入门经典》（刘汝佳）、《算法竞赛进阶指南》（李煜东）、《信息学奥赛一本通》（董永建）。
