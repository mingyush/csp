## 归档规则

1. **何时归档**：某个轮次考完即归档，根目录只保留当轮主线材料（当前为 2026 复赛）。
2. **怎么迁**：整目录 `git mv`，不拆分、不改内部命名 —— 内部相对链接自动继续有效。
3. **要不要改链接**：只需改根 `README.md` 里的入口指向；归档目录内部文档互链无需改动。
4. **怎么复用**：下一年度备战时把目录整体移回根目录（同样 `git mv`），再改一次根 README 入口即可。
5. **不归档什么**：跨年度通用内容（如 `NOI/` 大纲、`参考资料/`）留在根目录。
