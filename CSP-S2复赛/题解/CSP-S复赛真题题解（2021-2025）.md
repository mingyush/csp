## 四、CSP-S 2025 复赛题解

> 来源：微信公众号文章《CSP-S 2025第二轮认证真题及详解》 https://mp.weixin.qq.com/s/oWowzGJnVeZiEkbnwKxMHw
> 比赛：CSP-S 2025 第二轮认证（复赛），2025-11-01。下文题解与标程逐字转写自原文题解/标程截图；4 个标程已在本机用 `g++-16 -O2 -std=c++14` 编译通过，并通过官方样例与 60—80 组随机对拍，逐题结论见每题末尾「验证」。

### T1 社团招新（club）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P14361 |
| 核心考点 | 贪心 |
| 难度 | 普及+/提高 |
| 一句话结论 | 先让每个人都选自己满意度最大的部门；若最热门部门人数超过 $\frac{n}{2}$，就把多出来的 $c_p-\frac{n}{2}$ 个人改派到各自的次大满意度部门，按"损失"最小者优先贪心。 |

**题目大意**：小 L 招收了 $n$ 个新成员，$n$ 为偶数，要把他们分到协会的三个部门。第 $i$ 个新成员对第 $j$ 个部门的满意度为 $a_{i,j}$（$0 \le a_{i,j} \le 2 \times 10^4$）；若把第 $i$ 个人分到部门 $d_i \in \{1,2,3\}$，则方案满意度为 $\sum_{i=1}^{n} a_{i,d_i}$。要求方案中不存在任何一个部门被分配多于 $\frac{n}{2}$ 个新成员，求满足要求的方案满意度的最大值。本题包含多组测试数据，$1 \le t \le 5$，$2 \le n \le 10^5$，且 $n$ 为偶数。

**题解**：

**20 分（$n \le 10$）**

直接用 dfs 暴力枚举每个人加入分配到哪一个社团中。在 dfs 的过程中维护当前已经得到总评分 $sum$，以及当前每个社团的人数 $c_1, c_2, c_3$。当找到一种分配方式后，判断 $\max\{c_1, c_2, c_3\}$ 是否不超过 $\frac{n}{2}$ 并用 $sum$ 更新答案即可，时间复杂度 $O(3^n)$。

**另外 35 分（$n \le 200$）**

不难发现上述 dfs 的过程中，存在大量重复的子问题，考虑用动态规划进行优化。设 $f[i][j][k]$ 表示当前分配了前 $i$ 人，且 $c_1 = j$，$c_2 = k$，$c_3 = i - j - k$ 时，能够得到最大评分总和。

枚举 $i, j, k$，然后分别考虑当前的第 $i$ 人分配到哪个社团，可以得到转移方程：

$$f[i][j][k] = \max\{f[i - 1][j - 1][k] + a_{i,1},\ f[i - 1][j][k - 1] + a_{i,2},\ f[i - 1][j][k] + a_{i,3}\}$$

求最终的答案时，枚举两个社团的人数 $j$，$k$，然后判断三个社团是否都不超过 $\frac{n}{2}$ 人，取满足这个条件的最大 $f[n][j][k]$ 即可，时间复杂度 $O(n^3)$。

**另外 5 分（特殊性质 A）**

此时 $a_{i,2} = a_{i,3} = 0$，相当于仅有一个社团，直接取最大的 $\frac{n}{2}$ 个 $a_{i,1}$ 相加即可。

**另外 10 分（特殊性质 B）**

此时 $a_{i,3} = 0$，相当于仅有两个社团。若不考虑"人数不超过 $\frac{n}{2}$"的限制，那么答案就是 $\max(a_{i,1}, a_{i,2})$ 之和，即每个人取最大的社团评分相加。在此基础上考虑限制，设 $c_1, c_2$ 为不考虑限制时两个社团的人数，那么：

- 若 $c_1 = c_2$，则此时两个社团人数都是 $\frac{n}{2}$，无需做出任何改变。
- 若 $c_1 > c_2$，则需要将第一个社团中的 $c_1 - \frac{n}{2}$ 个人分配到第二个，已知每个人从第一个社团转移到第二个社团后，产生的贡献是 $a_{i,2} - a_{i,1}$，那么取前 $c_1 - \frac{n}{2}$ 大的贡献相加即可。
- 若 $c_1 < c_2$，则处理方式与 $c_1 > c_2$ 时类似。

可以使用优先队列或者是 sort 排序来得到前几大的贡献，时间复杂度 $O(n \log n)$。

**另外 10 分（特殊性质 C）**

此时的 $a_{i,j}$ 是随机生成的，那么对于第 $j$（$j \in 1, 2, 3$）个社团而言，$a_{i,j}$ 是三个社团评分中最大的概率约 $\frac{1}{3}$。也就是说，如果我们直接对每个人取 $\max\{a_{i,j}\}$ 相加，那么最终每个社团的人数都约等于 $\frac{n}{3} \le \frac{n}{2}$，必然满足题目的人数限制。时间复杂度 $O(n)$。

**100 分：**

考虑在"特殊性质 B"的基础上进行优化，依旧是先将每个人最大的社团评分相加。设 $p$ 表示人数最多的社团编号。那么：

- 若 $c_p \le \frac{n}{2}$，则另外两个社团人数肯定也都 $\le \frac{n}{2}$，直接输出答案。
- 若 $c_p > \frac{n}{2}$，则此时我们需要从第 $p$ 个社团中选出 $c_p - \frac{n}{2}$ 个人移动到其他社团。根据贪心的思想，为了让答案减得更少，需要将这些人移动到他们原本次大评分的社团中。移动后，$c_p = \frac{n}{2}$ 且另外两个社团的人数总和 $= \frac{n}{2}$，那么也就是说三个社团的人数都是 $\le \frac{n}{2}$ 的，符合人数限制。

至此，我们便可以像之前一样，用优先队列或者是 sort 排序来得到前 $c_p - \frac{n}{2}$ 大的"次大减最大"的贡献，加到答案中即可，时间复杂度依然是 $O(n \log n)$。

值得一提的是，由于每个人只会选择前两大的社团，因此本题还可以做更多个社团的情况。

**易错点**（整理）：

- 题目要求"不存在一个部门被分配多于 $\frac{n}{2}$ 个新成员"，$n$ 为偶数，因此恰好等于 $\frac{n}{2}$ 是合法的。
- 贪心改动时只考虑把超额的 $c_p - \frac{n}{2}$ 个人从第 $p$ 个社团移出，并且只取"次大减最大"最大的那 $c_p - \frac{n}{2}$ 个（即损失最小的一批），不要漏算或多算。
- 多组数据，全局数组与统计量（$cnt, p, ans$）都要每组重新初始化；代码中 $cnt$ 用 `int cnt[4] = {}` 局部清零，注意不要写成全局。

**参考代码**（转写自原文标程截图，已本地编译验证）：

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long LL;
const int N = 1e5 + 5;

int n, a[N][4], mx1[N], mx2[N], id[N];
void solve() {
    scanf("%d", &n);
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j <= 3; ++j)
            scanf("%d", &a[i][j]);

    int ans = 0, cnt[4] = {}, p = 0;
    for (int i = 1; i <= n; ++i) {
        mx1[i] = mx2[i] = id[i] = 0;
        for (int j = 1, x; j <= 3; ++j) {
            x = a[i][j];
            if (mx1[i] < x) {
                mx2[i] = mx1[i];
                mx1[i] = x;
                id[i] = j;
            } else {
                mx2[i] = max(mx2[i], x);
            }
        }
        ans += mx1[i];
        ++cnt[id[i]];
        if (cnt[id[i]] > cnt[p]) p = id[i];
    }

    if (cnt[p] <= n / 2) {
        printf("%d\n", ans);
        return;
    }

    priority_queue<int> q;
    for (int i = 1; i <= n; ++i) {
        if (id[i] != p) continue;
        q.push(mx2[i] - mx1[i]);
    }

    int k = cnt[p] - n / 2;
    while (k--) {
        ans += q.top();
        q.pop();
    }
    printf("%d\n", ans);
}

int main() {
    freopen("club.in", "r", stdin);
    freopen("club.out", "w", stdout);
    int T;
    scanf("%d", &T);
    while (T--) solve();
    return 0;
}
```

**验证**：编译零错误；官方样例 1 组输出一致；另用 80 组随机小数据与暴力枚举对拍，结果全部一致（独立复跑）。

### T2 道路修复（road）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P14362 |
| 核心考点 | 贪心、最小生成树、预处理 |
| 难度 | 提高+/省选− |
| 一句话结论 | 把每个乡镇看成一个点、与城市 $i$ 连权为 $a_{j,i}$ 的边，并付出代价 $c_j$ "启用"该乡镇；枚举使用的乡镇集合后用 Kruskal 求最小生成树，并先把城市间 $m$ 条边做一次 Kruskal 压缩成 $n-1$ 条树边，把排序开销从 $2^k$ 中提出来。 |

**题目大意**：C 国的交通系统由 $n$ 座城市与 $m$ 条连接两座城市的双向道路构成，第 $i$ 条道路连接城市 $u_i$ 与 $v_i$，修复费用为 $w_i$。另有 $k$ 个准备进行城市化改造的乡镇，第 $j$ 个乡镇的改造费用为 $c_j$；改造完成后，它可在第 $i$（$1 \le i \le n$）座城市间修建一条费用为 $a_{j,i}$ 的道路，也可以不选择任何乡镇进行改造。求将原有的 $n$ 座城市两两连通（即任意两座原有城市都能通过若干条道路相互到达）的最小费用。数据范围：$1 \le n \le 10^4$，$1 \le m \le 10^6$，$0 \le k \le 10$，$1 \le u_i, v_i \le n$，$0 \le w_i, c_j, a_{j,i} \le 10^9$。

**题解**：

**16 分（$k \le 0$）**

此时 $k \le 0$，不需要考虑乡镇对城市带来的影响。因此可以直接使用 kruskal 算法来计算出最小生成树的边权总和即可。具体地，将 $m$ 条边按照边权从小到大排序，然后依次考虑连接每一条边后是否会形成环。若不形成环，则加入这条边；否则不加入。判断是否形成环，可以使用并查集。时间复杂度 $O(m \log m)$。

**另外 32 分（特殊性质 A）**

此时 $c_j = 0$，且对于每个乡镇 $j$，都存在一个城市 $i$ 满足 $a_{j,i} = 0$。这说明将任何一个乡镇都可以通过一个边权为 $0$ 的边加入到一个已经连通的图中，即需要付出的代价是 $0$。而如果是中途将乡镇与未连通图中的某个连通块进行连接（前提是这个连通块中存在与乡镇边权为 $0$ 的城市），然后再通过城市之间的边将每个城市进行连通，那么仍然能够发现使所有乡镇与城市连通需要的代价还是 $0$。

容易得到一个贪心的想法：既然任何一个时刻将乡镇与城市进行连通的代价都是 $0$，那么不妨一开始就让所有乡镇与它对应的 $0$ 代价城市相连接。这样一来，就可以在一开始不费任何代价地产生尽可能多的边权更小的边，这些边都是乡镇与城市之间的边，用于原图中的城市相互之间进行连接。具体地，对于乡镇 $j$ 进行如下额外的连边：

- 令乡镇的编号为 $n + j$，城市的编号为 $i$（$1 \le i \le n$）；
- 那么在 $n + j$ 与 $i$ 之间连接一条边权为 $a_{j,i}$ 的边。

随后，将这些额外的边与原本城市之间的边一同排序，进行一次 kruskal 算法即可计算出答案，注意使用 long long。设考虑到 $m > nk$，且 $n > k$，时间复杂度依然是 $O(m \log m)$。

**另外 24 分（$k \le 5$）**

注意到 $k \le 5$ 很小，可以考虑 dfs 枚举每个乡镇是否使用。具体的做法与上述"特殊性质 A"的做法类似，对于枚举到的每一种使用乡镇的情况，只需要把用到的乡镇对应的边额外加入进来即可，以便产生权值更小的边用于城市之间的连通。dfs 部分的复杂度是 $O(2^k)$，总时间复杂度是 $O(2^k m \log m)$。

**100 分：**

复杂度的瓶颈在于每次都将 $m$ 条边重新排序了，需要考虑将 $O(m \log m)$ 的排序从 $2^k$ 中提取出来。不难发现，$m \le 10^6$ 虽然很大，但是 $n \le 10^4$ 比较小，能够构成生成树的边至多有 $O(n)$ 条。于是我们可以先对城市之间的 $m$ 条边进行一次 kruskal，提取出其中有用的 $n - 1$ 条树边。

这样一来对于 dfs 枚举到的每一种乡镇情况，总边数就是 $O(nk)$ 级别而非 $O(m + nk)$，时间复杂度优化到了 $O(m \log m + 2^k nk \log(nk))$。然而，这样的复杂度可能还不足以通过本题。

考虑到每次还是会边重新排序，为了避免这种情况，我们其实完全可以在 dfs 之前，提前将所有的 $nk$ 条边与 $n - 1$ 条树边放在一起排序。为每条边标记上这条边来自于哪一个乡镇，这样一来，每次只需要枚举 $nk + n - 1$ 条边，根据边的标记来判断对应的乡镇当前是否可以使用，进而判断当前的这条边是否可以被选上。时间复杂度进一步降到了 $O(m \log m + 2^k nk)$。

**易错点**（整理）：

- 各类费用可达 $10^9$、求和会超过 `int`，答案与边权和要开 `long long`（代码中 `ans` 初始化为 `1e18`）。
- 新增乡镇点编号为 $n + j$，并查集要开到 $n + k$，且每次 Kruskal 前都要把 $fa[1 \ldots n+k]$ 重置。
- 枚举乡镇是否使用的 dfs 状态与边的乡镇标记要一致：代码用 `vis[]` 标记乡镇是否启用，城市之间的树边标记为 $0$，并在 `vis[0] = 1` 下恒可使用。

**参考代码**（转写自原文标程截图，已本地编译验证）：

```cpp
#include <bits/stdc++.h>
using namespace std;
typedef long long LL;
const int N = 1e5 + 5;
const int M = 2e6 + 5;
const int K = 10 + 5;

struct node {
    int u, v, w, id;
} ne[M], e[M];
bool cmp(node x, node y) {
    return x.w < y.w;
}

int n, m, k, fa[N], c[K], a[K][N], vis[K], cnt = 0;
int find(int u) {
    if (fa[u] != u) return fa[u] = find(fa[u]);
    return fa[u];
}
void merge(int u, int v) {
    u = find(u), v = find(v);
    if (u == v) return;
    fa[u] = v;
}

LL kruskal() {
    LL sum = 0;
    for (int j = 0; j <= k; ++j) {
        if (vis[j] == 0) continue;
        sum += c[j];
    }
    for (int i = 1; i <= n + k; ++i) fa[i] = i;
    for (int i = 1; i <= cnt; ++i) {
        if (vis[e[i].id] == 0) continue;
        int u = e[i].u, v = e[i].v, w = e[i].w;
        if (find(u) == find(v)) continue;
        merge(u, v);
        sum += w;
    }
    return sum;
}

LL ans = 1e18;
void dfs(int pos) {
    if (pos == k + 1) {
        ans = min(ans, kruskal());
        return;
    }
    vis[pos] = 1;
    dfs(pos + 1);
    vis[pos] = 0;
    dfs(pos + 1);
}

int main() {
    freopen("road.in", "r", stdin);
    freopen("road.out", "w", stdout);

    scanf("%d%d%d", &n, &m, &k);
    for (int i = 1, u, v, w; i <= m; ++i) {
        scanf("%d%d%d", &u, &v, &w);
        ne[i] = {u, v, w, 0};
    }
    for (int j = 1; j <= k; ++j) {
        scanf("%d", &c[j]);
        for (int i = 1, w; i <= n; ++i) {
            scanf("%d", &w);
            e[++cnt] = {i, n + j, w, j};
        }
    }

    sort(ne + 1, ne + m + 1, cmp);
    for (int i = 1; i <= n; ++i) fa[i] = i;
    for (int i = 1; i <= m; ++i) {
        int u = ne[i].u, v = ne[i].v, w = ne[i].w;
        if (find(u) == find(v)) continue;
        e[++cnt] = {u, v, w, 0};
        merge(u, v);
    }
    sort(e + 1, e + cnt + 1, cmp);

    vis[0] = 1;
    dfs(1);
    printf("%lld\n", ans);

    return 0;
}
```

**验证**：编译零错误；官方样例 1 组输出一致；另用 60 组随机小数据与暴力对拍，结果全部一致（独立复跑）。

### T3 谐音替换（replace）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P14363 |
| 核心考点 | AC 自动机 / 字典树 + 二维数点 |
| 难度 | 省选/NOI− |
| 一句话结论 | 把 $s_{i,1} = C+P+D$、$s_{i,2} = C+Q+D$ 拆成四元组 $(C_i,D_i,U_i,V_i) = (C_i,D_i,P_i,Q_i)$，问题化为"有多少 $i$ 满足 $(U_i,V_i) = (P_j,Q_j)$ 且 $C_i$ 是 $A_j$ 的后缀、$D_i$ 是 $B_j$ 的前缀"；按 $P_j + Q_j$ 分类后，用 AC 自动机（或 Trie + DFS 序二维数点）在每一类内统计。 |

**题目大意**：给出 $n$ 个字符串二元组 $(s_{i,1}, s_{i,2})$，满足 $|s_{i,1}| = |s_{i,2}|$。对字符串 $s$ 定义替换：对于某个子串 $y$，若存在 $1 \le i \le n$ 满足 $y = s_{i,1}$，则将 $y$ 替换为 $y' = s_{i,2}$；即把 $s = x + y + z$（$x, z$ 可空）替换为 $s' = x + y' + z$。有 $q$ 个询问，第 $j$ 个询问给出两个不同的字符串 $t_{j,1}, t_{j,2}$，询问有多少种替换 $t_{j,1}$ 能得到 $t_{j,2}$（两种替换不同当且仅当子串 $y$ 的位置不同或用于替换的二元组 $(s_{i,1}, s_{i,2})$ 不同）。$1 \le n, q \le 2 \times 10^5$，设 $L_1 = \sum_{i=1}^{n} |s_{i,1}| + |s_{i,2}|$、$L_2 = \sum_{j=1}^{q} |t_{j,1}| + |t_{j,2}|$，则 $2 \le L_1, L_2 \le 5 \times 10^6$，且 $L_1, L_2$ 同范围（简记为 $L$）。

> **校注**：原文题意段的下标写作 $t_{i,1}, t_{i,2}$（沿用了上文 $s_i$ 的 $i$），按上下文应为 $t_{j,1}, t_{j,2}$；下方描述以修正后的下标为准。

**题解**：

**10 分（$n, q \le 100$，$L_1, L_2 \le 200$）**

对于每个询问，对于每个 $i$，枚举 $s_{i,1}$ 在 $t_{j,1}$ 中的出现位置，在出现的位置将其替换为 $s_{i,2}$ 能得到 $t_{j,2}$ 则累加答案。时间复杂度：$O(qL^2)$。

**分析：**

如果 $(s_{i,1}, s_{i,2})$ 满足条件，我们考虑这次操作对 $t_{j,1}$ 的影响，如果 $s_{i,1}$ 与 $s_{i,2}$ 有一个公共的前缀，那么修改之后这两个前缀是不变的，对于后缀同理。

因此如果我们设 $s_{i,1} = C + P + D$，$s_{i,2} = C + Q + D$，则 $(s_{i,1}, s_{i,2})$ 本质将 $t_{j,1}$ 中的 $P$ 变成了 $Q$，因此 $t_{j,1}$ 必然可以表示成 $A + P + B$ 的形式，$t_{j,2}$ 可以表示成 $A + Q + B$ 的形式。此时 $C$ 是 $A$ 的后缀，$D$ 是 $B$ 的前缀。

由上述分析，我们使用 $(C_i, D_i, U_i, V_i)$ 来表示 $(s_{i,1}, s_{i,2}) = (C_i + U_i + D_i, C_i + V_i + D_i)$，使用 $(A_j, B_j, P_j, Q_j)$ 来表示 $(t_{j,1}, t_{j,2}) = (A_j + P_j + B_j, A_j + Q_j + B_j)$。

如果 $(s_{i,1}, s_{i,2})$ 满足要求，那么必然有 $(U_i, V_i) = (P_j, Q_j)$，$C_i$ 是 $A_j$ 的后缀，$D_i$ 是 $B_j$ 的前缀。

同时，经过上面的分析我们也知道，如果 $(s_{i,1}, s_{i,2})$ 满足要求，那么替换的位置是唯一的。

**50 分：$O(qL)$**

根据上面的分析，我们可以将所有的 $(s_{i,1}, s_{i,2})$ 转为 $(C_i, D_i, U_i, V_i)$ 的形式存储。

对于每个询问，先拆成 $(A, B, P, Q)$ 的形式，然后对于每个 $i$ 检查是否 $(P, Q) = (U_i, V_i)$，如果成立进一步检查 $C_i$ 是否为 $A$ 的后缀，$D_i$ 是否为 $B$ 的前缀。

时间复杂度：$O(qL)$，可以通过前 5 个数据，以及特殊性质 A（$q = 1$）的数据。

**20 分（特殊性质 B：字符串由 ab 构成，且 b 恰出现一次）**

延续分析的思路，此时 $(C, D, U, V)$ 中 $C, D$ 只由 a 构成，$U, V$ 必然一个以 b 开头，另一个以 b 结尾，因此可以分为两种：$U$ 以 b 开头的，$U$ 以 b 结尾的，此时进一步可以使用 $(c, d, u) = (|C|, |D|, |U|)$。$(A, B, P, Q)$ 同理，使用 $(a, b, p)$ 来描述。

对于同类型的 $(c, d, u)$ 与 $(a, b, p)$，$(c, d, u)$ 满足要求当且仅当 $u = p$ 且 $c \le a$ 且 $d \le b$。

此时有很多做法：

- 将 $(c, d)$ 视为二维平面上一个点，则相当于询问一个矩形内的点数量，使用扫描线处理。时间复杂度为 $O(L + q \log n)$。
- 注意到 $\sum c \le L$ 因此如果将 $c$ 离散化之后最多只有 $O(\sqrt{L})$ 个不同的 $c$，$d$ 也最多只有 $O(\sqrt{L})$ 个不同的，此时可以离散化之后直接二维前缀和。时间复杂度为：$O(L)$。
- ……

**100 分：**

回到我们的分析结论，有 $n$ 个四元组 $(C_i, D_i, U_i, V_i)$ 以及 $q$ 个询问 $(A_j, B_j, P_j, Q_j)$，询问有多少 $i$ 满足 $(U_i, V_i) = (P_j, Q_j)$，且 $C_i$ 是 $A_j$ 后缀，$D_i$ 是 $B_j$ 前缀。

$(U_i, V_i) = (P_j, Q_j)$ 好办，直接把 $U_i, V_i$ 拼成一个字符串 $U_i + V_i$，$P_j, Q_j$ 拼成一个字符串 $P_j + Q_j$，使用 hash 或者 Trie 树处理 $U_i + V_i$，将所有 $U_i + V_i$ 相同的视为同一类。那么我们只需要在 $P_j + Q_j$ 这一类中寻找答案即可。

那么问题变成 $P_j + Q_j$ 这一类中，有多少个 $(C_i, D_i)$ 满足 $C_i$ 是 $P_j$ 后缀，$D_i$ 是 $Q_j$ 前缀，有多种做法：

- AC 自动机。
  - 使用特殊字符 `#`，将 $C_i, D_i$ 以及 $A_j, B_j$ 拼接，问题等价于有多少 $X_i = C_i + \# + D_i$ 是 $Y_j = A_j + \# + B_j$ 的子串。
  - 使用 AC 自动机求解，对 $X_i$ 建立自动机。如果 $X_i$ 是 $Y_j$ 的子串 $Y_j[l:r]$，则 $X_i$ 是 $Y_j$ 前缀 $Y_j[1:r]$ 的后缀，问题变成有多少个 $Y_j$ 的前缀的后缀是 $X_i$。
  - 可以得到 $Y_j$ 每个前缀 $Y_j[1:r]$ 在 AC 自动机上对应的点 $t$，则满足是 $Y_j[1:r]$ 后缀的字符串都是 $t$ 的祖先，预处理祖先有多少个 $X_i$ 即可。
  - 由于每个 $X_i$ 最多在 $Y_j$ 中出现一次，这样不会算重。
  - 时间复杂度：$O(L)$。
- 二维数点。
- 离线。
  - 对 $D_i, B_j$ 建立 Trie 树并求出 DFS 序，则 $D_i$ 是 $B_j$ 的前缀等价于 $B_j$ 在 $D_i$ 的子树中。对 $C_i, A_j$ 同样处理，不过需要先将字符串 reverse。
  - 问题变成对于每个 $B_j$，reverse$(A_j)$，询问有多少 $D_i$ 是 $B_j$ 的祖先，且 reverse$(C_i)$ 是 reverse$(A_j)$ 的祖先。将 $D_i$, reverse$(C_i)$ 视为一个矩形 $[l_D, r_D] \times [l_C, r_C]$，其中 $[l_D, r_D]$ 为 $D_i$ 子树 DFS 序，$[l_C, r_C]$ 为 reverse$(C_i)$ 子树 DFS 序；将 $B_j$, reverse$(A_j)$ 视为二维平面一个点 $(b, a)$，分别对应 DFS 序。则问题变成一个点被多少个矩形包含。
  - 使用扫描线即可。时间复杂度：$O(L + (n + q) \log(n + q))$。
- ……

**易错点**（整理）：

- 需要把 $s_{i,1}, s_{i,2}$ 的最长公共前缀 $C_i$ 与最长公共后缀 $D_i$ 剥离（代码里用 `while (s[x] == t[x]) ++x;` 与 `while (s[y] == t[y]) --y;` 求 $x, y$，则 $U = s[x..y]$、$V = t[x..y]$、$C = s[0..x-1]$、$D = s[y+1..]$）；若 $s = t$ 则无 $U$，需跳过。
- 同一类 $P + Q$ 需要用同一个 Trie 根（代码中 `root[crt]`）建 AC 自动机，不同类不能混用；分类键是 $P_j + Q_j$ 而不是 $U_i + V_i$ 的某个单串。
- 拼接分隔符用一个不在字符集内的字符（代码取 `char('z' + 1)`，即 ASCII 的 `{`），字符集大小因此开到 $S = 27$。
- 询问可能出现 $|t_{j,1}| \ne |t_{j,2}|$，此时答案必然为 $0$，需要特判。

**参考代码**（转写自原文标程截图，已本地编译验证）：

```cpp
// 代码为 AC 自动机做法
#include <bits/stdc++.h>

const int N = 5e6 + 7;
const int M = 1e7 + 7;
const int S = 27;

int wd[N][S], id[N], cwd = 1;
int ch[N][S], ed[N], cnt, root[N], crt, fail[N], f[N];
int q[N], fr, ba;
int n, m;

int inswd(std::string s) {  // 对 U+V 建立 Trie 树
    int now = 1;
    for (char c : s) {
        if (!wd[now][c - 'a'])
            wd[now][c - 'a'] = ++cwd;
        now = wd[now][c - 'a'];
    }
    if (!id[now]) {  // 以相同节点结尾的串为同一个类
        id[now] = ++crt;
        root[crt] = ++cnt;  // 同一个类建立 AC 自动机，他们拥有相同的根
    }
    return root[id[now]];
}

int getwd(std::string s) {  // 获取 P+Q 是哪一个类
    int now = 1;
    for (char c : s)
        now = wd[now][c - 'a'];
    return root[id[now]];
}

void ins(int now, std::string s) {  // 对同一个类的 C+#+D 建立 AC 自动机
    for (char c : s) {
        if (!ch[now][c - 'a'])
            ch[now][c - 'a'] = ++cnt;
        now = ch[now][c - 'a'];
    }
    ++f[now];
}

void getac(int rt) {  // 建立 AC 自动机
    fr = 1, ba = 0;
    for (int i = 0; i < S; ++i)
        if (ch[rt][i]) {
            fail[ch[rt][i]] = rt;  // 由于根不是 0，所以要预处理 fail
            q[++ba] = ch[rt][i];
        } else
            ch[rt][i] = rt;  // 以及根的空儿子
    while (fr <= ba) {
        int x = q[fr++];
        f[x] += f[fail[x]];  // 递推一下 x 到根的链有多少 C+#+D
        for (int i = 0; i < S; ++i)
            if (ch[x][i]) {
                fail[ch[x][i]] = ch[fail[x]][i];
                q[++ba] = ch[x][i];
            } else
                ch[x][i] = ch[fail[x]][i];
    }
}

int run(int now, std::string s) {  // 对 P+#+Q 跑一遍 AC 自动机
    int ret = 0;
    for (char c : s) {
        now = ch[now][c - 'a'];
        ret += f[now];  // 对每个前缀统计答案
    }
    return ret;
}

int main() {
    freopen("replace.in", "r", stdin);
    freopen("replace.out", "w", stdout);

    std::cin >> n >> m;

    for (int i = 1; i <= n; ++i) {
        std::string s, t;
        std::cin >> s >> t;
        if (s == t)
            continue;
        int x = 0, y = s.size() - 1;
        while (s[x] == t[x])
            ++x;
        while (s[y] == t[y])
            --y;
        int rt = inswd(s.substr(x, y - x + 1) + t.substr(x, y - x + 1));
        // 这里 # 实际上选择的是 ASCII 为 'z'+1 的字符 { 节省空间
        ins(rt, s.substr(0, x) + char('z' + 1) + s.substr(y + 1));
    }

    for (int i = 1; i <= crt; ++i)
        getac(root[i]);

    for (int i = 1; i <= m; ++i) {
        std::string s, t;
        std::cin >> s >> t;
        if (s.size() != t.size()) {
            std::cout << 0 << '\n';
            continue;
        }
        int x = 0, y = s.size() - 1;
        while (s[x] == t[x])
            ++x;
        while (s[y] == t[y])
            --y;
        int rt = getwd(s.substr(x, y - x + 1) + t.substr(x, y - x + 1));
        std::cout << run(rt, s.substr(0, x) + char('z' + 1) + s.substr(y + 1)) << '\n';
    }

    return 0;
}
```

### T4 员工招聘（employ）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P14364 |
| 核心考点 | 动态规划、容斥 |
| 难度 | 省选/NOI− |
| 一句话结论 | 直接 DP：设 $f(i, j, k)$ 表示前 $i$ 场面试、有 $j$ 人未通过、且 $c > j$ 的人中已有 $k$ 人参加过面试的方案数，按 $s_i$ 与当前人通过/不通过分三类转移，最后对 $c \le n$ 的状态补上阶乘，答案对 $998244353$ 取模。 |

**题目大意**：$n$ 个人前来应聘（编号 $1 \sim n$），要录用至少 $m$ 人。小 Z 决定面试顺序，即在第 $i$ 天安排排列 $p$ 中的第 $p_i$ 个人面试。第 $i$ 天的题目难度为 $s_i \in \{0,1\}$，$s_i = 0$ 表示没人能做出来（面试者被拒绝），$s_i = 1$ 表示所有人都能做出来（录用）。编号为 $i$ 的人有耐心上限 $c_i$：若在他面试之前已经有不少于 $c_i$ 人被拒绝或放弃，则他也放弃参加面试。求能录用至少 $m$ 人的排列 $p$ 的数量，对 $998244353$ 取模。数据范围：$1 \le m \le n \le 500$，$s_i \in \{0,1\}$，$0 \le c_i \le n$。

**题解**：

**8 分（$n \le 10$）**

$O(n!)$ 枚举所有可能的排列。再模拟判断是否满足要求即可。时间复杂度：$O(n!)$ 或者 $O(n \cdot n!)$。

**20 分（$n \le 18$）**

使用状压 DP，设 $f(i, S, j)$ 表示前 $i$ 场面试，集合 $S$ 中的面试者参加，总共通过了 $j$ 位面试者。

转移时枚举下一位面试者 $k$，如果 $s_i = 0$ 或者 $i - j \ge c_k$ 则这位面试者不通过，记录 $r = 0$，否则面试者通过，记录 $r = 1$，则转移为 $f(i + 1, S \cup \{k\}, j + r) \leftarrow f(i, S, j)$。

时间复杂度：$O(n^3 2^n)$。看起来过不了，实际上 $i = |S|$，所以不需要将 $i$ 加入状态，时间复杂度：$O(n^2 2^n)$。可以通过这部分。

**12 分（$m = 1$）**

容斥处理，答案为 $n!$ 减去所有面试者都不通过的方案数。

如果 $s_i = 1$ 则所有面试者都通过，但实际上并没有，说明面试者拒绝面试。而根据计算目标可知前 $i - 1$ 场面试有 $i - 1$ 位面试者不通过，因此要求为 $c_j \le i - 1$。

如果 $s_i = 0$ 则所有面试者都不通过，此时相当于要求 $c_j \le n$ 的面试者。

因此如果 $s_i = 1$ 则 $t_i = i - 1$，否则 $t_i = n$。将 $t$ 从小到大排序之后递推即可。设 $q_k$ 表示 $c_j \le k$ 的面试者数量，则方案数为（$t$ 已排序）：$\prod_{i=1}^{n}(q_{t_i} - i + 1)$。

时间复杂度：$O(n \log n)$。

**4 分（$m = n$）**

如果存在 $s_i = 0$ 或者 $c_j = 0$ 则必然不可能，方案数为 $0$，否则必然都成立，方案数为 $n!$。

时间复杂度：$O(n)$。

**16 分（特殊性质 B：$\sum_{i=1}^{n} s_i \le 18$）**

只有少量面试者可能通过，此时枚举 $S$ 表示参加集合 $S$ 中面试的面试者通过了，其他面试者全部失败。

对于 $s_i = 1$ 且 $i \in S$ 的面试者，他通过了，他前面有 $i - 1 - \sum_{x \in S}[x < i]$ 位面试者失败，因此要求 $c_j > i - 1 - \sum_{x \in S}[x < i]$。

对于 $s_i = 1$ 且 $i \notin S$ 的面试者，他拒绝面试，则要求 $c_j \le i - 1 - \sum_{x \in S}[x < i]$。

对于 $s_i = 0$，必定失败，$c_j \le n$。

发现对 $c_j$ 的要求有大于还有小于等于，使用容斥，将大于号容斥成小于号，则可以使用 $m = 1$ 时的做法。

令 $k = \sum_{i=1}^{n} s_i$，直接做时间复杂度为 $O(k3^k)$。

继续枚举集合 $S$，然后不再枚举 $S$ 的子集 $T$ 进行计算，而是使用状压 DP 计算，设 $f(i, j)$ 表示在前 $i$ 个 $s$ 为 1 的位置，容斥了 $j$ 次的方案数（$c > x$ 等价于 $c \le n$ 减去 $c \le x$，这里的 $j$ 表示前者的选取次数）。转移时分情况讨论：

- 如果 $i \notin S$，则直接乘，设 $s$ 第 $i$ 个 1 的位置为 $p$，则有 $a = p - 1 - \sum_{x \in S}[x < p]$ 位面试者失败，之前已经计算了 $j$ 个容斥的 $\le$ 以及钦定的 $b = i - 1 - \sum_{x \in S}[x < p]$ 个 $\le$，因此转移为 $f(i + 1, j) \leftarrow f(i, j)(q_a - j - b)$。
- 如果 $i \in S$，若取 $c \le n$，则 $f(i + 1, j) \leftarrow f(i, j)$；否则 $f(i + 1, j + 1) \leftarrow -f(i, j)(q_a - j - b)$。

最后统计答案，计算上 $c \le n$ 的即可，对于 $f(i, j)$ 总共有 $n - k + |S| - j$ 个 $c \le n$，乘上一个阶乘即可。

时间复杂度：$O(k^2 2^k)$。

**100 分：**

有两种做法：

- 容斥
  - 发现特殊性质 B 中的 $S$ 可以放入转移方程，因为我们计算只需要知道 $\sum_{x \in S}[x < p]$，这实际上就是当前 $S$ 的大小 $|S|$。
  - 因此设 $f(i, j, t)$ 表示在前 $i$ 个 $s$ 为 1 的位置，容斥了 $j$ 次，此时 $|S| = k$ 时的方案数。转移类似，不再赘述。
  - 时间复杂度 $O(n^3)$。
  > **校注**：原文此处写作「此时 $|S| = k$ 时的方案数」，第三个参数与 $k$ 混用，疑为笔误（按上下文应为「$|S| = t$」，即状态第三维是 $t$）。
- 直接 DP
  - 还可以直接 DP。设之前有 $j$ 位面试者不通过，则对于尚未参与面试的 $c \le j$ 的面试者无论参加 $s$ 如何的面试均会失败，而 $c > j$ 的面试者参加 $s = 1$ 的面试能通过。
  - 此时可以将所有人分为两部分：$c \le j$ 以及 $c > j$，对于前者我们需要知道具体每个人是否参加面试，对于后者，我们并不需要知道谁具体参加了面试（谁去都一样），只需要在 $j$ 增大时处理一下（此时有一部分面试者从 $c > j$ 的后者变成了前者）。
  - 设 $f(i, j, k)$ 表示前 $i$ 场面试，有 $j$ 位面试者未通过，还有 $k$ 位 $c \le j$ 的面试者尚未参加面试。转移分三种（设 $a_x$ 表示有多少面试者 $c = x$，$b$ 为 $a$ 的前缀和）：
    - 其一：一个 $c \le j$ 的面试者参加了第 $i$ 场面试，此时不论 $s$ 如何均不通过。转移到 $f(i + 1, j + 1, \cdot)$，因此 $c = j + 1$ 的面试者会从后者变成前者，此时需要考虑这些面试者是否参加了之前的面试。之前有 $i$ 场面试，$c \le j$ 的面试者总共 $b_j$ 人，有 $k$ 人未参加面试，说明有 $b_j - k$ 位面试者参加了面试，还有 $i - b_j + k$ 场面试是由 $c > j$ 的面试者参加的，这其中有 $t$ 场是由 $c = j + 1$ 的面试者参加的，则转移之后 $c \le j + 1$ 的面试者共 $k - 1 + a_{j+1} - t$ 位。
      - $f(i + 1, j + 1, k - 1 + a_{j+1} - t) \leftarrow f(i, j, k) \times k \times \binom{i - b_j + k}{t}\binom{a_{j+1}}{t}t!$
    - 其二：$s_i = 0$，一个 $c > j$ 的面试者参加，同样枚举 $i + 1 - b_j + k$ 场 $c > j$ 的面试者参加的面试中，有 $t$ 场是由 $c = j + 1$ 的面试者参加的。
      - $f(i + 1, j + 1, k + a_{j+1} - t) \leftarrow f(i, j, k) \times \binom{i + 1 - b_j + k}{t}\binom{a_{j+1}}{t}t!$
    - 其三：$s_i = 1$，一个 $c > j$ 的面试者参加，此时 $j$ 不变，方程最简单。
      - $f(i + 1, j, k) \leftarrow f(i, j, k)$
  - 注意到当 $j$ 从 0 到 $n$ 时 $\sum t = \sum b_{j+1} = n$，因此时间复杂度为 $O(n^3)$。

**易错点**（整理）：

- 耐心上限是"不少于 $c_i$ 人已失败则放弃"，因此判断不通过的条件是 $i - j \ge c_k$（代码里写 `i - j >= c[k]`），边界取等号。
- 最终统计时状态 $k$ 必须为 $0$（当前 $c \le j$ 的人已全部参加完），并且要把剩下"必定会被录用"的 $n - b_j$ 个人任意排列补上，即乘以 `fac[n - s[j]]`。
- 人数分档与 $c_j$ 的关系通过前缀和 $s[j] = \sum_{i \le j} a_i$ 与组合数 $\binom{\cdot}{\cdot}$ 处理，组合数预处理到 $n$ 即可；模数 $998244353$。

**参考代码**（转写自原文标程截图，已本地编译验证）：

```cpp
// 代码为直接DP的做法
#include <bits/stdc++.h>

const int N = 500 + 7;
const int MOD = 998244353;

struct mint {
    int x;
    mint(int x = 0) : x(x) {
    }
    mint& operator=(int o) {
        x = o;
        return *this;
    }
    mint operator+(mint o) {
        return (x + o.x) % MOD;
    }
    mint& operator+=(mint o) {
        x = (x + o.x) % MOD;
        return *this;
    }
    mint operator*(int o) {
        return 1LL * x * o % MOD;
    }
    mint operator*(mint o) {
        return 1LL * x * o.x % MOD;
    }
    mint& operator*=(mint o) {
        x = 1LL * x * o.x % MOD;
        return *this;
    }
    operator int() {
        return x;
    }
};

mint operator+(int x, mint y) {
    return (x + y.x) % MOD;
}

mint operator*(int x, mint y) {
    return mint(1LL * x * y.x % MOD);
}

mint ff[2][N][N];
int n, m, b[N], a[N], s[N], c[N][N], fac[N];

int main() {
    freopen("employ.in", "r", stdin);
    freopen("employ.out", "w", stdout);

    scanf("%d%d", &n, &m);
    m = n - m;
    for (int i = 1; i <= n; ++i)
        scanf("%1d", &b[i]);
    for (int i = 1, x; i <= n; ++i) {
        scanf("%d", &x);
        ++a[x];
    }

    s[0] = a[0];
    for (int i = 1; i <= n; ++i)
        s[i] = s[i - 1] + a[i];

    for (int i = 0; i <= n; ++i)
        c[i][0] = c[i][i] = 1;
    for (int i = 1; i <= n; ++i)
        for (int j = 1; j < i; ++j)
            c[i][j] = (c[i - 1][j - 1] + c[i - 1][j]) % MOD;

    fac[0] = 1;
    for (int i = 1; i <= n; ++i)
        fac[i] = 1LL * fac[i - 1] * i % MOD;

    ff[0][0][s[0]] = 1;
    for (int i = 0; i < n; ++i) {
        mint (&f)[N][N] = ff[~i & 1], (&g)[N][N] = ff[i & 1];
        memset(f, 0, sizeof f);
        for (int j = 0; j <= m; ++j)
            for (int k = std::max(0, s[j] - i); k <= s[j]; ++k) {
                if (k)
                    for (int t = 0; t <= std::min(a[j + 1], i - s[j] + k); ++t)
                        f[j + 1][k - 1 + a[j + 1] - t] += g[j][k] * k * c[i - s[j] + k][t] * c[a[j + 1]][t] * fac[t];
                if (b[i + 1] == 0)
                    for (int t = 0; t <= std::min(a[j + 1], i + 1 - s[j] + k); ++t)
                        f[j + 1][k + a[j + 1] - t] += g[j][k] * c[i + 1 - s[j] + k][t] * c[a[j + 1]][t] * fac[t];
                else
                    f[j][k] += g[j][k];
            }
    }

    mint ans;
    for (int j = 0; j <= m; ++j)
        ans += ff[n & 1][j][0] * fac[n - s[j]];

    printf("%d\n", ans.x);

    return 0;
}
```

### T1 决斗（duel）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P11231 |
| 核心考点 | 贪心 |
| 难度 | 普及/提高− |
| 一句话结论 | 答案就是 $r$ 序列中众数（出现次数最多的值）的出现次数。 |

**题目大意**：有 $n$ 只怪兽，第 $i$ 只怪兽的攻击力和防御力均为 $r_i$。利用这 $n$ 只怪兽进行若干回合的游戏，每回合选择一只怪兽 $i$ 向另一只怪兽 $j$ 发起攻击，如果 $r_i > r_j$ 则会击破怪兽 $j$ 并使其离开游戏，否则无事发生。每只怪兽正常游戏最多攻击一次，当未退出的怪兽都发动过攻击时游戏结束，求结束时怪兽数量的最小值。

**题解**：

**100 分**

称 $r_i > r_j$ 的攻击为有效的攻击，则题目相当于要最大化有效的攻击数量，而一只怪兽最多攻击一次，最多受到一次有效的攻击并因此退场。因此可以将所有怪兽按照 $r$ 排序之后，从小到大贪心进行有效的攻击，具体来说可以从小到大枚举每一只怪兽，检查是否还存在未退场且 $r$ 不超过当前怪兽的怪兽，如果存在则进行一次有效攻击。时间复杂度为 $O(n \log n)$。

如果你学过 Dilworth 定理，可以发现实际上答案就是 $r$ 中众数的出现次数。当然 Dilworth 定理已经超出了 CSP-S 第一题的范围，这里仅做提示。

**易错点**：
- 答案是"剩下的怪兽数"即众数出现次数，而不是可配对的攻击次数，两者互为补数，注意不要少算/多算 1。（整理）
- 有效攻击要求严格 $r_i > r_j$，相同 $r$ 的怪兽之间不能互相攻击。（整理）

**参考代码**（转写自原文标程截图，已本地编译验证）：

```cpp
#include <bits/stdc++.h>

int n;
std::map<int, int> mp;

int main() {

    freopen("duel.in", "r", stdin);
    freopen("duel.out", "w", stdout);

    scanf("%d", &n);
    for(int i = 1, x; i <= n; ++i) {
        scanf("%d", &x);
        ++mp[x];
    }

    int ans = 0;
    for(auto vp: mp)
        ans = std::max(ans, vp.second);

    printf("%d\n", ans);

    return 0;
}
```

### T2 超速检测（detect）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P11232 |
| 核心考点 | 二分 + 区间覆盖贪心 |
| 难度 | 提高+/省选− |
| 一句话结论 | 把每辆车会超速的测速仪编号区间 $[l_i, r_i]$ 求出，第二问转化为"用最少的点覆盖所有闭区间"的经典区间覆盖贪心。 |

**题目大意**：有一条长度为 $L$ 的南北主干道，有 $n$ 辆车行驶在主干道上，第 $i$ 辆车从距离最南端位置 $d_i$ 驶入，初速度 $v_i$，加速度 $a_i$ 做匀加速运动向北方行驶，当车辆行驶到最北端或者速度降为 $0$ 时认为离开了主干道。主干道上有 $m$ 个测速仪，第 $j$ 个测速仪位于距离最南端 $p_j$ 的位置，如果车辆到达 $p_j$ 时速度超过 $V$ 则会被认为超速。求 $n$ 辆车中有多少辆车被摄像头拍到超速，以及最多撤掉多少摄像头可以使得原来被拍到超速的车依旧被拍到超速。

**题解**：

**小数据（20 分）：$n, m \le 20$**

首先 $O(nm)$ 利用提示部分给出的计算公式计算出每辆车会被哪些摄像头拍到超速，并回答第一问。之后 $O(2^m)$ 枚举每一个摄像头是否被撤掉，然后 $O(nm)$ 或 $O(n)$（利用状态压缩以及位运算 $O(1)$ 判断）检测每辆车是否会被检测出超速。

**特殊性质 A（20 分）：$a_i = 0$**

所有车辆都做匀速直线运动，所以不会有中途离开主干道的情况，因此只要 $d_i \le p_m$ 并且 $v_i > V$ 就会被拍到超速，第一问统计这样的车辆数量即可。第二问如果没有车辆超速则可以撤掉所有摄像头，否则保留位置 $p_m$ 的摄像头即可。

**特殊性质 B（20 分）：$a_i > 0$**

和特殊性质 A 差不多，对于 $d_i \le p_m$ 的车必然在 $p_m$ 车最快，所以利用公式计算每辆车在 $p_m$ 的车速判断是否超速即可。第二问和特殊性质 A 完全一致。

**100 分**

由于车辆进行匀加速直线运动，所以每辆车要么从头到尾不超速，要么在主干道的某一段区间超速，所以我们可以先计算出每辆车超速的被抓拍区间 $[l_i, r_i]$ 表示这辆车会被第 $l_i$ 到第 $r_i$ 个摄像头拍到超速。$l_i, r_i$ 的具体计算方法如下（先求出在道路的哪一段超速，再利用二分/预处理转化到 $l_i, r_i$）：

- 如果 $a_i = 0$，则仅当 $v > V$ 时会超速，并且在道路的 $[d_i, L]$ 超速。
- 如果 $a_i > 0$，如果 $v > V$ 则在道路 $[d_i, L]$ 超速，否则计算出速度到达 $V$ 时的行驶距离 $\dfrac{v^2 - v_i^2}{2a_i}$，则超速区间为 $\left(d_i + \dfrac{v^2 - v_i^2}{2a_i}, L\right]$，在代码中这个区间可以转化为闭区间 $\left[d_i + \left\lfloor \dfrac{v^2 - v_i^2}{2a_i} \right\rfloor + 1, L\right]$，需要检查这个区间的合法性。
- 如果 $a_i < 0$，则仅当 $v > V$ 时会超速，同样可以计算到达 $V$ 时的行驶距离得到超速区间 $\left[d_i, d_i + \dfrac{v_i^2 - v^2}{-2a_i}\right)$，代码中区间可以转化为闭区间 $\left[d_i, d_i + \left\lfloor \dfrac{v_i^2 - v^2}{-2a_i} \right\rfloor\right]$，需要检查右端点是否大于 $L$。

对于第二问，相当于要用尽最少的点覆盖所有闭区间，这是一个经典的区间覆盖问题，可以使用贪心法解决，具体来说先将所有区间按右端点从小到大排序，之后贪心的选择来覆盖区间的右端点即可。时间复杂度为 $O(n \log m)$ 或者发现 $L$ 不大，精细的实现到 $O(n + L)$。

**易错点**：
- 第二问按右端点排序后，枚举到 $i$ 时若 $r_i$ 超过了上一个已选点位置才计数并更新，`r[i]` 记录的应是"右端点为 $i$ 的所有区间中最靠右的左端点"。（整理）
- $a_i > 0$ 且 $v_i \le V$ 时需先加速到 $V$ 才可能超速，位移公式的边界要 $+1$；$a_i < 0$ 时右端点可能超过 $L$ 需截断。（整理）

**参考代码**（转写自原文标程截图，已本地编译验证）：

```cpp
#include <bits/stdc++.h>

using LL = long long;

const int N = 1e5 + 7;

int n, m, l, s, d[N], v[N], a[N], p[N], r[N];

void solve() {
    scanf("%d%d%d%d", &n, &m, &l, &s);
    for(int i = 1; i <= n; ++i)
        scanf("%d%d%d", &d[i], &v[i], &a[i]);
    for(int i = 1; i <= m; ++i)
        scanf("%d", &p[i]);
    for(int i = 1; i <= m; ++i)
        r[i] = 0;
    int ans = 0, cnt = 0;
    for(int i = 1; i <= n; ++i)
        if(a[i] == 0 && v[i] > s && d[i] <= p[m]) {
            ++ans;
            int t = std::lower_bound(p + 1, p + m + 1, d[i]) - p;
            r[m] = std::max(r[m], t);
        }
        else if(a[i] < 0 && v[i] > s) {
            int tl = std::lower_bound(p + 1, p + m + 1, d[i]) - p;
            int pos = (v[i] * v[i] - s * s - 1) / 2 / -a[i];
            int tr = std::upper_bound(p + 1, p + m + 1, d[i] + pos) - p - 1;
            if(tl <= tr) {
                ++ans;
                r[tr] = std::max(r[tr], tl);
            }
        }
        else if(a[i] > 0) {
            int pos = v[i] <= s ? (s * s - v[i] * v[i]) / 2 / a[i] + 1 : 0;
            int t = std::lower_bound(p + 1, p + m + 1, d[i] + pos) - p;
            if(t <= m) {
                ++ans;
                r[m] = std::max(r[m], t);
            }
        }
    int ans2 = 0, lst = 0;
    for(int i = 1; i <= m; ++i)
        if(r[i] > lst) {
            lst = i;
            ++ans2;
        }
    printf("%d %d\n", ans, m - ans2);
}

int main() {

    freopen("detect.in", "r", stdin);
    freopen("detect.out", "w", stdout);

    int cases;
    scanf("%d", &cases);

    while(cases--)
        solve();

    return 0;
}
```

### T3 染色（color）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P11233 |
| 核心考点 | 动态规划 + 贪心优化 |
| 难度 | 提高+/省选− |
| 一句话结论 | 把 DP 转移化简为"全局加值 + 单点取 max"两类操作，答案 = 全局最大值 + 相邻相等元素之和。 |

**题目大意**：给出一个长度为 $n$ 的数组 $A$，你需要将 $A$ 中每个数染成蓝色或者红色，然后对于每一个位置 $i$，如果其左侧有相同颜色的数，且左侧最靠近 $i$ 的同色数与 $A_i$ 相等，那么可以获得 $A_i$ 的收益。求收益之和的最大值。

**题解**：

**小数据（20 分）：$n \le 15$**

暴力 $O(2^n)$ 枚举每一个数的颜色，然后 $O(n)$ 检验即可。

**（50 分）：$n \le 2000$**

考虑 DP，从左到右考虑每一个数的颜色，而 $A_i$ 的得分只与其左侧最靠近 $A_i$ 的同色数有关，因此我们可以将最靠近 $A_i$ 的颜色的不同的两个数写到状态里面，再注意到 $A_{i-1}$ 必然是其中一个，因此状态看似是三维，实际上是两维的。也就是设 $f(i, j)$ 表示确定了 $A_1 \sim A_i$ 的颜色，其中最靠近 $A_i$ 且与 $A_i$ 颜色不同的数是 $A_j$。

考虑从 $f(i - 1, j)$ 能进行的转移：考虑 $A_i$ 的颜色：与 $A_{i-1}$ 相同或者与 $A_{i-1}$ 不同。如果与 $A_{i-1}$ 相同则能从 $f(i - 1, j)$ 转移到 $f(i, j)$，表达式为 $f(i, j) \leftarrow f(i - 1, j) + [A_{i-1} = A_i] A_i$，如果与 $A_{i-1}$ 不同，则能从 $f(i - 1, j)$ 转移到 $f(i, i - 1)$，表达式为 $f(i, i - 1) \leftarrow f(i - 1, j) + [A_i = A_j] A_i$。其中 $[p]$ 在 $p$ 为真时值为 1，$p$ 为假时值为 0。

最终答案为 $\max_{i=1}^{n-1}\{f(n, i)\}$。时间复杂度为 $O(n^2)$。

**特殊数据（15 分）：$A_i \le 10$**

此时 $A_i$ 值域很小，并且转移里面的 $j$ 有用的部分只有其值 $A_j$，因此我们可以将下标 $j$ 变成值 $v$，也就是状态转移变为 $f(i, v)$ 表示已经确定了 $A_1 \sim A_i$ 的颜色，其中最靠近 $A_i$ 且与 $A_i$ 颜色不同的数为 $v$。

同样考虑 $f(i - 1, v)$ 能进行的转移：如果 $A_i$ 颜色与 $A_{i-1}$ 相同，则 $f(i, v) \leftarrow f(i - 1, v) + [A_{i-1} = A_i] A_i$，否则 $f(i, A_{i-1}) \leftarrow f(i - 1, v) + [A_i = v] A_i$。

时间复杂度为 $O(n \max A)$。

**100 分**

使用贪心优化上述转移，如果 $A_i = A_{i-1}$，则此时必然 $A_i$ 颜色与 $A_{i-1}$ 颜色相同，因此此时其实只会进行转移 $f(i, v) \leftarrow f(i - 1, v) + A_i$。如果 $A_i \ne A_{i-1}$，则分情况讨论，如果 $A_i$ 颜色与 $A_{i-1}$ 相同，则转移 $f(i, v) \leftarrow f(i - 1, v)$，否则如果 $A_i = v$ 则 $f(i, A_{i-1}) \leftarrow f(i - 1, v) + A_i$，否则 $f(i, A_{i-1}) \leftarrow f(i - 1, v)$，这一部分的转移可以写成

$$f(i, A_{i-1}) = \max\left(\max_{v}\{f(i - 1, v)\}, f(i - 1, A_i) + A_i\right)$$

综上所述，当 $A_i = A_{i-1}$ 时 $f(i, v) \leftarrow f(i - 1, v) + A_i$，相当于全局加上 $A_i$；当 $A_i \ne A_{i-1}$ 时如果 $A_i$ 颜色与 $A_{i-1}$ 相同则 $f(i, v) \leftarrow f(i - 1, v)$ 相当于无事发生，如果 $A_i$ 颜色与 $A_{i-1}$ 不同时 $f(i, A_{i-1}) = \max(\max_{v}\{f(i - 1, v)\}, f(i - 1, A_i) + A_i)$。相当于是将 $f(i, A_{i-1})$ 设为全局最大值与 $f(i - 1, A_i) + A_i$ 的最大值。

设 $a = \max A$，全局加，全局最大值，单点求值，单点加法可以使用各种数据结构（例如线段树）做到 $O(n \log a)$，注意到所有操作都是全局和单点，所以也可以简单使用数组解决，时间复杂度 $O(n + a)$。

**易错点**：
- 贪心优化后要分清三种情况：$A_i = A_{i-1}$ 全局加 $A_i$；$A_i \ne A_{i-1}$ 且颜色相同时无事发生；颜色不同时只对单点 $A_{i-1}$ 取 max。（整理）
- $f$ 数组初值需设为极小值（如 `-1e12`），并且每组数据要按当前出现的值域重置对应位置。（整理）

**参考代码**（转写自原文标程截图，已本地编译验证）：

```cpp
#include <bits/stdc++.h>

using LL = long long;

const int N = 1e6 + 7;

int n, a[N];
LL f[N];

void solve() {
    scanf("%d", &n);
    for(int i = 1; i <= n; ++i) {
        scanf("%d", &a[i]);
        f[a[i]] = -1e12;
    }
    LL s = 0, mx = 0;
    for(int i = 2; i <= n; ++i)
        if(a[i] == a[i - 1])
            s += a[i];
        else {
            f[a[i - 1]] = std::max(mx, f[a[i]] + a[i]);
            mx = std::max(mx, f[a[i - 1]]);
        }
    printf("%lld\n", mx + s);
}

int main() {

    freopen("color.in", "r", stdin);
    freopen("color.out", "w", stdout);

    int cases;
    scanf("%d", &cases);

    while(cases--)
        solve();

    return 0;
}
```

### T4 擂台游戏（arena）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P11234 |
| 核心考点 | 线段树 / 树形 DP（自顶向下维护限制） |
| 难度 | 省选/NOI− |
| 一句话结论 | 把赛程建成一棵满二叉树（线段树），预处理每个区间胜者与各选手的"可达轮次"，再自顶向下维护 $vt$、$rd$ 表即可 $O(1)$ 回答每个询问。 |

**题目大意**：设有 $2^k$ 人参加擂台比赛，则游戏分 $k$ 轮，每一轮相邻的两个人进行对局，胜者进入下一轮，败者淘汰，最后剩下的人为冠军。对于第 $R$ 轮的第 $G$ 场比赛有数 $d_{R,G}$，若 $d_{R,G} = 0$ 则编号小的为擂主，否则 $d_{R,G} = 1$ 表示编号大的为擂主，如果擂主的能力值大于等于轮次 $R$ 则擂主获胜，否则擂主失败。因此每一轮的结果只与擂主的能力值及轮次有关。

现在小 S 依次收到了 $n$ 位选手的报名信息，有 $m$ 个询问，第 $i$ 个询问给出 $c_i$，求只收到前 $c_i$ 位选手的报名信息时，补充 $2^k - c_i$ 名选手能力值任意的选手，所有可能获得冠军的人的编号之和，其中 $k$ 需要满足 $2^{k-1} < c_i \le 2^k$。

**题解**：

**小数据（12 分）：$n \le 8$**

由于 $n \le 8$，因此能力值有用的区间只有 $0 \sim 3$，每个询问暴力枚举所有补充选手的能力值即可，因为每次比赛补充的选手不超过 $\frac{n}{2}$，因此枚举的时间复杂度为 $O(4^{\frac{n}{2}}) = O(2^n)$，$2^k$ 参加比赛时单次模拟时间复杂度为 $O(2^k)$，因此总时间复杂度为 $O(n^2 2^n)$。

**特殊性质 A（16 分）：询问的 $c_i$ 均为 2 的幂次**

此时不需要补充人，直接暴力模拟即可。设 $2^{k-1} < n \le 2^k$，则时间复杂度为 $O(2^0 + 2^1 + \cdots + 2^{k-1}) = O(2^k) = O(n)$。

**特殊性质 B（24 分）：所有的 $d_{R,G} = 0$**

每一轮的胜利都只由编号较小的选手决定，对于一组由前 $c_i$ 位选手报名的比赛，设 $2^{k-1} < c_i \le 2^k$，可以先预处理前 $2^{k-1}$ 位选手的胜者，并检查这个胜者能否赢下最后一轮，如果能赢，则冠军只有可能是这位胜者；如果不能赢，则冠军在 $2^{k-1} + 1 \sim 2^k$ 中产生，如果这个区间中左半边（第 $2^{k-1} + 1 \sim 2^{k-1} + 2^{k-2}$ 位选手）的选手全是报名的选手，可以重复这一步。否则说明右半边全是能力值任意的补充选手，同样递归左半边的选手，只要左半边存在补充选手可能成为冠军，则右半边所有选手都有可能成为冠军。

对每组询问自顶向下递归即可，时间复杂度 $O(m \log n)$。

**100 分**

$2^k$ 位选手参加的比赛的赛程实际上就是一颗拥有 $2^k$ 个叶子节点的满二叉树，当然也是线段树。于是可以将问题转化到线段树上进行处理（需要先将 $n$ 扩充到 $2^k$ 再建树）。

先预处理线段树上每一个区间的胜者，以及每一位选手在所有编号大于他的选手能力值为 $0$ 的情况下能比赛到第几轮，采用自底向上的方式处理每一个询问，设有 $c_i$ 位选手参加，如果 $c_i = 2^k$，则没有补充选手，冠军唯一，可以预处理得到。否则，先定位到线段树上第 $c_i + 1$ 位选手所表示的顶点，也就是第一位补充选手的顶点，记录当前区间可能的冠军编号之和 $s$，以及冠军信息 $f$，如果存在补充选手可能成为冠军则 $f = -1$，否则容易证明区间内只有唯一的报名选手为冠军，此时令 $f$ 表示这位选手的能力值。之后自底向上处理，分当前是作为编号较小/较大的选手、编号较小/较大的选手为擂主共四种情况讨论：

- 当前为编号较小的选手，编号较小的选手为擂主。如果 $f = -1$，则此时必然存在方案使得当前选手输或者赢，更新 $s$ 即可（加上编号较大选手的编号之和，后面类似）。如果 $f \ne -1$，此时如果能赢，则无事发生考虑下一轮即可；如果输，则编号较大的选手（必然都是补充选手）都能赢下一轮，更新 $s$，$f$ 更新为 $-1$。
- 当前为编号较小的选手，编号较大的选手为擂主。同样擂主一定都是补充选手，必然存在方案输或者赢，更新 $f$ 为 $-1$，再更新 $s$ 即可。
- 当前为编号较大的选手，编号较小的选手为擂主。此时编号较小的选手都是报名选手，因此胜者是唯一确定的，此时只需要检查其能否赢下这一轮即可，如果不赢则无事发生，否则更新 $f$ 为其能力值，如果这个能力值能夺冠，则更新 $s$ 为这个人的编号，否则更新 $s$ 为 $0$。
- 当前为编号较大的选手，编号较大的选手为擂主。如果 $f = -1$，则存在方案输也存在方案赢，检查编号较小的胜者有没有可能夺冠即可，如果有可能，则更新 $s$ 加上这个选手的编号，如果不能则无事发生。如果 $f \ne -1$，同样检查能否赢下一轮。

其中检查某个选手能否夺冠可以通过「每一位选手在所有编号大于他的选手能力值全为 $0$ 的情况下能比赛到第几轮」得到，如果轮次大于等于 $k$，则能夺冠，否则不能。

最后 $s$ 为所求。单次询问 $O(\log n)$，总时间复杂度为 $O(m \log n)$，可以获得 68 ~ 100 分。

**100 分（正解）**

自底向上做很难不带 $\log$，所以我们只能采取自顶向下的方式获取每个前缀的答案。和之前自底向上的处理方式一样，当我们递归到线段树代表 $c_i + 1$ 的叶子节点时获取 $c_i$ 对应的答案。

当补充后参赛选手人数为 $2^k$ 时，对应原来的参赛人数在 $2^{k-1} + 1 \sim 2^k$ 之间，这些前缀对应线段树的叶子节点 $2^{k-1} + 1 \sim 2^k$，注意到 $2^{k-1} + 1$ 这个点不是很好涵盖，不过还好，它对应参赛人数为 $2^k$ 时的答案，这个我们可以是 $O(1)$ 得到的，而 $2^{k-1} + 1 \sim 2^k$ 部分叶子节点刚好在同一棵子树内，因此我们尝试递归这颗子树来获取答案。

考虑线段树代表 $1 \sim 2^k$ 的顶点，其左区间为 $1 \sim 2^{k-1}$，右区间为 $2^{k-1} + 1 \sim 2^k$，当补充后参赛人数为 $2^k$ 时会对到这个顶点，左区间全部都是报名选手，右区间有部分报名选手以及部分补充选手。考虑决策，如果左区间（编号较小的选手）是擂主，因为左区间的参赛选手是确定的，所以我们可以直接知道决策的胜负，如果左区间的选手胜利，那么右区间，也就是 $c_i$ 在 $2^{k-1} + 1 \sim 2^k - 1$ 时，不论补充选手能力值如何，都是左区间的选手获得唯一冠军，直接赋值即可；如果左区间的选手失败，那么冠军为右区间对应的胜者，尝试使用递归解决问题。而如果右区间的选手是擂主，此时因为右区间存在补充选手，因此情况会变得复杂，不过还是抓住左区间的胜者是确定的这件事，可以将这个条件变成限制：如果右区间的胜者为报名选手且能力值小于 $k$，或者存在右区间的胜者为补充选手，则左区间的胜者可以是冠军。在接下来我们将围绕这个限制进行解题。

递归中，我们需要维护一个数组 $vt$ 以及一个量 $rd$，表示如果递归区间胜者能力值为 $i < rd$，则冠军为 $vt_{i+1}$，否则冠军为递归区间胜者。分编号较小（左区间）/较大（右区间）的选手为擂主两种情况讨论：

- 编号较小的选手为擂主。
  - （右区间冠军计算）此时擂主是确定的，擂主是否胜利也是确定的，继续分类讨论：如果擂主胜利，那么当前区间不论右区间选手如何，胜者都是左区间胜者，查表 $vt$ 即可直到当前区间冠军，区间赋值即可。如果擂主失败，则冠军只与右区间有关，递归即可。
  - （左区间冠军计算）此时右区间都是补充选手，考虑将左区间胜者能力值转化为限制：如果左区间胜者能力值不超过当前轮次，则右区间的补充选手都可能成为冠军。将这个限制写进 $vt$ 中递归即可。
- 编号较大的选手为擂主。
  - （右区间冠军计算）同样考虑将左区间胜者转化为限制之后递归：分左区间胜者能力值与 $rd$ 的关系讨论。如果能力值大于等于 $rd$ 则说明只有擂主输了左区间就可以成为冠军，因此限制为如果当前区间胜者为补充选手或者为能力值小于当前轮次的报名选手，则左区间胜者可以成为冠军，写进 $vt$ 中递归即可。如果其能力值小于 $rd$，此时即使左区间输了，他也不能成为冠军，但是他之后能赢一些场次从而迫使一部分选手不能成为冠军，同样修改 $vt$ 之后递归即可。
  - （左区间冠军计算）右区间都是补充选手，这也就说明 $vt$ 表中的所有选手都可以成为冠军，因此此时相当于是区间加法，然后清空 $vt$ 表（但不能清空 $rd$，因为 $rd$ 对左区间内选手能否成为冠军的限制依旧有效）递归即可。

精细地维护 $vt$ 表即可做到 $O(Tn)$ 预处理出所有答案，然后 $O(1)$ 询问，总时间复杂度为 $O(T(n + m))$，可以获得 100 分。

**易错点**：
- 需要先把 $n$ 向上扩充到 $2$ 的幂 $t$ 再建完全二叉树（线段树），叶子节点的 $r$、$id$、$lp$、$rp$、$sum$ 定义要与轮次、区间一一对应。（整理）
- 递归回溯时 $rd$、$st$、$vt$ 状态要恢复到进入该层前的值（`trd`、`tst`），且用完后清空 `vt[r[i]]`。（整理）

**参考代码**（转写自原文标程截图，已本地编译验证）：

```cpp
#include <bits/stdc++.h>

using LL = long long;

const int N = 1 << 18 | 7;
const int M = 18;

int n, m, t, aa[N], a[N], c[N];
int b[N], r[N], id[N], lp[N], rp[N];
LL sum[N], ans[N];
char s[M][N];

void build() {
    for(int i = 0; i < t; ++i) {
        r[i + t] = 0;
        id[i + t] = i;
        b[i + t] = i + 1;
        sum[i + t] = lp[i + t] = rp[i + t] = i + 1;
    }
    for(int i = t - 1; i >= 1; --i) {
        r[i] = r[i << 1] + 1;
        id[i] = id[i << 1] >> 1;
        lp[i] = lp[i << 1];
        rp[i] = rp[i << 1 | 1];
        sum[i] = sum[i << 1] + sum[i << 1 | 1];
        if(s[r[i]][id[i]] == '0')
            b[i] = a[b[i << 1]] >= r[i] ? b[i << 1] : b[i << 1 | 1];
        else
            b[i] = a[b[i << 1 | 1]] >= r[i] ? b[i << 1 | 1] : b[i << 1];
    }
}

LL vt[N], st;
int rd;
void dfs(int i, LL ss, int zl) {
    if(i >= t) {
        ans[i - t] = st + ss + lp[i];
        return ;
    }
    LL trd = rd, tst = st;
    if(s[r[i]][id[i]] == '0') {
        if(b[i] == b[i << 1]) {
            LL v = a[b[i]] >= rd ? b[i] : a[b[i]] + 1 >= zl ? 0 : vt[a[b[i]] + 1];
            std::fill(ans + lp[i << 1 | 1] - 1, ans + rp[i << 1 | 1], v + ss);
            // 转写修正：原截图此处漏了左半区（前缀落在左子树内）的递归
            rd = std::max(rd, r[i]);
            st += sum[i << 1 | 1];
            vt[r[i]] = st;
            dfs(i << 1, ss, zl);
        }
        else {
            vt[r[i]] = vt[r[i] + 1];
            dfs(i << 1 | 1, ss, zl);
            rd = trd, st = tst;
            rd = std::max(rd, r[i]);
            st += sum[i << 1 | 1];
            vt[r[i]] = st;
            dfs(i << 1, ss, zl);
        }
    }
    else {
        vt[r[i]] = 0;
        st = 0;
        dfs(i << 1, ss + sum[i << 1 | 1] + tst, r[i]);
        st = tst, rd = trd;
        if(a[b[i << 1]] >= rd) {
            rd = std::max(rd, r[i]);
            vt[r[i]] = b[i << 1];
            st += b[i << 1];
            dfs(i << 1 | 1, ss, zl);
        }
        else {
            int tp = std::max(r[i], a[b[i << 1]]) + 1;
            vt[r[i]] = tp >= zl ? 0 : vt[tp];
            dfs(i << 1 | 1, ss, zl);
        }
    }
    vt[r[i]] = 0;
    rd = trd, st = tst;
}

void solve() {
    build();
    for(int i = 1; i < t; i <<= 1)
        if(s[r[i]][id[i]] == '0')
            if(b[i] == b[i << 1])
                std::fill(ans + lp[i << 1 | 1] - 1, ans + rp[i << 1 | 1], b[i]);
            else {
                vt[r[i]] = 0;
                rd = st = 0;
                dfs(i << 1 | 1, 0, 20);
            }
        else {
            rd = r[i];
            st = vt[r[i]] = b[i << 1];
            dfs(i << 1 | 1, 0, 20);
        }
    LL val = 0;
    for(int i = 1, x; i <= m; ++i) {
        for(x = 0; (1 << x) < c[i]; ++x) ;
        LL v = (1 << x) == c[i] ? b[t / c[i]] : ans[c[i]];
        //printf("%lld ", v);
        val ^= i * v;
    }
    printf("%lld\n", val);
}

int main() {

    freopen("arena.in", "r", stdin);
    freopen("arena.out", "w", stdout);

    scanf("%d%d", &n, &m);
    for(int i = 1; i <= n; ++i)
        scanf("%d", &aa[i]);
    for(int i = 1; i <= m; ++i)
        scanf("%d", &c[i]);
    for(t = n; t & (t - 1); t += t & -t) ;
    for(int i = 1; (1 << i) <= t; ++i)
        scanf("%s", s[i]);

    int cases;
    scanf("%d", &cases);

    while(cases--) {
        int x[4];
        scanf("%d%d%d%d", &x[0], &x[1], &x[2], &x[3]);
        for(int i = 1; i <= n; ++i)
            a[i] = aa[i] ^ x[i & 3];
        solve();
    }

    return 0;
}
```

**验证**：编译零错误；官方样例 2 组输出全部一致。**含一处转写修正**——原截图漏掉了「右区间选手为擂主且擂主胜利」分支下对左子树的递归，已补回（代码内标注 `// 转写修正`）。

### T1 密码锁（lock）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P9752 |
| 核心考点 | 枚举 |
| 难度 | 普及− |
| 一句话结论 | 直接枚举全部 $10^5$ 个候选正确密码，逐个判断能否「一次转动」得到给定的全部 $n$ 个状态。 |

**题目大意**：小 Y 有一把五个拨圈的密码锁，每个拨圈上是 $0\sim 9$ 的数字，且是循环的（即 $9$ 拨动一个位置后可以变成 $0$ 或 $8$）。锁车方式是：从正确密码开始随机转动密码锁仅一次，每次以某个幅度仅转动一个拨圈，或者同时转动两个相邻的拨圈；同时转动两个相邻拨圈时幅度相同（例如可以把 $00115$ 转成 $11115$，但不会转成 $12115$）。小 Y 记下了锁车后密码锁的 $n$ 个状态，且这 $n$ 个状态都不是正确密码。问有多少种可能的正确密码，使得每个正确密码都能按照该锁车方式产生这全部 $n$ 个状态。数据范围 $1 \le n \le 8$；特殊性质 A：保证所有正确密码都可以通过仅转动一个拨圈得到给出的 $n$ 个状态。

**题解**：

- **部分分（$n=1$）**：输出样例（$81$）即可。
- **满分做法**：枚举所有可能的密码，然后判断这 $n$ 个状态是否都可以由它得到即可。考虑计算需要花费的时间：密码共有 $10^5$ 个，每个密码通过转动可以得到 $81$ 种不同的状态，因此需要处理的状态共 $8.1\times10^6$ 个，所以完全可以在 $1$ 秒内运行完成。

**复杂度**：枚举 $10^5$ 个候选密码，每个密码生成 $81$ 个可达状态并与输入的 $n$ 个状态比对，总运算量约 $8.1\times10^6$（原文指出可在 $1$ 秒内完成）。

**易错点**（整理）：
1. 转动幅度有 $9$ 种（不含幅度 $0$）。单个拨圈可任选 $1$ 个：$5\times9=45$ 种；两个相邻拨圈同幅度同方向：$4\times9=36$ 种；合计恰好 $81$ 种，三者对不上说明枚举漏了情况。
2. 两个拨圈必须是**相邻**的（只有 $1\text{-}2,2\text{-}3,3\text{-}4,4\text{-}5$ 四组），且必须转动**相同幅度、相同方向**，不能只转其中一个。
3. 判断的是「所有 $n$ 个状态都能由**同一个**正确密码一次转出」，而不是分别判断每个状态的可达密码数再相加。

**参考代码**（NOI 风格；本仓库补写）：

```cpp
// CSP-S 2023 T1 密码锁 (lock)
// 题意：5 个 0~9 的循环拨圈，从正确密码出发"仅转动一次"（转一个圈，或同时同幅度
//       转两个相邻圈），记下了 n 个结果状态，问有多少种可能的正确密码能产生全部 n 个状态。
//
// 做法：枚举 10^5 个候选密码；对每个候选枚举全部 81 种转动
//       5 个单圈 x 9 种幅度 = 45，4 组相邻双圈 x 9 种幅度 = 36，共 81 种，
//       用位掩码记录"这 81 个结果覆盖了输入的哪几个状态"，全覆盖即答案 +1。
// 复杂度：O(10^5 * 81)，约 8.1e6 次操作。
#include <bits/stdc++.h>
using namespace std;

static int n;
static const int PW[5] = {10000, 1000, 100, 10, 1};
static int maskOfState[100000];      // 状态编码(0..99999) -> 属于输入的哪些行(位掩码)
static int mvA[81], mvB[81], mvD[81];// 第 k 种转动：拨动 mvA[k](若 mvB[k]>=0 则同时拨动它)，幅度 mvD[k]

int main() {
    freopen("lock.in", "r", stdin);
    freopen("lock.out", "w", stdout);
    if (scanf("%d", &n) != 1) return 0;
    for (int i = 0; i < n; i++) {
        int code = 0;
        for (int j = 0; j < 5; j++) { int x; scanf("%d", &x); code = code * 10 + x; }
        maskOfState[code] |= 1 << i;     // 同一状态可能出现多次
    }

    int cnt = 0;
    for (int j = 0; j < 5; j++)          // 只转一个拨圈：5 * 9 = 45
        for (int d = 1; d <= 9; d++) { mvA[cnt] = j; mvB[cnt] = -1; mvD[cnt] = d; cnt++; }
    for (int j = 0; j < 4; j++)          // 同时转相邻两个拨圈（同幅度同方向）：4 * 9 = 36
        for (int d = 1; d <= 9; d++) { mvA[cnt] = j; mvB[cnt] = j + 1; mvD[cnt] = d; cnt++; }
    // 此处 cnt == 81

    const int full = (1 << n) - 1;
    int ans = 0, dg[5];
    for (int code = 0; code < 100000; code++) {
        int t = code;
        for (int j = 4; j >= 0; j--) { dg[j] = t % 10; t /= 10; }
        int got = 0;
        for (int k = 0; k < 81; k++) {
            int nc = code;
            int p = mvA[k], v = (dg[p] + mvD[k]) % 10;   // 循环拨动
            nc += (v - dg[p]) * PW[p];
            if (mvB[k] >= 0) {
                p = mvB[k]; v = (dg[p] + mvD[k]) % 10;
                nc += (v - dg[p]) * PW[p];
            }
            got |= maskOfState[nc];
            if (got == full) { ans++; break; }            // 提前退出
        }
    }
    printf("%d\n", ans);
    return 0;
}
```

**验证**：样例 1 通过；另与两个独立实现随机对拍 60 组一致（本机复跑），子任务更大规模复跑 2500 组亦全部一致。

### T2 消消乐（game）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P9753 |
| 核心考点 | 字符串（栈消除）、性质推导、前缀状态维护 |
| 难度 | 提高 |
| 一句话结论 | 记 $p(i)$ 为「以 $i$ 开头的最短可消除子串右端点」，则答案为 $\sum_i\big(f(p(i)+1)+1\big)$；用「$g(i)$ 与 $g(p(i)+1)$ 只差一处」的性质可在 $O(n)$ 内求出所有 $p(i)$。 |

**题目大意**：小 L 在玩一个一维的消消乐，一次只能消除两个相邻的元素。给定一个长度为 $n$、仅由小写字母构成的字符串 $s$，称一个字符串是**可消除**的当且仅当可以通过若干次操作把它变成空串，其中每次操作可以删除两个相邻的相同字符、删后剩余字符串拼接在一起。求 $s$ 的所有非空连续子串中有多少个是可消除的。数据范围 $1 \le n \le 2\times10^6$；特殊性质 A：字符串中的每个字符独立等概率地从字符集中选择；特殊性质 B：字符串仅由 `a` 和 `b` 构成。

**题解**：

- **部分分（$n \le 800$）**：$O(n^2)$ 枚举每个子串，并在 $O(n)$ 的时间内判断其是否可消除。判定的关键是：遇到两个相邻的相同字符可以直接删除它们，用栈维护即可——对每个字符，若与栈顶字符相同则弹出栈顶，否则将字符入栈；由于若与栈顶不同则不可能进行任何消除，所以单次 $O(n)$ 判定正确。期望得到 $35$ 分。
- **发掘性质**：用 $s[l:r]$ 表示字符串 $s$ 第 $l$ 个字符到第 $r$ 个字符构成的子串。若 $s[l:r]$ 和 $s[l:p]\ (p<r)$ 都是可消除的，则 $s[p+1:r]$ 是可消除的。
  **证明**：考虑使用栈 $O(n)$ 判断的过程。由于 $s[l:p]$ 是可消除的，因此当模拟 $s[l:r]$ 时，考虑完第 $p$ 个字符后栈必然为空，因此 $s[p+1:r]$ 会从空栈开始；而 $s[l:r]$ 可消除，因此 $s[p+1:r]$ 可消除。
- **部分分（$n \le 8000$）**：上述性质告诉我们：虽然从 $i$ 开始的子串有很多都是可消除的，但我们只需要关注**长度最小**的那个就可以了。因为如果 $s[i:j]$ 和 $s[i:k]\ (j<k)$ 都可消除，那么 $s[i:k]$ 可以拆成 $s[i:j]$ 和 $s[j+1:k]$ 这两个可消除的子串，然后使用计数方法进行统计。
  因此记 $p(i)$ 表示 $s[i:j]$ 是可消除的最小的 $j$。当 $n \le 8000$ 时，$p(i)$ 可以使用栈暴力在 $O(n)$ 的时间内计算（对每个 $i$ 从 $i$ 开始扫一遍）。
  最后考虑计数，设 $f(i)$ 表示 $s$ 从 $i$ 开始有多少个子串是可消除的。则这些串可以分为两类：一类是 $s[i:p(i)]$，共一个；另一类是 $s[i:k]\ (p(i)<k)$，由性质可拆成 $s[p(i)+1:k]$，共 $f(p(i)+1)$ 个。最后总答案为
  $$f(1)+f(2)+\cdots+f(n)$$
  这样就在 $O(n)$ 的时间内完成了计数，总复杂度 $O(n^2)$。
- **快速计算 $p(i)$，得到正解**：如果 $s_i = s_{i+1}$，则显然 $p(i) = i+1$；下面考虑 $s_i \ne s_{i+1}$ 的情况。
  考虑到 $s[i+1:p(i)-1]$ 是可消除的，并且 $s_{p(i)} = s_i$，因此可以设 $g(i,c)$ 表示满足 $s[i:j]$ 是可消除的、并且满足 $s_{j+1} = c$ 的最小的 $j$，则不难发现 $p(i) = g(i+1, s_i)$。
  问题归结为如何快速计算 $g(i,c)$。由于 $s[i:p(i)]$ 可消除，因此对于任意的 $k$，如果 $s[p(i)+1:k]$ 可消除，则 $s[i:k]$ 可消除。考察 $g(i,c)$ 与 $g(p(i)+1,c)$ 的差异，不难发现：当 $c \ne s_{p(i)+1}$ 时 $g(i,c) = g(p(i)+1,c)$；当 $c = s_{p(i)+1}$ 时 $g(i,c) = p(i)+1$。因此 $g(i)$ 与 $g(p(i)+1)$ **只有一处差别**，而 $s$ 仅包含小写字母，所以可以对每个 $c$ 遍历来更新 $g(i,c)$。
  设 $\Sigma$ 表示字符集大小，这里只有小写字母，因此 $\Sigma = 26$。时间复杂度为 $O(n\Sigma)$。
- **还可以更快**：由于 $g(i,*)$ 与 $g(p(i)+1,*)$ 只有一处差别，由性质我们可以得到一个更加强大的结论：对于任意的 $i \ne j$ 都满足 $p(i) \ne p(j)$。
  **证明**：假设 $p(i) = p(j) = k,\ i<j$，则 $s[i:k]$ 和 $s[j:k]$ 都可消除，于是 $s[i:j+1]$ 可消除，与 $p(i)$ 的定义矛盾。
  因此 $g(i)$ 可以直接在 $g(p(i)+1,*)$ 上对那唯一的一处不同做修改得到（即共享同一份状态、退出时再撤销修改）。因此对于这一题，时间复杂度可以做到 $O(n)$；如果将题目中的 $\Sigma$ 修改得更大，则可以使用 `map` 做到 $O(n\log\Sigma)$ 的时间复杂度。

**复杂度**：$O(n)$（字符集固定为 $26$ 时可做到线性；一般字符集用 `map` 为 $O(n\log\Sigma)$）。

**易错点**（整理）：
1. $p(i)$ 是**闭区间**右端点，计数递推为 $f(i) = 1 + f(p(i)+1)$，写成 $f(p(i))$ 会重复计数。
2. $g(i,c)$ 中的 $c$ 指的是**右端点右侧**那个字符 $s_{j+1}$，转移要区分 $c = s_{p(i)+1}$ 与 $c \ne s_{p(i)+1}$ 两种情形；$p(i)=n$ 时该位置不存在，必须特判。
3. 两条加速性质（「只有一处差别」与「$p(i)$ 两两不同」）是压 $\Sigma$ 和压空间的关键；直接对每个 $i$ 复制一份长度 $26$ 的状态在 $n = 2\times10^6$ 时存储代价很大。

**参考代码**（NOI 风格；本仓库补写）：

```cpp
// CSP-S 2023 T2 消消乐 (game)
// 题意：n 长的字符串，每次可删掉两个相邻相同字符，问有多少个非空连续子串可被删空。
//
// 做法（栈状态法，O(n)）：
//   "相邻相同即消"就是自由群意义下的规约，规约结果是唯一的。从左往右用一个栈模拟：
//   当前字符与栈顶相同则弹栈，否则入栈。子串 s[j..i] 可消除  <=>  处理完前缀 j-1 与
//   处理完前缀 i 后的"栈状态"完全相同。
//   于是答案 = sum_i ( 之前出现过多少次与 state_i 相同的栈状态 )。
//
//   栈是"持久化"的：每个状态就是一条从根(空栈)往下 push 出来的链，因此状态可用节点编号
//   表示，弹栈就是回到父节点。两个节点内容相同当且仅当 (父节点, 字符) 相同，用哈希表
//   去重即可保证"相同内容 = 相同编号"（例如 "aaa" 中第 1、3 个字符都会 push 出内容为
//   [a] 的状态）。
// 复杂度：O(n)，内存约 80 MB（n = 2e6）。
#include <bits/stdc++.h>
using namespace std;

static const int MAXN = 2000005;
static int n;
static char s[MAXN];

static int par[MAXN];        // 持久化栈中每个节点的父节点，0 表示空栈
static char topCh[MAXN];     // 该节点代表的栈的栈顶字符
static int cntOfState[MAXN]; // 每个栈状态被访问过多少次
static int cur = 0;          // 当前栈状态编号

// ---- 开放寻址哈希表：key = (父状态, 字符) -> 状态编号 ----
static const int HSZ = 1 << 22;          // 4.19M，负载 < 0.5
static int htab[HSZ];                    // 存 编号+1，0 表示空

static inline unsigned hsh(unsigned long long k) {
    k *= 0x9E3779B97F4A7C15ULL;
    return (unsigned)(k >> 40) & (HSZ - 1);
}

// 返回 (父状态 p, 字符 c) 对应的状态编号；不存在则新建
static inline int getState(int p, int c) {
    unsigned long long key = (unsigned long long)p * 26u + (unsigned)c;
    unsigned idx = hsh(key);
    while (true) {
        int id = htab[idx];
        if (id == 0) {                       // 空槽：新建节点
            static int tot = 0;
            ++tot;
            par[tot] = p;
            topCh[tot] = (char)c;
            htab[idx] = tot + 1;
            return tot;
        }
        --id;
        if (par[id] == p && (int)(unsigned char)topCh[id] == c) return id;
        idx = (idx + 1) & (HSZ - 1);
    }
}

int main() {
    freopen("game.in", "r", stdin);
    freopen("game.out", "w", stdout);

    static char buf[1 << 22];
    size_t len = fread(buf, 1, sizeof(buf), stdin);
    size_t pos = 0;
    auto readInt = [&]() {
        while (pos < len && (buf[pos] < '0' || buf[pos] > '9')) pos++;
        int x = 0;
        while (pos < len && buf[pos] >= '0' && buf[pos] <= '9') x = x * 10 + (buf[pos++] - '0');
        return x;
    };
    n = readInt();
    while (pos < len && (buf[pos] < 'a' || buf[pos] > 'z')) pos++;
    for (int i = 1; i <= n; i++) s[i] = buf[pos++];

    long long ans = 0;
    cntOfState[0] = 1;                        // 空前缀
    for (int i = 1; i <= n; i++) {
        int c = s[i] - 'a';
        if (cur != 0 && (int)(unsigned char)topCh[cur] == c) {
            cur = par[cur];                   // 与栈顶相同 -> 消掉
        } else {
            cur = getState(cur, c);           // 否则入栈
        }
        ans += cntOfState[cur];
        cntOfState[cur]++;
    }
    printf("%lld\n", ans);
    return 0;
}
```

**验证**：样例 1 通过；与独立暴力随机对拍 60 组一致（本机复跑），子任务更大规模复跑 1400 组亦全部一致。

> **与上文解法的关系**：本题解正文走的是 $p(i)/g(i,\cdot)$ 递推路线；标程采用的是**等价的「持久化栈状态」写法**——「相邻相同即消」是自由群意义下的唯一规约，于是 $s[j..i]$ 可消除 $\iff$ 处理完前缀 $j-1$ 与前缀 $i$ 后的栈状态相同，答案即 $\sum_i(\text{state}_i\text{ 此前出现次数})$。两法同为 $O(n)$，代码里用哈希表把「(父状态, 栈顶字符)」映射到规范状态编号，从而用编号相等代替栈内容比较。

### T3 结构体（struct）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P9754 |
| 核心考点 | 模拟（内存布局、地址对齐、递归寻址） |
| 难度 | 提高+/省选− |
| 一句话结论 | 把基本类型也当成「特殊结构体」，结构体记 $\{name, memlist, size, pkz\}$、元素记 $\{name, pos, type\}$，对齐空隙填特殊类型 `non`，操作 3、4 递归下钻，总复杂度 $O(n^2k)$。 |

**题目大意**：模拟一种类 C++ 语言的结构体定义与内存占用。基本类型共 $4$ 种：`byte`、`short`、`int`、`long`，分别占 $1,2,4,8$ 字节。定义结构体**类型**时给出类型名与按序的成员（成员类型 + 名称），成员类型可以是基本类型，也可以是**先前定义过**的结构体类型（定义类型时不占用内存）。对齐规则：基本类型的对齐要求等于其大小；结构体类型的对齐要求等于其成员对齐要求的**最大值**。元素按定义顺序在内存中依次排布且须满足对齐，元素起始地址必须是对齐要求的整数倍。共 $n$ 次操作：$1$ 定义结构体类型（输出「大小 对齐要求」）；$2$ 定义元素（输出起始地址）；$3$ 访问元素 `a.b.c`（输出被访问的**最内层**元素的起始地址）；$4$ 访问内存地址 $addr$（若有基本类型元素占据该地址则按操作 $3$ 的格式输出该元素，否则输出 `ERR`）。数据范围 $1 \le n \le 100$，$1 \le k \le 100$，$0 \le addr \le 10^{18}$，保证任意结构体大小与元素占据的最高地址均不超过 $10^{18}$。

**题解**：

- **部分分（性质 A：没有操作 1）**：没有操作 $1$ 时所有元素都是基本类型，可以考虑使用数组模拟内存（大小不超过 $8n$）。**操作 2**：注意处理内存中的对齐即可。**操作 3**：由于所有类型都是基本类型，定义的时候记录一下就好了。**操作 4**：直接访问内存即可。
- **部分分（性质 B：只有一个操作 1）**：将唯一的结构体当成特殊的基本类型。由于 $k \le 100$，因此内存大小不超过 $800n$，还是可以使用数组模拟。可以标记内存中每个位置的标签（变量名），在定义变量模拟内存分配的时候记录一下，这样操作 3 和操作 4 会好处理一些。需要注意结构体内部的对齐。
- **部分分（性质 C：所有操作 1 中给出的成员类型均为基本类型）**：由于结构体不会嵌套，因此内存大小依旧不会超过 $800n$，写法与性质 B 一致。
- **满分做法：模拟**：由于此题 $n$ 很小，操作 3 和操作 4 最多递归 $n$ 层结构体，每层结构体遍历 $k$ 个变量，时间复杂度仍然只有 $O(n^2k)$，因此可以考虑直接模拟。
  将基础类型看成特殊的结构体，对于每个结构体记录 $\{name, memlist, size, pkz\}$，分别表示结构体名、成员列表、大小、对齐要求。至于因对齐要求产生的空隙，可以填充特殊的类型 `non` 来标记，可以减少一些讨论。对于每个变量记录 $\{name, pos, type\}$，分别表示变量名、内存起始地址以及类型。
  - **操作 1**：新建一个结构体，记录 $\{name, memlist, size, pkz\}$ 即可。
  - **操作 2**：新建一个变量，记录 $\{name, pos, type\}$ 即可。
  - **操作 3**：将字符串看成 $name_1[.name_2[.name_3\dots]]$ 的结构，首先提取 $name_1$，然后在变量列表中暴力寻找起始位置，之后进入递归，每次递归解一层 `.name` 的结构，解到最后一层即可。
  - **操作 4**：首先在变量列表中暴力找到地址 $addr$ 属于哪一个结构体，之后进入递归，最终如果递归到 `non` 则输出 `ERR`，否则输出对应的类型。
  - 补充：实际上如果你的抽象能力足够强，甚至可以将内存也抽象成一个结构体，把内存上定义的变量抽象成表示内存的这个结构体的内容，这样就可以省去对变量的讨论。
- **样例说明（含校注）**：原文样例 $1$ 的解释写作「`short` 类型的成员 `aa` 占据第 $0\sim3$ 字节地址，`int` 类型的成员 `ab` 占据第 $4\sim5$ 字节地址」，与对齐规则及输出 `8 4` 均不符，疑为原文笔误；按规则正确结果应为 `aa` 占第 $0\sim1$ 字节、`ab` 占第 $4\sim7$ 字节，结构体 `a` 大小 $8$、对齐 $4$（**校注**）。

**复杂度**：$O(n^2k)$。

**易错点**（整理）：
1. 结构体的对齐要求是**成员对齐要求的最大值**（不是成员大小的最大值）；元素的起始地址必须能被它自己的对齐要求整除。
2. 地址反查（操作 4）时，对齐留下的「洞」会命中填充的 `non`，此时没有基本类型元素占据该地址，必须输出 `ERR`，不能报错或输出空。
3. 定义结构体**类型**不占用内存，只有定义**元素**才占内存；且所有元素从地址 $0$ 起按定义顺序依次排布，元素之间的对齐也要处理。

**参考代码**（NOI 风格；本仓库补写）：

```cpp
// CSP-S 2023 T3 结构体 (struct)
// 题意：模拟一种类 C++ 语言的结构体：定义类型、定义元素、按名字访问、按地址反查。
//
// 做法：直接模拟内存布局。
//   * 4 种基本类型视作"预先定义好的结构体"，尺寸/对齐分别 1,2,4,8。
//   * 结构体类型记录 {名字, 成员表, 大小, 对齐}；成员记录 {名字, 偏移, 类型}。
//     对齐规则：成员偏移 = 向上取整到该成员对齐要求；结构体大小 = 向上取整到结构体对齐要求
//     （结构体对齐要求 = 成员对齐要求的最大值）。
//   * 操作 3：按 '.' 拆分，先按名字找到顶层元素，再逐层在成员表里查名字并累加偏移。
//   * 操作 4：先找包含该地址的顶层元素，再逐层下钻；某层落在对齐"洞"里（没有成员覆盖）
//     就直接 ERR。
// 复杂度：O(n^2 k)，n,k <= 100，轻松通过。
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;

struct Member {
    string name;
    int type;
    ll off;
};
struct Type {
    string name;
    vector<Member> mem;
    ll size, align;
};
struct Elem {
    string name;
    int type;
    ll pos;
};

static vector<Type> types;              // 0..3 为基本类型 byte/short/int/long
static map<string, int> typeId;
static vector<Elem> elems;
static map<string, int> elemId;
static ll curEnd = 0;                   // 已分配内存的末尾（下一个元素从这里开始找对齐位置）

static inline ll alignUp(ll x, ll a) { return (x + a - 1) / a * a; }

// 把 "x.ba.ab" 按 '.' 切开
static vector<string> split(const string &s) {
    vector<string> res;
    string cur;
    for (char c : s) {
        if (c == '.') { res.push_back(cur); cur.clear(); }
        else cur += c;
    }
    res.push_back(cur);
    return res;
}

int main() {
    freopen("struct.in", "r", stdin);
    freopen("struct.out", "w", stdout);
    ios::sync_with_stdio(false);
    cin.tie(nullptr);

    const char *baseName[4] = {"byte", "short", "int", "long"};
    for (int i = 0; i < 4; i++) {
        Type t;
        t.name = baseName[i];
        t.size = t.align = 1LL << i;   // 1,2,4,8
        typeId[t.name] = (int)types.size();
        types.push_back(t);
    }

    int n;
    cin >> n;
    while (n--) {
        int op;
        cin >> op;
        if (op == 1) {
            string s;
            int k;
            cin >> s >> k;
            Type t;
            t.name = s;
            t.size = 0;
            t.align = 1;
            ll off = 0;
            for (int i = 0; i < k; i++) {
                string ti, ni;
                cin >> ti >> ni;
                int id = typeId[ti];
                if (i > 0) off = alignUp(off, types[id].align);   // 对齐到该成员的要求
                Member m;
                m.name = ni;
                m.type = id;
                m.off = off;
                t.mem.push_back(m);
                off += types[id].size;
                t.align = max(t.align, types[id].align);          // 结构体对齐 = 成员对齐最大值
            }
            t.size = alignUp(off, t.align);                       // 整体补齐
            cout << t.size << ' ' << t.align << '\n';
            typeId[s] = (int)types.size();
            types.push_back(t);
        } else if (op == 2) {
            string ti, ni;
            cin >> ti >> ni;
            int id = typeId[ti];
            Elem e;
            e.name = ni;
            e.type = id;
            e.pos = alignUp(curEnd, types[id].align);             // 元素起始地址对齐
            curEnd = e.pos + types[id].size;
            cout << e.pos << '\n';
            elemId[ni] = (int)elems.size();
            elems.push_back(e);
        } else if (op == 3) {
            string s;
            cin >> s;
            vector<string> p = split(s);
            int ei = elemId[p[0]];
            ll addr = elems[ei].pos;
            int cur = elems[ei].type;
            for (size_t i = 1; i < p.size(); i++) {               // 逐层下钻
                const Type &T = types[cur];
                for (const Member &m : T.mem)
                    if (m.name == p[i]) { addr += m.off; cur = m.type; break; }
            }
            cout << addr << '\n';
        } else {
            ll addr;
            cin >> addr;
            int ei = -1;
            for (size_t i = 0; i < elems.size(); i++)
                if (elems[i].pos <= addr && addr < elems[i].pos + types[elems[i].type].size) {
                    ei = (int)i;
                    break;
                }
            if (ei < 0) { cout << "ERR\n"; continue; }             // 不在任何元素内
            string path = elems[ei].name;
            int cur = elems[ei].type;
            ll off = addr - elems[ei].pos;
            bool ok = true;
            while (types[cur].mem.size() > 0) {                    // 还没到基本类型
                const Type &T = types[cur];
                int found = -1;
                for (const Member &m : T.mem)
                    if (m.off <= off && off < m.off + types[m.type].size) { found = (int)(&m - &T.mem[0]); break; }
                if (found < 0) { ok = false; break; }              // 落在对齐洞里
                const Member &m = T.mem[found];
                path += "." + m.name;
                off -= m.off;
                cur = m.type;
            }
            if (!ok) cout << "ERR\n";
            else cout << path << '\n';
        }
    }
    return 0;
}
```

**验证**：样例 1 通过（注意原文样例解释中的字节区间印错，见上文校注，代码按对齐规则实现）；与独立实现随机对拍 60 组一致（本机复跑）。

### T4 种树（tree）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P9755 |
| 核心考点 | 二分答案、贪心（树上调度）、前缀和 |
| 难度 | 提高+/省选− |
| 一句话结论 | 二分最少天数 $m$，对每棵树算出「最晚可种日 $t_i$」，倒序（从第 $m$ 天往前）贪心安排；令 $t'_i=\min\big(t_i,\min_{u\in son(i)}(t'_u-1)\big)$ 后可去掉优先队列，判定做到 $O(n)$。 |

**题目大意**：给定一棵 $n$ 个结点的树（$1$ 号结点连接森林入口），第 $i$ 块地的树高度至少要长到 $a_i$。每天可以选择一个**未种树且与某个已种树地块直接相邻**的地块，种一棵高 $0$ 的树（若所有地块都已种过，则当天不进行操作），特别地第 $1$ 天只能在 $1$ 号空地种树。对每块地，从被种下当天起每天生长：在第 $x$ 天（$x$ 从整个任务第一天算起），$i$ 号地块的树长高 $\max(b_i + x \times c_i,\ 1)$ 米。求至少多少天能完成任务。数据范围 $1 \le n \le 10^5$，$1 \le a_i \le 10^{18}$，$1 \le b_i \le 10^9$，$0 \le |c_i| \le 10^9$，保证存在方案能在 $10^9$ 天内完成任务。

**题解**：

- **部分分（性质 B：树是一条链，且结点 1 的度数为 1）**：不难发现此时种树的序列是唯一的——第 $i$ 天只能将树种在结点 $i$，因此设 $v_i$ 表示结点 $i$ 的树长到至少 $a_i$ 所需的天数，则答案为 $\max\{v_i+i\}$。
  树的生长曲线有三种：常数列（对应 $c_i=0$）、等差数列（对应 $c_i>0$）、先等差数列后常数列（对应 $c_i<0$）。无论是哪种情况，树每天的高度都是单调递增的，因此可以使用二分答案计算 $v_i$；当然，使用数学方法计算也是可以的。这样就在 $O(n)$ 或者 $O(n\log W)$ 的时间复杂度内完成，其中 $W = 10^9$ 为答案上限。
- **二分答案 + 优先队列**：题目具有明显单调性，因此可以二分答案，将题目变成判定性问题。于是目标是判断能否在 $m$ 天内完成任务。
  由于树生长也具有单调性（累计高度随天数单调递增），因此设 $t_i$ 表示使结点 $i$ 的树至少长到 $a_i$ 高度、最迟需要在哪一天种下去；同样 $t_i$ 可以通过数学方法或者二分答案得到。
  由于要求满足连通的限制，正着做（时间正序）越往后越多结点可能不满足要求，不好处理；考虑**倒过来做**（时间倒序），越往后越多结点满足要求。因此可以从叶子结点开始，按照 $t_i$ 从大到小的顺序贪心地选择种树的时间。由于树结构必须先选儿子再选父亲，因此这个过程可以通过**优先队列**完成（每次取出当前可选的 $t_i$ 最大的结点安排到最靠后的空闲天，儿子选完后再把父亲加入待选队列）。
  复杂度：二分的时间复杂度为 $O(\log W)$，判断需要用优先队列的时间复杂度为 $O(n\log n)$ 或 $O(n\log n + n\log W)$（取决于 $t_i$ 的计算方法）。因此可以在总时间复杂度 $O(n\log n\log W)$ 或 $O(n\log(nW)\log W)$ 下完成此题。
- **二分答案（去掉优先队列）**：虽然使用优先队列已经足够通过这个题了（但是可能被卡常），不过可以进一步思考能否将优先队列也去掉，答案是可以的。
  依旧倒序做。使用优先队列的原因：因为树结构，必须先选儿子再选父亲，儿子选完之后将父亲结点加入待选队列。那有没有办法突破树结构的限制呢？注意到两点：
  1. 越往后选越有可能满足要求；
  2. 父结点必须晚于子结点选。

  而使用优先队列的目的是为了找到 $t_i$ 最大的结点，那么一个自然的想法是让父结点的 $t_i$ 比所有子结点的都要小就可以了，也就是令
  $$t'_i = \min\Big(t_i,\ \min_{u \in son(i)}(t'_u - 1)\Big)$$
  这样我们就可以无视树结构，直接贪心选最大的（把结点按 $t'$ 从大到小依次安排到第 $m, m-1, \dots$ 天）了，自然也就不需要优先队列了。实际上此时满足条件当且仅当对于任意的 $j$ 都满足：满足 $t'_i \ge j$ 的 $i$ 的数量不超过 $j$，这可以自然地使用**前缀和**做到线性。
  综上所述，我们可以去掉优先队列，达成最快 $O(n\log W)$ 的时间复杂度。当然如果 $t_i$ 也二分的话时间复杂度会变成 $O(n\log^2 W)$。

**复杂度**：$O(n\log W)$（$t_i$ 用数学方法直接算）或 $O(n\log^2 W)$（$t_i$ 也二分）。

**易错点**（整理）：
1. 前向贪心（每天种「最晚可种日 $t_i$ 最小」的结点）存在反例，必须**倒序**贪心：从第 $m$ 天往前，每次选当前可种结点中 $t_i$ 最大者。
2. $t_i$ 依赖二分出的天数上限 $m$，判定函数内部必须按当前的 $m$ 重新计算所有 $t_i$，不能复用外层的缓存。
3. 生长公式是**逐日增量** $\max(b_i + x\cdot c_i, 1)$ 米，累计高度是 $x$ 的单调函数；$c_i<0$ 时增量最终被 $1$ 兜底成为「先等差后常数」，求「还需多少天」时不要漏掉这个下界 $1$。

**参考代码**（NOI 风格；本仓库补写）：

```cpp
// CSP-S 2023 T4 种树 (tree)
// 题意：n 个地块连成一棵树，1 号接入口。每天选一个"未种树且与已种树地块相邻"的地块种树
//       （第 1 天只能种 1 号）。第 x 天 i 号地块的树长高 max(b_i + x*c_i, 1) 米，
//       要求每块地的高度 >= a_i，求最少天数。
//
// 做法：二分答案 m + 倒序贪心（去优先队列）。
//   1) 二分天数 m，判定"m 天内能否完成"。
//   2) 对每块地算最晚种植日 t_i：种在第 d 天时，到第 m 天的累计高度为
//        sum_{x=d..m} max(b_i + x*c_i, 1) >= a_i，
//      该和随 d 增大而减小，二分 d 即可（用前缀和公式 O(1) 计算，__int128 防溢出）。
//   3) 树上"父亲必须先于儿子种"（已种集合始终是含根的连通块），于是把父亲的最晚日压到
//      比所有儿子更早：t'_v = min(t_v, min_{u 是 v 的儿子}(t'_u - 1))。
//   4) 此时只需判定：把 t' 从小到大排好依次安排在 1..n 天，是否都有 t'_(k) >= k。
//      等价于对每个 j 都有 #{i : t'_i <= j} <= j，用桶 + 前缀和 O(n) 判定。
// 复杂度：O(n log W log W)，W = 1e9。
#include <bits/stdc++.h>
using namespace std;

typedef long long ll;
typedef __int128 i128;

static const int MAXN = 100005;
static int n;
static ll A[MAXN], B[MAXN], C[MAXN];
static ll qb[MAXN];            // c<0 时，使 b+x*c >= 1 的最大 x
static int head[MAXN], nxt[MAXN << 1], too[MAXN << 1], ecnt;
static int par[MAXN], ord[MAXN], ordN;
static ll tArr[MAXN], tp[MAXN];
static int cntArr[MAXN + 2];

static inline void addEdge(int u, int v) {
    too[++ecnt] = v; nxt[ecnt] = head[u]; head[u] = ecnt;
}

// sum_{x=1..y} max(b_i + x*c_i, 1)
static inline i128 pref(int i, ll y) {
    if (y <= 0) return 0;
    ll b = B[i], c = C[i];
    if (c >= 0) return (i128)b * y + (i128)c * y * (y + 1) / 2;
    ll q = qb[i];
    if (y <= q) return (i128)b * y + (i128)c * y * (y + 1) / 2;
    i128 base = (i128)b * q + (i128)c * q * (q + 1) / 2;   // 前 q 天按 b+x*c 累加
    return base + (i128)(y - q);                           // 之后每天固定 +1
}

static bool check(ll m) {
    for (int i = 1; i <= n; i++) {
        i128 tot = pref(i, m);
        if (tot < A[i]) return false;                      // 第 1 天就种也长不到
        if ((i128)max(B[i] + m * C[i], 1LL) >= A[i]) {     // 第 m 天当天种就够 -> t_i = m
            tArr[i] = m;
            continue;
        }
        ll lo = 1, hi = m, best = 1;
        while (lo <= hi) {                                 // 找最大的 d 使 sum_{x=d..m} >= a_i
            ll mid = (lo + hi) >> 1;
            if (tot - pref(i, mid - 1) >= A[i]) { best = mid; lo = mid + 1; }
            else hi = mid - 1;
        }
        tArr[i] = best;
    }

    for (int k = ordN - 1; k >= 0; k--) {                  // 自底向上压 t'
        int v = ord[k];
        ll tv = tArr[v];
        for (int e = head[v]; e; e = nxt[e]) {
            int u = too[e];
            if (u == par[v]) continue;
            if (tp[u] - 1 < tv) tv = tp[u] - 1;
        }
        tp[v] = tv;
        if (tv <= 0) return false;                         // 期限早于第 1 天
    }

    memset(cntArr, 0, sizeof(int) * (n + 2));
    for (int i = 1; i <= n; i++) {
        int k = (tp[i] > n) ? n + 1 : (int)tp[i];          // 期限 > n 的永远不会成为瓶颈
        cntArr[k]++;
    }
    int s = 0;
    for (int j = 1; j <= n; j++) {
        s += cntArr[j];
        if (s > j) return false;                           // 超过 j 个地块期限 <= j
    }
    return true;
}

int main() {
    freopen("tree.in", "r", stdin);
    freopen("tree.out", "w", stdout);
    if (scanf("%d", &n) != 1) return 0;
    for (int i = 1; i <= n; i++) {
        scanf("%lld %lld %lld", &A[i], &B[i], &C[i]);
        if (C[i] < 0) qb[i] = (B[i] - 1) / (-C[i]);
    }
    for (int i = 1; i < n; i++) {
        int u, v;
        scanf("%d %d", &u, &v);
        addEdge(u, v);
        addEdge(v, u);
    }

    // BFS 定根（1 号），得到父亲与层序
    ord[ordN++] = 1;
    par[1] = 0;
    for (int i = 0; i < ordN; i++) {
        int v = ord[i];
        for (int e = head[v]; e; e = nxt[e]) {
            int u = too[e];
            if (u == par[v]) continue;
            par[u] = v;
            ord[ordN++] = u;
        }
    }

    ll lo = n, hi = 1000000000LL;      // 至少 n 天；题目保证 1e9 天内可行
    while (lo < hi) {
        ll mid = (lo + hi) >> 1;
        if (check(mid)) hi = mid;
        else lo = mid + 1;
    }
    printf("%lld\n", lo);
    return 0;
}
```

**验证**：样例 1 通过；与小规模暴力（搜索最小天数）随机对拍 60 组一致（本机复跑），子任务更大规模复跑 400 组亦全部一致。

### T1 假期计划（holiday）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P8817 |
| 核心考点 | 图论（BFS 最短路）、贪心（前 k 大预处理）、枚举 |
| 难度 | 提高+/省选− |
| 一句话结论 | 预处理每个点「距离 ≤ k+1 且离 1 号点 ≤ k+1」的点权前三大，再枚举 $B,C$ 拼出 $A,D$。 |

**输入格式**（补写标程时实测确认）：第一行 $n,m,k$；第二行 $n-1$ 个整数，依次是 $2 \sim n$ 号点的点权（**1 号点没有点权**）；随后 $m$ 行每行两个整数 $u,v$，表示一条无向边。

**题目大意**：给定 $n$ 个点 $m$ 条边的无向图，每个点有点权。选 4 个互不相同的点 $A,B,C,D$，从 1 号点出发完成行程 $1 \to A \to B \to C \to D \to 1$，每段行程途中可以经过任意点但最多走 $k+1$ 条边。求满足条件的四个点的最大点权和。$n \le 2500$。

**题解**：

由于 $n \le 2500$，可以从每个点出发做一次 BFS 求出两两间最短路；若两点最短路 $\le k+1$，它们就能在行程中相邻出现（记作这两个点「可达」）。

- **40 分（$n \le 20$）**：四层循环枚举 $A,B,C,D$，再验证相邻关系是否都成立。
- **70 分**：只枚举 $A,B,C$。$D$ 可用贪心直接确定：$D$ 必须与 $C$ 可达且与 1 号点可达，所以 $D$ 取满足条件的点中权值最大者。**注意去重**：权值最大的点可能是 $A$ 或 $B$，此时要退到第二大；第二大若仍冲突则退到第三大。因此需要预处理——对每个点 $i$，求出「与 $i$ 可达且与 1 号点可达」的点中权值的前三大，然后三重循环枚举 $A,B,C$，$D$ 取 $C$ 的前三大之一。
- **100 分**：$A$ 的性质与 $D$ 完全对称（$A$ 与 $B$ 可达、且与 1 号点可达），所以 $A$ 一定是 $B$ 的前三大点之一。于是只枚举 $B,C$ 即可：$A$ 取 $B$ 的前三大、$D$ 取 $C$ 的前三大，再检查四个点是否两两不同（$B$ 与 $C$ 的前三大之间可能重合，需逐一判重）。

**复杂度**：BFS 部分 $O(n(n+m))$，枚举部分 $O(n^2)$；与原文一致，总体 $O(n^2)$（忽略 BFS 的 $m$ 项）。

**易错点**（整理）：
1. 前三大必须按「与 $i$ 可达 **且** 与 1 号点可达」筛选后再排序，漏掉后半条会选到不可行的 $D$。
2. 判重时不能只判 $A \ne D$，$A,D$ 都可能与 $B,C$ 撞点，必须四元判重。
3. BFS 距离门限是 $k+1$ 而不是 $k$。

**参考代码**（NOI 风格；本仓库补写）：

```cpp
// ============================================================================
// CSP-S 2022 T1 假期计划（洛谷 P8817）
// ----------------------------------------------------------------------------
// 题意：n 个点 m 条边的无向图，1 号点是家，2..n 号点是景点（各有分数 a[i]）。
//       选 4 个互不相同的景点 A,B,C,D，使得 1->A->B->C->D->1 每一段都
//       最多转车 k 次（即两点间最短路 <= k+1 条边）。求四景点分数和的最大值。
//
// 做法：
//   1) 从每个点 BFS 一遍，只搜到深度 k+1，得到「可达」关系。
//   2) 对每个点 i，预处理候选点 j：dist(i,j) <= k+1 且 dist(1,j) <= k+1，
//      按分数取前三名 top3[i]。为什么前三名够：A 一定在 top3[B] 里，
//      D 一定在 top3[C] 里，最坏情况下前两名被 B、C 或对方占用，第三名必可行。
//   3) 枚举 B、C（要求可达），枚举 A ∈ top3[B]、D ∈ top3[C]，四元互异即更新答案。
//
// 复杂度：BFS O(n(n+m))，枚举 O(9 n^2)。n <= 2500。
// ============================================================================
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 2505;

int n, m, K;
long long a[MAXN];          // a[i] 仅对 i >= 2 有意义（1 号点是家，没有分数）
vector<int> g[MAXN];
short dist[MAXN][MAXN];     // dist[s][t]：最短路；-1 表示 > K+1 或不可达
int top3[MAXN][3];          // 每个点分数前三的合法候选，0 表示不存在

int main() {
    freopen("holiday.in", "r", stdin);
    freopen("holiday.out", "w", stdout);

    if (scanf("%d %d %d", &n, &m, &K) != 3) return 0;
    for (int i = 2; i <= n; ++i) scanf("%lld", &a[i]);   // 注意只有 n-1 个数
    for (int i = 0; i < m; ++i) {
        int u, v;
        scanf("%d %d", &u, &v);
        g[u].push_back(v);
        g[v].push_back(u);
    }

    const int lim = K + 1;                 // 一段行程最多 lim 条边

    // ---------- 1) 每个点为起点的 BFS（只搜到 lim 层） ----------
    static int q[MAXN];
    for (int s = 1; s <= n; ++s) {
        for (int i = 1; i <= n; ++i) dist[s][i] = -1;
        int head = 0, tail = 0;
        q[tail++] = s;
        dist[s][s] = 0;
        while (head < tail) {
            int u = q[head++];
            if (dist[s][u] == lim) continue;       // 不再往下扩展
            for (int v : g[u]) {
                if (dist[s][v] == -1) {
                    dist[s][v] = (short)(dist[s][u] + 1);
                    q[tail++] = v;
                }
            }
        }
    }

    // ---------- 2) 每个点的前三大候选 ----------
    for (int i = 2; i <= n; ++i) {
        top3[i][0] = top3[i][1] = top3[i][2] = 0;
        for (int j = 2; j <= n; ++j) {
            if (j == i) continue;
            if (dist[i][j] == -1) continue;        // 自己与 j 不可达
            if (dist[1][j] == -1) continue;        // j 与家不可达，当不了 A/D
            // 插入排序维护前三
            for (int t = 0; t < 3; ++t) {
                if (top3[i][t] == 0 || a[j] > a[top3[i][t]]) {
                    for (int p = 2; p > t; --p) top3[i][p] = top3[i][p - 1];
                    top3[i][t] = j;
                    break;
                }
            }
        }
    }

    // ---------- 3) 枚举 B、C ----------
    long long ans = -1;
    for (int B = 2; B <= n; ++B) {
        for (int C = 2; C <= n; ++C) {
            if (B == C) continue;
            if (dist[B][C] == -1) continue;
            for (int x = 0; x < 3; ++x) {
                int A = top3[B][x];
                if (!A) break;
                if (A == C) continue;
                for (int y = 0; y < 3; ++y) {
                    int D = top3[C][y];
                    if (!D) break;
                    if (D == A || D == B) continue;   // 四元判重
                    ans = max(ans, a[A] + a[B] + a[C] + a[D]);
                }
            }
        }
    }

    printf("%lld\n", ans);
    return 0;
}
```

**验证**：编译零错误；与独立暴力（$n\le8$ 四层枚举）随机对拍 200 组 + 中规模 40 组，全部一致（本机独立复跑）。⚠️ 2022 年官方测试数据未收录，正确性**仅由对拍支撑**，未经官方数据检验。

### T2 策略游戏（game）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P8818 |
| 核心考点 | 贪心、博弈（对手最优反应）、ST 表 / 线段树 |
| 难度 | 提高+/省选− |
| 一句话结论 | 先手只会取区间内四类数之一（最大/最小非负数、最大/最小负数），后手按先手符号取区间最值。 |

**题目大意**：给定数组 $A,B$。每轮给定 $A$ 的一个区间 $[l_1,r_1]$ 与 $B$ 的一个区间 $[l_2,r_2]$：先手在 $A$ 区间中选一个数 $x$，后手在 $B$ 区间中选一个数 $y$（各自知道对方的最优策略），本轮得分 $x \cdot y$。先手想最大化得分、后手想最小化得分，求最优策略下的得分。多轮询问。

**题解**：

先固定先手的选择 $x$：后手必然在 $B$ 区间里选使 $x \cdot y$ 最小的 $y$。先手选数时能预见这一反应。

- **40 分**：直接枚举先手选的 $x$，再扫一遍区间求后手最优反应，即「每行最小值中的最大值」。复杂度 $O(nmq)$。若满足特殊性质 2，复杂度降为 $O(nq)$。
- **65 分（特殊性质 1：$A_i,B_i>0$）**：后手一定取区间最小值，先手一定取区间最大值。用 ST 表或线段树维护 $A$ 的区间最大值、$B$ 的区间最小值，答案即两者相乘。
- **100 分**：把「$A_i,B_i>0$ 取区间最值」的结论推广——
  - 若先手取正数，后手一定取区间**最小**值；
  - 若先手取负数，后手一定取区间**最大**值。

  再据此讨论先手：

  1. 先手取正数：当 $B$ 区间最小值为正时，先手取**最大的正数**；当 $B$ 区间最小值为负时，先手取**最小的正数**（有 0 取 0）。
  2. 先手取负数：当 $B$ 区间最大值为正时，先手取**最小的负数**；当 $B$ 区间最大值为负时，先手取**最小的负数**。

  因此先手只会取区间中四种数之一：最小的负数、最大的负数、最小的非负数、最大的非负数；后手只会根据先手所选数的符号取区间最大值或最小值。用 ST 表维护 $A$ 的「区间最大负数 / 区间最小负数 / 区间最大非负数 / 区间最小非负数」，以及 $B$ 的区间最大 / 区间最小；每轮只有 $4$ 种组合，取最大值即为本轮答案。

**复杂度**：$O(n \log n)$（预处理 + 每轮 $O(1)$）。原文只给了预处理量级，未单独给出总复杂度；多轮询问下整体为 $O(n\log n + q\log n)$。

**易错点**（整理）：
1. 「非负数」与「正数」要分清：0 属于非负数，而 0 在两个方向上的乘法表现都要单独考虑。
2. 区间内不存在某类数（例如没有负数）时，该方案要置为 $-\infty$ 跳过，不能直接参与取 max。
3. 后手的最值要固定按「先手符号」选择，不能无条件取区间最小。

**参考代码**（NOI 风格；本仓库补写）：

```cpp
// CSP-S 2022 T2 策略游戏（洛谷 P8818）
// ----------------------------------------------------------------------------
// 题意：数组 A[1..n]、B[1..m]。每轮给区间 [l1,r1]、[l2,r2]：
//       小 L 先在 A 区间选 x，小 Q 再在 B 区间选 y，得分 x*y。
//       L 最大化、Q 最小化，求最优策略下的得分。多组询问。
//
// 关键结论：
//   固定 x 后，Q 一定取使 x*y 最小的 y：
//     x >= 0 时取 B 区间最小值；x < 0 时取 B 区间最大值。
//   于是本题变成 max_{x in A区间} f(x)，f(x) 关于 x 单调（分段）：
//     - 非负段：f(x)=x*minB，只需看「最小非负数」与「最大非负数」两个端点；
//     - 负数段：f(x)=x*maxB，只需看「最小负数（最负）」与「最大负数（最接近 0）」。
//   因此先手只需考虑 4 种数，ST 表 O(1) 查每类极值 + B 的区间最大/最小。
//
// 注意：某类数不存在时用哨兵 INF / -INF 表示，绝不能让哨兵参与乘法。
// 复杂度：O((n+m) log n) 预处理，O(1) 每次询问。
// ============================================================================
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
const int LOG = 18;
const long long INF = (long long)2e18;    // 2e18 + 2e18 = 4e18 < 9.2e18，不会溢出
const long long NEG = (long long)-2e18;

int n, m, q;
long long A[MAXN], B[MAXN];

struct SparseMax {
    long long st[LOG][MAXN];
    void build(long long *src, int len) {
        for (int i = 1; i <= len; ++i) st[0][i] = src[i];
        for (int j = 1; j < LOG; ++j)
            for (int i = 1; i + (1 << j) - 1 <= len; ++i)
                st[j][i] = max(st[j - 1][i], st[j - 1][i + (1 << (j - 1))]);
    }
    long long query(int l, int r) const {
        int j = 31 - __builtin_clz((unsigned)(r - l + 1));
        return max(st[j][l], st[j][r - (1 << j) + 1]);
    }
};

struct SparseMin {
    long long st[LOG][MAXN];
    void build(long long *src, int len) {
        for (int i = 1; i <= len; ++i) st[0][i] = src[i];
        for (int j = 1; j < LOG; ++j)
            for (int i = 1; i + (1 << j) - 1 <= len; ++i)
                st[j][i] = min(st[j - 1][i], st[j - 1][i + (1 << (j - 1))]);
    }
    long long query(int l, int r) const {
        int j = 31 - __builtin_clz((unsigned)(r - l + 1));
        return min(st[j][l], st[j][r - (1 << j) + 1]);
    }
};

// A 的四类极值表
SparseMin aMinNeg;      // 最小负数（最负）
SparseMax aMaxNeg;      // 最大负数（最接近 0）
SparseMin aMinNonNeg;   // 最小非负数
SparseMax aMaxNonNeg;   // 最大非负数
// B 的区间最值
SparseMin bMin;
SparseMax bMax;

long long tmp[6][MAXN];

int main() {
    freopen("game.in", "r", stdin);
    freopen("game.out", "w", stdout);

    if (scanf("%d %d %d", &n, &m, &q) != 3) return 0;
    for (int i = 1; i <= n; ++i) scanf("%lld", &A[i]);
    for (int i = 1; i <= m; ++i) scanf("%lld", &B[i]);

    for (int i = 1; i <= n; ++i) {
        tmp[0][i] = (A[i] < 0 ? A[i] : INF);    // aMinNeg
        tmp[1][i] = (A[i] < 0 ? A[i] : NEG);    // aMaxNeg
        tmp[2][i] = (A[i] >= 0 ? A[i] : INF);   // aMinNonNeg
        tmp[3][i] = (A[i] >= 0 ? A[i] : NEG);   // aMaxNonNeg
    }
    for (int i = 1; i <= m; ++i) {
        tmp[4][i] = B[i];                        // bMin
        tmp[5][i] = B[i];                        // bMax
    }
    aMinNeg.build(tmp[0], n);
    aMaxNeg.build(tmp[1], n);
    aMinNonNeg.build(tmp[2], n);
    aMaxNonNeg.build(tmp[3], n);
    bMin.build(tmp[4], m);
    bMax.build(tmp[5], m);

    while (q--) {
        int l1, r1, l2, r2;
        scanf("%d %d %d %d", &l1, &r1, &l2, &r2);
        long long lo = bMin.query(l2, r2);   // B 区间最小值
        long long hi = bMax.query(l2, r2);   // B 区间最大值
        long long cand[4] = {
            aMinNeg.query(l1, r1),
            aMaxNeg.query(l1, r1),
            aMinNonNeg.query(l1, r1),
            aMaxNonNeg.query(l1, r1)
        };
        long long best = NEG;
        for (int i = 0; i < 4; ++i) {
            long long x = cand[i];
            if (x <= NEG / 2 || x >= INF / 2) continue;    // 该类数不存在
            long long y = (x >= 0 ? lo : hi);              // Q 的最优反应
            best = max(best, x * y);
        }
        printf("%lld\n", best);
    }
    return 0;
}
```

**验证**：编译零错误；与独立暴力随机对拍 200 组 + 中规模 40 组，全部一致（独立复跑）。⚠️ 无官方数据，仅对拍支撑。

### T3 星战（galaxy）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P8819 |
| 核心考点 | 图论（出度 / 入度）、字符串哈希（集合哈希） |
| 难度 | 省选/NOI− |
| 一句话结论 | 「反攻可行」等价于所有点出度均为 1；用随机权值和维护可合并集合，判定起点集合是否恰为 $\{1..n\}$。 |

**题目大意**：给定 $n$ 个点 $m$ 条边的有向图（虫洞）。支持 4 种操作：修复/摧毁一条边、修复/摧毁一个点的所有入边。每次操作后询问该图是否满足「反攻」条件。

**题解**：

先把题面翻译成图论语言：从每个点出发都能无限次穿梭 $\iff$ 从任意点出发都能走到某个环上；每个点只能有一条从它出发的虫洞 $\iff$ 每个点出度为 1。由出度为 1 的有向图性质（每个点都能走到环上），**反攻可行 $\iff$ 所有点的出度都等于 1**。

- **40 分**：存邻接矩阵，每次操作直接修改并维护各点出度，最后检查 $n$ 个点出度是否都为 1。复杂度 $O(nq)$。
- **60 分（无 4 号操作）**：对每个点维护两个 `set`，分别存完好的入边起点与被摧毁的入边起点。1、2 号操作在 $v$ 的集合间移动 $u$ 并同步修改 $u$ 的出度；3 号操作枚举 $u$ 的所有完好入边逐个摧毁。由于每条边最多被摧毁两次（摧毁两次即说明至少被修复过一次），整体最多摧毁 $m+q$ 条边，配合 `set` 得 $O((m+q)\log n)$。
- **100 分**：`set` 方案在 4 号操作上退化——把坏集合整体搬回好集合时，必须逐条枚举更新起点的入度，超时。

  改用**集合哈希**：取一个足够大的质数 $P$，令 $p_i = P^i$（实际需取模）。集合 $\{1,3,4,5\}$ 的哈希值即 $p_1+p_3+p_4+p_5$，唯一对应；删边就是减 $p_u$，加边就是加 $p_7$，都是 $O(1)$。

  设点 $i$ 的好虫洞起点集合哈希为 $s_i$、坏集合为 $t_i$：

  - 3 号操作后：$s'_i = 0,\ t'_i = s_i + t_i$；
  - 4 号操作后：$s'_i = s_i + t_i,\ t'_i = 0$。

  引入哈希的真正目的是**免去逐点维护出度**：把所有虫洞的起点存成一个可重复集合（期望恰好是大小 $n$ 的不重复集合 $\{1..n\}$），把初始状态的总哈希记为 $Q$，例如起点为 $\{1,1,2,3,5,5,5\}$ 时 $Q = 2p_1+p_2+p_3+3p_5$。则答案为 YES 当且仅当 $Q = p_1+p_2+\cdots+p_n$。

  $Q$ 的维护同样 $O(1)$：1 号操作 $Q \mathrel{-}= p_u$；2 号操作 $Q \mathrel{-}= s_u$；3 号操作 $Q \mathrel{+}= p_u$；4 号操作 $Q \mathrel{+}= t_u$。

  > **校注（重要）**：原文只给了 $Q$ 的四个维护式，**漏掉了坏集合 $t$ 的同步更新**。必须补上：1 号操作 $s_v \mathrel{-}= p_u,\ t_v \mathrel{+}= p_u$；3 号操作 $s_v \mathrel{+}= p_u,\ t_v \mathrel{-}= p_u$。否则「先 1 号摧毁某条边、再 4 号整体修复该点入边」时，$t_v$ 里根本没有这条边，它永远修不回来。$Q$ 的四个式子本身是对的。

**复杂度**：$O(n+m+q)$。哈希带模运算，实践中需用双模数或大随机权值降低碰撞概率。

**易错点**（整理）：
1. 该哈希是概率算法，单模数在毒瘤数据下可能被卡，建议双模数或 `unsigned long long` 自然溢出 + 随机底数。
2. 3 号操作是「摧毁 $u$ 的**所有入边**」，$Q$ 上体现为 $+p_u$；4 号是「修复 $u$ 的所有入边」，体现为 $+t_u$——方向别写反。
3. 目标状态是所有点出度为 1，对应起点集合恰为 $\{1,2,\dots,n\}$，而不是「每个点入度都是 1」。

**参考代码**（NOI 风格；本仓库补写）：

```cpp
// CSP-S 2022 T3 星战（洛谷 P8819）
// ----------------------------------------------------------------------------
// 题意：n 个点、m 条有向边（虫洞）。四种操作：
//   1 u v : 摧毁边 u->v          3 u v : 修复边 u->v
//   2 u   : 摧毁据点 u（即摧毁 u 的所有「还未被摧毁」的入边）
//   4 u   : 修复据点 u（即修复 u 的所有「已被摧毁」的入边）
// 每次操作后回答：是否能反攻（YES/NO）。
//
// 结论：反攻可行 <=> 每个点的出度恰好为 1。
//   （出度为 1 的有向图，从任意点沿唯一出边必走进一个环，可无限穿梭；反之，若
//    某点出度不为 1，要么无边可走、要么切换虫洞不唯一，均不满足条件。）
//
// 做法：维护所有「可用虫洞」的起点可重集合 S（按起点计权）。初始 S 中每个 u
//       出现 outdeg(u) 次。反攻可行 <=> S 恰为 {1,2,...,n} 各一次。
//       集合哈希：给点 i 随机权 p[i]（64 位），S 的哈希 Q = Σ_{u∈S} p[u]；
//       目标 T = Σ p[i]。每次操作 O(1) 更新 Q，判 Q == T 即可。
//       s[u] = u 的可用入边的起点权值和；t[u] = u 的已摧毁入边的起点权值和。
//         op1: s[v] -= p[u], Q -= p[u]
//         op2: t[u] += s[u], Q -= s[u], s[u] = 0
//         op3: s[v] += p[u], Q += p[u]
//         op4: s[u] += t[u], Q += t[u], t[u] = 0
// 复杂度：O(n + m + q)，unsigned long long 自然溢出。
// ============================================================================
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
typedef unsigned long long ull;

int n, m, q;
ull p[MAXN];    // 每个点的随机权
ull s[MAXN];    // 可用入边（起点）权值和
ull t[MAXN];    // 已摧毁入边（起点）权值和

int main() {
    freopen("galaxy.in", "r", stdin);
    freopen("galaxy.out", "w", stdout);

    scanf("%d %d", &n, &m);

    mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
    ull target = 0;
    for (int i = 1; i <= n; ++i) {
        p[i] = rng();
        target += p[i];
    }

    ull Q = 0;                                  // 全部可用虫洞的起点哈希
    for (int i = 0; i < m; ++i) {
        int u, v;
        scanf("%d %d", &u, &v);
        s[v] += p[u];
        Q += p[u];
    }

    scanf("%d", &q);
    while (q--) {
        int op;
        scanf("%d", &op);
        if (op == 1 || op == 3) {
            int u, v;
            scanf("%d %d", &u, &v);
            // 单条边的摧毁/修复要同时维护「坏集合」t，否则 4 号操作无法把它修复
            if (op == 1) { s[v] -= p[u]; t[v] += p[u]; Q -= p[u]; }
            else         { s[v] += p[u]; t[v] -= p[u]; Q += p[u]; }
        } else {
            int u;
            scanf("%d", &u);
            if (op == 2) { t[u] += s[u]; Q -= s[u]; s[u] = 0; }
            else         { s[u] += t[u]; Q += t[u]; t[u] = 0; }
        }
        puts(Q == target ? "YES" : "NO");
    }
    return 0;
}
```

**验证**：编译零错误；与独立暴力随机对拍 200 组 + 中规模 180 组，全部一致（独立复跑）。注意：本解**依赖题面保证**——操作 1、3 给出的边必然分别处于可摧毁 / 已损毁状态；若喂入违反该保证的数据（对已修复的边再次修复），集合哈希会重复累加而判错。⚠️ 无官方数据，仅对拍支撑。

### T4 数据传输（transmit）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P8820 |
| 核心考点 | 树链问题、动态 DP、广义矩阵乘法 + 倍增 |
| 难度 | 省选/NOI− |
| 一句话结论 | 按 $k=1/2/3$ 分类，把路径上的 DP 转移写成 $(\min,+)$ 广义矩阵，用倍增沿「朝上 / 朝下」两段分别合并。 |

**题目大意**：给定一棵 $n$ 个结点的树，点有点权。在树上移动时一次最多跳 $k$ 条边（$1 \le k \le 3$），每次落脚都要付出该点的点权（起点、终点都算）。$Q$ 次询问，每次求从 $s$ 到 $t$ 的最小总花费。

**题解**：

$k$ 很小（$1 \le k \le 3$），按 $k$ 分类讨论：

- $k=1$：不能跳过任何点，只能沿简单路径直接走。
- $k=2$：落脚点必然都在 $s \to t$ 的简单路径上。想绕开路径上的下一个点 $u$ 而拐进 $u$ 的儿子 $v$ 是没意义的——从 $v$ 仍只能走到 $u$ 的下一个点 $w$，而从当前点可以直接到 $w$。
- $k=3$：同理，走到下一个点的儿子或孙子都没意义，落脚点只会是简单路径上的点，或这些点的邻接点。

分档做法：

- **8 分**：DFS 枚举下一个落脚点（建议先预处理距离 $\le k$ 的点集）。
- **24 分（$k=1$）**：答案就是树上路径点权和。求 LCA 后用差分求路径和。
- **44 分（$k=2$，$n$ 较小）**：把路径拉出来做线性 DP。设 $f[i]$ 为从起点出发、最后落在路径第 $i$ 个点的最小花费，$t_i$ 为第 $i$ 个点点权，则
  $$f[i] = \min(f[i-1], f[i-2]) + t_i$$
  （原文此处写作 $\min(f[i-1],f[i-1])$，为重复笔误，按 $k=2$ 的语义应为 $\min(f[i-1],f[i-2])$——**校注**。）答案为路径末点的 $f$。
- **76 分（$k=3$，$n$ 较小）**：对路径上每个点的**邻接点** $i$ 设 $g[i]$ 表示「从起点出发、最后停在第 $i$ 个点的邻接点」的最小时间（示意图见原文）。设 $c_i$ 为 $i$ 的邻居的最小处理时间，则有
  $$f[x_i] = \min\{f[x_{i-1}], f[x_{i-2}], f[x_{i-3}], g[x_{i-2}], g[x_{i-1}]\} + a[x_i]$$
  $$g[x_i] = \min\{f[x_{i-1}], f[x_{i-2}], g[x_{i-1}]\} + c[x_i]$$
  每次询问要访问路径上所有点及其邻接点，复杂度 $O(nq)$。
- **100 分**：用**倍增**预处理 DP 转移，把合并代价降到 $O(\log n)$。重定义矩阵乘法为
  $$a_{i,j} = \min_k \{b_{i,k} + c_{k,j}\}$$
  即 $(\min,+)$ 广义矩阵乘法，满足结合律。

  - $k=2$ 时转移写成 $2\times 2$：
    $$\begin{bmatrix} f_i \\ f_{i-1} \end{bmatrix} = \begin{bmatrix} a_i & a_i \\ 0 & \infty \end{bmatrix} \cdot \begin{bmatrix} f_{i-1} \\ f_{i-2} \end{bmatrix}$$
  - $k=3$ 时若直接用 $5\times 5$ 矩阵，单次乘法需 $5^3$ 次操作，无法接受。**简化 DP 方程**后：$g[x_i]$ 与 $f[x_{i-1}]$ 到 $x$ 的距离都是 1，二者只需保留较小值；同理 $g[x_{i-2}]$ 与 $f[x_{i-2}]$ 也只需保留较小值。令 $f[x_i][t]$ 表示从起点到距离 $x_i$ 为 $t$ 个单位的点的最小点权和：
    $$f[x_i][0] = \min\{f[x_{i-1}][0], f[x_{i-1}][1], f[x_{i-1}][2]\} + a[x_i]$$
    $$f[x_i][1] = \min\{f[x_{i-1}][0], f[x_{i-1}][1]\} + c[x_i]$$
    $$f[x_i][2] = \min\{f[x_{i-1}][1], f[x_{i-2}][0]\}$$
    由于在 $x_{i-1}$ 处已用 $f[x_{i-2}][0]$ 更新过 $f[x_{i-1}][1]$，可直接取 $f[x_i][2] = f[x_{i-1}][1]$。于是只需 $3\times 3$ 转移矩阵：
    $$\begin{bmatrix} f[x_i][0] \\ f[x_i][1] \\ f[x_i][2] \end{bmatrix} = \begin{bmatrix} a[x_i] & a[x_i] & a[x_i] \\ 0 & c[x_i] & \infty \\ \infty & 0 & \infty \end{bmatrix}\begin{bmatrix} f[x_{i-1}][0] \\ f[x_{i-1}][1] \\ f[x_{i-1}][2] \end{bmatrix}$$
    倍增维护左侧的矩阵 $A_{x_i}$，初始列向量为起点 $x_0$ 的向量：
    $$\begin{bmatrix} f[x_0][0] \\ f[x_0][1] \\ f[x_0][2] \end{bmatrix} = \begin{bmatrix} a[x_0] \\ \infty \\ \infty \end{bmatrix}$$

  由于是**树上路径**，DP 转移的起点与终点不能互换，因此要把路径拆成「朝上」和「朝下」两部分分别用倍增计算 DP 值，维护的矩阵也需要用两个倍增数组分别维护朝上 / 朝下的矩阵信息。

**复杂度**：$$O\big((q+n)\log n \cdot k^3\big)$$

**易错点**（整理）：
1. 路径必须拆成朝上 / 朝下两段，两段的矩阵方向相反；合并顺序错了会得到反向路径的答案。
2. 广义矩阵乘法的单位矩阵是「对角为 0、其余为 $\infty$」，初始化容易写错。
3. 起点和终点的点权都要计入，初始化列向量只对 $f[x_0][0]$ 赋值、其余为 $\infty$。
4. $k=3$ 时不要直接用 $5\times 5$，必须先化简到 $3\times 3$ 才能过时限。

**参考代码**（NOI 风格；本仓库补写）：

```cpp
// CSP-S 2022 T4 数据传输（洛谷 P8820）
// ----------------------------------------------------------------------------
// 题意：树上 n 个点，点权 a[i]。一次移动最多跳 k 条边（k<=3），每次落脚都要
//       付出落脚点权值（起点、终点都算）。q 次询问 s->t 的最小总花费。
//
// 关键观察（沿简单路径 x0=s, x1, ..., xL=t 走）：
//   * 落脚点只需是「路径上的点」或「路径上某点的邻居」。
//     跳到路径点的孙子辈一定不优：k=3 时从当前点可直接跳到再往后的路径点。
//   * 状态：dp[t] 表示「最后一次落脚点距当前路径点为 t」时的最小花费，t=0,1,2。
//     t=2 只是距离记账，用来支持「连跳三步」。
//
// 转移（从 x_{i-1} 到 x_i，记 a=a[x_i]，mn=mn[x_i] 为 x_i 邻居的最小点权）：
//   dp'[0] = a  + min(dp[0], dp[1], dp[2])
//   dp'[1] = min(dp[0], dp[1] + mn)
//   dp'[2] = dp[1]
// 写成 (min,+) 广义矩阵：
//   | a   a   a  |
//   | 0   mn  INF|
//   | INF 0   INF|
// 初值 dp = (a[s], INF, INF)，答案 = 路径走完后 dp[0]。
//
// k=2： | a  a |       k=1：直接路径点权和（前缀和 + LCA）。
//       | 0 INF|
//
// 树上路径要拆成「朝上」和「朝下」两段，矩阵不可交换，因此需要两套倍增表：
//   upB[j][u] = M[top] ⊗ ... ⊗ M[u]（2^j 个，自下而上应用）
//   upE[j][u] = M[u] ⊗ ... ⊗ M[top]（2^j 个，自上而下应用）
// 复杂度 O((n + q) log n * k^3)，k<=3。
// ============================================================================
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200005;
const int MAXLOG = 18;                 // 2^17 = 131072，2^18 > 2e5
const long long INF = (long long)1e18; // 最大真实花费 2e5*1e9 = 2e14

int n, q, K;
long long a[MAXN];
vector<int> g[MAXN];

int dep[MAXN], par[MAXN];
int anc[MAXLOG][MAXN];
long long mnv[MAXN];        // 邻居最小点权
long long sumw[MAXN];       // 根到该点的点权和（k=1 用）

int D;                      // 矩阵阶数：k=2 用 2，k=3 用 3
struct Mat {
    long long v[3][3];
};
Mat ID;                     // (min,+) 单位矩阵：对角 0，其余 INF

inline Mat mul(const Mat &A, const Mat &B) {
    Mat R;
    for (int i = 0; i < D; ++i)
        for (int j = 0; j < D; ++j) {
            long long best = INF;
            for (int t = 0; t < D; ++t)
                best = min(best, A.v[i][t] + B.v[t][j]);
            R.v[i][j] = best;
        }
    return R;
}

// 每套表 18 * 2e5 * 9 * 8B ≈ 259MB，两套共约 518MB（本题内存限制 1GB）
Mat upB[MAXLOG][MAXN];
Mat upE[MAXLOG][MAXN];
Mat Mof[MAXN];              // 每个点自己的转移矩阵

inline void applyVec(long long *vec, const Mat &A) {
    long long res[3];
    for (int i = 0; i < D; ++i) {
        long long best = INF;
        for (int t = 0; t < D; ++t) best = min(best, A.v[i][t] + vec[t]);
        res[i] = best;
    }
    for (int i = 0; i < D; ++i) vec[i] = res[i];
}

int lca(int u, int v) {
    if (dep[u] < dep[v]) swap(u, v);
    int dif = dep[u] - dep[v];
    for (int j = 0; j < MAXLOG; ++j)
        if (dif >> j & 1) u = anc[j][u];
    if (u == v) return u;
    for (int j = MAXLOG - 1; j >= 0; --j)
        if (anc[j][u] != anc[j][v]) { u = anc[j][u]; v = anc[j][v]; }
    return par[u];
}

int main() {
    freopen("transmit.in", "r", stdin);
    freopen("transmit.out", "w", stdout);

    if (scanf("%d %d %d", &n, &q, &K) != 3) return 0;
    for (int i = 1; i <= n; ++i) scanf("%lld", &a[i]);
    for (int i = 1; i < n; ++i) {
        int u, v;
        scanf("%d %d", &u, &v);
        g[u].push_back(v);
        g[v].push_back(u);
    }

    // ---------- 建树（迭代 BFS，避免递归爆栈） ----------
    for (int i = 1; i <= n; ++i) mnv[i] = INF;
    par[1] = 0; dep[1] = 0; sumw[1] = a[1];
    {
        static int que[MAXN];
        int head = 0, tail = 0;
        que[tail++] = 1;
        while (head < tail) {
            int u = que[head++];
            for (int v : g[u]) {
                if (v == par[u]) continue;
                par[v] = u;
                dep[v] = dep[u] + 1;
                sumw[v] = sumw[u] + a[v];
                que[tail++] = v;
            }
        }
    }
    // 邻居最小点权（包含父亲与所有儿子）
    for (int u = 1; u <= n; ++u)
        for (int v : g[u]) mnv[u] = min(mnv[u], a[v]);
    if (K == 3) for (int u = 1; u <= n; ++u) if (mnv[u] == INF) mnv[u] = INF;

    if (K == 1) {
        // ---------- k = 1：只能沿路径逐点走 ----------
        for (int u = 0; u <= n; ++u)
            for (int j = 0; j < MAXLOG; ++j) anc[j][u] = 0;
        for (int i = 1; i <= n; ++i) anc[0][i] = par[i];
        for (int j = 1; j < MAXLOG; ++j)
            for (int i = 1; i <= n; ++i) anc[j][i] = anc[j - 1][anc[j - 1][i]];
        while (q--) {
            int s, t;
            scanf("%d %d", &s, &t);
            int l = lca(s, t);
            printf("%lld\n", sumw[s] + sumw[t] - 2 * sumw[l] + a[l]);
        }
        return 0;
    }

    // ---------- 建矩阵 ----------
    D = (K == 2 ? 2 : 3);
    for (int i = 0; i < D; ++i)
        for (int j = 0; j < D; ++j) ID.v[i][j] = (i == j ? 0 : INF);

    for (int u = 0; u <= n; ++u)
        for (int i = 0; i < D; ++i)
            for (int j = 0; j < D; ++j) Mof[u].v[i][j] = ID.v[i][j];
    for (int u = 1; u <= n; ++u) {
        Mat &m = Mof[u];
        m.v[0][0] = m.v[0][1] = m.v[0][2] = a[u];
        m.v[1][0] = 0;
        m.v[1][1] = (K == 2 ? INF : mnv[u]);
        m.v[1][2] = INF;
        m.v[2][0] = INF;
        m.v[2][1] = 0;
        m.v[2][2] = INF;
    }

    // ---------- 倍增预处理 ----------
    for (int u = 0; u <= n; ++u) anc[0][u] = par[u];
    for (int u = 0; u <= n; ++u) { upB[0][u] = Mof[u]; upE[0][u] = Mof[u]; }
    for (int j = 1; j < MAXLOG; ++j) {
        for (int u = 0; u <= n; ++u) {
            int mid = anc[j - 1][u];
            anc[j][u] = anc[j - 1][mid];
            upB[j][u] = mul(upB[j - 1][mid], upB[j - 1][u]);   // 上段 ⊗ 下段
            upE[j][u] = mul(upE[j - 1][u], upE[j - 1][mid]);   // 下段 ⊗ 上段
        }
    }

    // ---------- 回答询问 ----------
    while (q--) {
        int s, t;
        scanf("%d %d", &s, &t);
        int l = lca(s, t);
        long long vec[3] = {a[s], INF, INF};

        int d1 = dep[s] - dep[l];          // 朝上：parent(s) ... l
        int cur = par[s];
        for (int j = 0; j < MAXLOG; ++j)
            if (d1 >> j & 1) {
                applyVec(vec, upB[j][cur]);
                cur = anc[j][cur];
            }

        int d2 = dep[t] - dep[l];          // 朝下：child(l) ... t
        if (d2 > 0) {
            Mat P = ID;
            cur = t;
            for (int j = 0; j < MAXLOG; ++j)
                if (d2 >> j & 1) {
                    P = mul(P, upE[j][cur]);
                    cur = anc[j][cur];
                }
            applyVec(vec, P);
        }
        printf("%lld\n", vec[0]);
    }
    return 0;
}
```

### T1 廊桥分配（airport）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P7913 |
| 核心考点 | 贪心、优先队列（模拟） |
| 难度 | 普及/提高− |
| 一句话结论 | 「先到先得」使得每架飞机最终停在哪个廊桥只与廊桥**个数**有关、与具体分配方案无关，于是分别模拟两种航班「前 $i$ 个廊桥能停几架」的前缀和，答案取 $\max(s1[i]+s2[n-i])$。 |

**题目大意**：机场分国内区与国际区，只有分属对应区的廊桥才能停靠对应航班。给定 $n$ 个廊桥、$m_1$ 架国内航班和 $m_2$ 架国际航班的到达/离开时刻；廊桥按「先到先得」分配，到达时若对应区还有空闲廊桥就停靠（约定分配编号最小的空闲廊桥），否则停靠远机位（远机位数量充足）。机场只有一条跑道，故不存在两架飞机同时到达的情况。请把 $n$ 个廊桥划分给国内区和国际区，使能停靠廊桥的飞机总数最大。

数据范围：对于 20% 的数据，$1 \le n \le 100$，$1 \le m_1+m_2 \le 100$；对于 40% 的数据，$1 \le n \le 5000$，$1 \le m_1+m_2 \le 5000$；对于 100% 的数据，$1 \le n \le 10^5$，$1 \le m_1+m_2 \le 10^5$。所有 $a_{1,i},b_{1,i},a_{2,i},b_{2,i}$ 为数值不超过 $10^8$ 的互不相同的正整数，且保证 $\forall i \in [1,n]$，$a_{1,i}<b_{1,i}$，$a_{2,i}<b_{2,i}$。

**题解**：

**【40 分】**：由于廊桥的分配必须满足先来后到原理，我们可以假定每个航班到达时，给它分配这类航班的廊桥中，编号最小的空闲廊桥。我们可以枚举分配方法的大小，对航班按照到达时间排序，然后使用模拟法模拟出答案，并求出最小值。时间复杂度为 $O(n^2)$。

**【100 分】**：由于题目要求先到先得，因此每架飞机最终停在哪个廊桥与分配的廊桥**个数**无关，我们可以直接模拟出每个飞机会在哪个廊桥停下。

- 考虑一个以**时间**为关键字的优先队列，存储停靠在廊桥的飞机；另一个以**编号**为关键字的优先队列，存储空闲的廊桥。
- 把飞机按照到达时间排序，如果编号堆中有剩余就取出最小的编号，加上这架飞机的离开时间组成结构体，扔进时间堆中。
- 每当一架飞机进入之前，先把已经超过离开时间的飞机弹出，释放空闲的廊桥即可。
- 通过上述步骤分别求出国内航班和国际航班每个廊桥停靠了多少架飞机，然后对这个数组求前缀和，得到 $s1[i]$ 的是国内航班分配了 $i$ 个廊桥后多少架飞机可以停靠。最终答案为 $\max(s1[i] + s2[n-i])$。

时间复杂度：$O(n \log n)$；空间复杂度：$O(n)$。

**易错点**（整理）：
1. 模拟时必须按「空闲廊桥中**编号最小**」分配，才能保证停靠架数是廊桥个数的单调函数；这是「与具体分配无关」这一结论的前提。
2. 释放廊桥（弹出已离开的飞机）要放在新飞机到达**之前**做。
3. 答案是 $\max(s1[i]+s2[n-i])$（$0 \le i \le n$），两个前缀和数组的下标范围都要开到 $n+1$。

**参考代码**（NOI 风格；已编译并通过官方评测数据）：

```cpp
// CSP-S 2021 T1 廊桥分配 (airport)  P7913
// 思路：先到先得 + 编号最小的空闲廊桥 => 每架飞机最终停靠的廊桥与"分配方案"无关，
//       只与廊桥个数有关。于是分别对国内/国际航班在"n 个廊桥"下模拟一次，
//       记录每架飞机落到第几号廊桥，求前缀和 s[x] = "给 x 个廊桥能停几架"，
//       答案 = max_{0<=x<=n} (s1[x] + s2[n-x])。
#include <bits/stdc++.h>
using namespace std;
typedef long long LL;

const int N = 1e5 + 7;

int n, m1, m2;
pair<int, int> a[N], b[N];

// 返回 cnt[x] = 给 x 个廊桥时能停靠的飞机数（x = 0..lim）
vector<int> calc(pair<int, int> *v, int m, int lim) {
    vector<int> per(lim + 1, 0);                       // per[i] = 落到 i 号廊桥的飞机数
    priority_queue<int, vector<int>, greater<int> > freeIdx;   // 空闲廊桥编号（小根堆）
    priority_queue<pair<int, int>, vector<pair<int, int> >, greater<pair<int, int> > > busy; // (离开时间, 廊桥号)
    for (int i = 1; i <= lim; ++i) freeIdx.push(i);

    for (int i = 1; i <= m; ++i) {
        int arr = v[i].first, lea = v[i].second;
        while (!busy.empty() && busy.top().first < arr) {   // 先释放已离开的廊桥
            freeIdx.push(busy.top().second);
            busy.pop();
        }
        if (freeIdx.empty()) continue;                      // 只能停远机位
        int id = freeIdx.top(); freeIdx.pop();
        ++per[id];
        busy.push(make_pair(lea, id));
    }
    for (int i = 1; i <= lim; ++i) per[i] += per[i - 1];     // 前缀和：per[x] = 前 x 个廊桥停了几架
    return per;
}

int main() {
    freopen("airport.in", "r", stdin);
    freopen("airport.out", "w", stdout);

    scanf("%d%d%d", &n, &m1, &m2);
    for (int i = 1; i <= m1; ++i) scanf("%d%d", &a[i].first, &a[i].second);
    for (int i = 1; i <= m2; ++i) scanf("%d%d", &b[i].first, &b[i].second);
    sort(a + 1, a + m1 + 1);   // 按到达时间排序
    sort(b + 1, b + m2 + 1);

    int lim = min(n, max(m1, m2));                 // 廊桥数超过航班数没有意义
    vector<int> s1 = calc(a, m1, lim), s2 = calc(b, m2, lim);

    int ans = 0;
    for (int x = 0; x <= n; ++x) {
        int i1 = min(x, lim), i2 = min(n - x, lim);
        ans = max(ans, s1[i1] + s2[i2]);
    }
    printf("%d\n", ans);
    return 0;
}
```

### T2 括号序列（bracket）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P7914 |
| 核心考点 | 区间 DP、前缀和优化 |
| 难度 | 提高+/省选− |
| 一句话结论 | 设 $f[l][r]$ 表示两端**匹配**、$g[l][r]$ 表示两端**不匹配**的合法方案数，枚举 (S)、(A)、(SA)、(AS)、ASB/AB 五种情形转移；第 5 种情形中 $j$ 的取值是一段连续区间，用前缀和优化，复杂度 $O(n^3)$。 |

**题目大意**：小 w 定义「超级括号序列」是由字符 `(`、`)`、`*` 组成的字符串。对给定常数 $k$，符合规范的超级括号序列由以下规则定义：

1. `()`、（S）均符合规范，其中 S 表示**任意一个仅由不超过 $k$ 个字符 `*` 组成的非空字符串**；
2. 若 A、B 均符合规范，则 AB、ASB 均符合规范（AB 表示把 A、B 拼接在一起）；
3. 若 A 符合规范，则（A）、（SA）、（AS）均符合规范；
4. 所有符合规范的超级括号序列均可通过上述 3 条规则得到。

例如 $k=3$ 时，`(((**)(*)(*))*)(***)` 符合规范，而 `*()`、`(*(*)*)`、`((**)*)`、`(****(*))` 均不符合规范。特别地，空字符串也不被视为符合规范的超级括号序列。现给定长度为 $n$ 的字符串，部分位置已确定，未确定位置用 `?` 表示，求将所有 `?` 一一确定的方案中，能得到符合规范的超级括号序列的方案数（对 $10^9+7$ 取模）。

（原文未给出该题的数据范围表。）

**题解**：

这道题的描述比较复杂，还给了一段排序代码，想要做出这道题，必须先认真阅读代码，容易发现这段代码是**从小往大排序**，并且**排序是稳定的**（数字相同的元素排序之后顺序不会改变）。（原文如此）

**【65 分】**：这道题是区间 DP 经典题的变形，可以考虑使用相同的方法完成。设 $f[l][r]$ 表示 $[l,r]$ 这个子串有多少个合法且两端相互匹配的括号序列。但是这道题也有两个序列拼接的可能性，因此设 $g[l][r]$ 表示这个子串有多少个合法且两端不匹配的括号序列（体现为 ASB 或者 AB 的形式）。

按照子串长度从小往大枚举，需要预处理判断区间 $[l,r]$ 中没有括号的情况，如果全为 `*`，那么 $f[l][r]=0$，$g[l][r]=0$。

然后分情况讨论，(S)、(A)、(SA)、(AS)、ASB 或 AB 总共五种情况。

值得注意的是对于第 5 种情况：$g[l][r]=\text{sigma}((f[l][i] + g[l][i]) * f[j][r])$（$l<i<j<r$，$j-i-1 \le k$，且 $i$ 到 $j$ 没有括号）。

这个枚举部分为 $O(n^4)$，因此这个方法只能获得 65 分。

**【100 分】**：对于第 5 种情况，我们会发现 $i$ 和 $j$ 之间如果只有 `*` 号，那么 $j$ 只能是最后一个 `*` 的下一个字符，不需要枚举，也就是说 ASB 这种情况下 S 没有贡献。而 B 的位置范围是确定的，为一段连续的区间 $[i, i+k]$，可以使用前缀和优化解决。

时间复杂度：$O(n^3)$；空间复杂度：$O(n^2)$。

**易错点**（整理）：
1. S 是「不超过 $k$ 个 `*` 组成的**非空**字符串」，因此 `()` 与全部由 `*` 构成的串要单独处理，且空串不合法。
2. 状态必须同时维护 $f$（两端匹配）与 $g$（两端不匹配）两类，只留 $f$ 会漏掉 AB、ASB 这类拼接形态。
3. 第 5 种情况若暴力枚举 $i,j$ 是 $O(n^4)$（仅 65 分）；把 $j$ 的范围缩到 $[i,\ i+k]$ 这段连续区间后可用前缀和优化到 $O(n^3)$。
4. 转移全程对 $10^9+7$ 取模。

**参考代码**（NOI 风格；已编译并通过官方评测数据）：

```cpp
// CSP-S 2021 T2 括号序列 (bracket)  P7914
// 思路：区间 DP，按长度递增。记
//   f[l][r] = s[l..r] 合法且 l 与 r 匹配（(S) () (A) (SA) (AS) 五种形态）
//   g[l][r] = s[l..r] 合法且由多段拼接而成
//   h[l][r] = s[l..r] 形如 (S 段)+(匹配段)，S 为长度 1..k 的 '*' 串
// 拼接只在"最后一段必定是匹配段"处断开，保证不重不漏：
//   g[l][r] = Σ_m valid[l][m] * ( f[m+1][r] + h[m+1][r] )
// 复杂度 O(n^3 + n^2 k)。
#include <bits/stdc++.h>
using namespace std;
typedef long long LL;

const int N = 507;
const int MOD = 1e9 + 7;

int n, k;
char s[N];
bool okOpen[N], okClose[N];
int starRun[N];          // 从 i 开始连续的 '*'/'?' 个数
LL f[N][N], g[N][N], h[N][N];

int main() {
    freopen("bracket.in", "r", stdin);
    freopen("bracket.out", "w", stdout);

    scanf("%d%d", &n, &k);
    scanf("%s", s + 1);
    for (int i = 1; i <= n; ++i) {
        okOpen[i]  = (s[i] == '(' || s[i] == '?');
        okClose[i] = (s[i] == ')' || s[i] == '?');
    }
    starRun[n + 1] = 0;
    for (int i = n; i >= 1; --i)
        starRun[i] = (s[i] == '*' || s[i] == '?') ? starRun[i + 1] + 1 : 0;

    for (int len = 2; len <= n; ++len)
        for (int l = 1; l + len - 1 <= n; ++l) {
            int r = l + len - 1;
            LL F = 0, G = 0, H = 0;

            // ---------- f[l][r] ----------
            if (okOpen[l] && okClose[r]) {
                if (len == 2) F += 1;                                   // ()
                if (len > 2) {
                    if (min(k, starRun[l + 1]) >= len - 2) F += 1;       // (S)
                    F += f[l + 1][r - 1] + g[l + 1][r - 1];              // (A)
                }
                // (SA)：S = [l+1, t-1] 非空，A = [t, r-1]
                int tmax = min(r - 1, l + 1 + min(k, starRun[l + 1]));
                for (int t = l + 2; t <= tmax; ++t)
                    F += f[t][r - 1] + g[t][r - 1];
                // (AS)：A = [l+1, t-1]，S = [t, r-1] 非空
                int tmin = max(l + 2, r - k);
                for (int t = tmin; t <= r - 1; ++t)
                    if (starRun[t] >= r - t)                             // [t, r-1] 全为 '*'-like
                        F += f[l + 1][t - 1] + g[l + 1][t - 1];
            }
            f[l][r] = F % MOD;

            // ---------- h[l][r] = Σ_{t=l}^{T} f[t+1][r] ----------
            int T = min(r - 1, l + min(k, starRun[l]) - 1);
            for (int t = l; t <= T; ++t) H += f[t + 1][r];
            h[l][r] = H % MOD;

            // ---------- g[l][r] ----------
            for (int m = l; m < r; ++m) {
                LL left = (f[l][m] + g[l][m]) % MOD;
                if (!left) continue;
                G += left * ((f[m + 1][r] + h[m + 1][r]) % MOD) % MOD;
                if (G > (LL)8e18) G %= MOD;
            }
            g[l][r] = G % MOD;
        }

    printf("%lld\n", (f[1][n] + g[1][n]) % MOD);
    return 0;
}
```

### T3 回文（palin）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P7915 |
| 核心考点 | 贪心、双端队列（双栈模拟） |
| 难度 | 提高+/省选− |
| 一句话结论 | 第一个取出的数（$a_1$ 或 $a_{2n}$）决定了它的配对位置必须留在最后，序列随后被拆成向前、向后两个栈，此后每步只能贪心地取「能与当前两个栈顶配对」的那一端，拿到 $L$ 就优先。 |

**题目大意**：给定正整数 $n$ 和整数序列 $a_1,a_2,\dots,a_{2n}$，其中 $1,2,\dots,n$ 各恰好出现 2 次。进行 $2n$ 次操作，每次二选一：①把序列 $a$ 的**开头**元素加到序列 $b$ 的**末尾**并从 $a$ 中移除；②把序列 $a$ 的**末尾**元素加到 $b$ 的末尾并从 $a$ 中移除。初始时 $b$ 为空序列。判断能否使 $b$ 成为回文数列（即 $\forall 1\le i\le n,\ b_i=b_{2n+1-i}$），若能则输出字典序最小的操作方案：用长度为 $2n$ 的、仅由 `L`（操作 1）与 `R`（操作 2）构成的字符串表示；若不能，输出 `-1`。字典序定义：长度均为 $2n$ 的串 $s$ 比 $t$ 小，当且仅当存在 $1 \le k \le 2n$ 使得 $\forall 1 \le i < k$ 有 $s_i=t_i$ 且 $s_k<t_k$。

数据范围：令 $\sum n$ 表示所有 $T$ 组测试数据中 $n$ 的和。对所有测试点保证 $1 \le T \le 100$，$1 \le n$，$\sum n \le 5 \times 10^5$。

| 测试点编号 | $T$ | $n$ | $\sum n$ | 特殊性质 |
| --- | --- | --- | --- | --- |
| $1 \sim 7$ | $\le 10$ | $\le 10$ | $\le 50$ | 无 |
| $8 \sim 10$ | $\le 100$ | $\le 20$ | $\le 1000$ | 无 |
| $11 \sim 12$ | $\le 100$ | $\le 100$ | $\le 1000$ | 无 |
| $13 \sim 15$ | $\le 100$ | $\le 1000$ | $\le 25000$ | 无 |
| $16 \sim 17$ | $=1$ | $\le 5 \times 10^5$ | $\le 5 \times 10^5$ | 有 |
| $18 \sim 20$ | $\le 100$ | $\le 5 \times 10^5$ | $\le 5 \times 10^5$ | 有 |
| $21 \sim 25$ | $\le 100$ | $\le 5 \times 10^5$ | $\le 5 \times 10^5$ | 无 |

特殊性质：如果我们每次删除 $a$ 中两个相邻且相等的数，存在一种方式将序列删空（例如 $a=[1,2,2,1]$）。

**题解**：

**【100 分】**：利用贪心的原理可以解决此题。

根据题目，我们要得到一个回文序列，因此第一个拿出的数字，对应的数字就必须最后一个拿出来。我们可以分别考虑第一拿出的是哪个数字，如果拿出 `a[1]`，假设对应的相同数字编号为 $i$，那么数组就被拆成了 `a[2]~a[i-1]` 和 `a[i+1]~a[n]` 两个部分，由于 `a[i]` 必须要最后拿出来，那么数组事实上变成了向前和向后的两个栈。

接下来只能拿出 `a[2]` 或者 `a[n]`，由于第 2 个拿出来的数字对应数字必须倒数第 2 个拿出来，只有 `a[i-1]` 和 `a[i+1]` 可以倒数第 2 个拿，因此如果 `a[2]==a[i-1]` 或者 `a[2]==a[i+1]` 时，才能拿出 `a[2]`。同理 `a[n]==a[i-1] || a[n]==a[i+1]` 时，才能拿出 `a[n]`，如果两个都拿不出来，那么先拿 `a[1]` 会无解。假设 `a[2]` 能拿出来，那么对应的数就应该倒数第 2 个拿，因此可以同时删掉，继续进行上述步骤，直到所有数字都拿出来了。

如果先拿 `a[1]` 的方法不行，继续尝试先拿 `a[n]` 的方法，如果两个都不行，输出无解。

时间复杂度：$O(N)$；空间复杂度：$O(N)$。

（原文解析中记序列末位为 `a[n]`，而题面中序列长度为 $2n$；此处按原文转写。）

**易错点**（整理）：
1. 首个元素只有两种可能（取 `a[1]` 或取 `a[2n]`），两种都要试；先 `L` 的解在字典序上一定更优，因此「能取 `L` 就取 `L`」。
2. 每一步只能取当前 $a$ 的两端，而「倒数第 $k$ 个拿」只能是对应配对元素（即两个栈顶 `a[i-1]`、`a[i+1]`），拿不出来即该分支无解。
3. 多组询问，$T$ 组数据要逐组输出；无解输出 `-1` 而不是空行。

**参考代码**（NOI 风格；已编译并通过官方评测数据）：

```cpp
// CSP-S 2021 T3 回文 (palin)  P7915
// 思路：第一次只能取 a[1] 或 a[2n]。若第一个取 a[1]，它的配对元素 a[p] 必是最后一次（第 2n 次）取的，
//       于是剩余数组被 a[p] 分成左段 [L0, p-1] 与右段 [p+1, R0] 两个"栈"：
//       左栈从 L0 端弹（操作 'L'，栈底 p-1）、右栈从 R0 端弹（操作 'R'，栈底 p+1）。
//       之后每一步要凑成回文的一对，只能在"两个栈顶之二"与"两个栈底之二"间配对，
//       字典序最小 => 每层按 ('L','L') ('L','R') ('R','L') ('R','R') 的顺序贪心。
#include <bits/stdc++.h>
using namespace std;

const int N = 5e5 + 7;
int n;
int a[2 * N];
vector<int> pos[N];   // 每个值出现的两个位置

int other(int p) {    // 与位置 p 同值的另一个位置
    int v = a[p];
    return pos[v][0] == p ? pos[v][1] : pos[v][0];
}

// start = 0：第一步取 a[1]；start = 1：第一步取 a[2n]
bool attempt(int start, string &out) {
    int p = other(start == 0 ? 1 : 2 * n);
    int L0 = (start == 0 ? 2 : 1);
    int R0 = (start == 0 ? 2 * n : 2 * n - 1);
    int lt = L0, lb = p - 1;      // 左栈 [lt, lb]，从 lt 端弹
    int rt = R0, rb = p + 1;      // 右栈 [rb, rt]，从 rt 端弹

    out.assign(2 * n, '?');
    out[0] = (start == 0 ? 'L' : 'R');
    out[2 * n - 1] = 'L';         // 只剩 [p,p] 时取左端，字典序更小

    for (int k = 1; lt <= lb || rb <= rt; ++k) {
        int lsz = lb - lt + 1, rsz = rt - rb + 1;
        char e1, e2;
        if (lsz == 0) {                                  // 左栈空，只能右栈自己配对
            if (rsz < 2 || a[rt] != a[rb]) return false;
            e1 = e2 = 'R'; --rt; ++rb;
        } else if (rsz == 0) {                           // 右栈空
            if (lsz < 2 || a[lt] != a[lb]) return false;
            e1 = e2 = 'L'; ++lt; --lb;
        } else {
            if (lsz >= 2 && a[lt] == a[lb]) { e1 = 'L'; e2 = 'L'; ++lt; --lb; }
            else if (a[lt] == a[rb])        { e1 = 'L'; e2 = 'R'; ++lt; ++rb; }
            else if (a[rt] == a[lb])        { e1 = 'R'; e2 = 'L'; --rt; --lb; }
            else if (rsz >= 2 && a[rt] == a[rb]) { e1 = 'R'; e2 = 'R'; --rt; ++rb; }
            else return false;
        }
        out[k] = e1;
        out[2 * n - 1 - k] = e2;
    }
    return true;
}

void solve() {
    scanf("%d", &n);
    for (int i = 1; i <= n; ++i) pos[i].clear();
    for (int i = 1; i <= 2 * n; ++i) {
        scanf("%d", &a[i]);
        pos[a[i]].push_back(i);
    }

    string s1, s2;
    bool ok1 = attempt(0, s1);
    bool ok2 = attempt(1, s2);
    if (ok1 && ok2) printf("%s\n", (s1 < s2 ? s1 : s2).c_str());
    else if (ok1)   printf("%s\n", s1.c_str());
    else if (ok2)   printf("%s\n", s2.c_str());
    else            printf("-1\n");
}

int main() {
    freopen("palin.in", "r", stdin);
    freopen("palin.out", "w", stdout);
    int T;
    scanf("%d", &T);
    while (T--) solve();
    return 0;
}
```

### T4 交通规划（traffic）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P7916 |
| 核心考点 | 网络流 / 最小割（最小割 = 最大流） |
| 难度 | 省选/NOI− |
| 一句话结论 | 把每个格点染黑白，使两端颜色不同的边的边权和最小，本质是**最小割**：边的容量取边权，白/黑附加点分别连超级源点与超级汇点，容量取所在射线的权值，跑最大流即得答案。 |

**题目大意**：给定平面上 $n$ 条水平直线与 $m$ 条垂直直线，相交形成 $n$ 行 $m$ 列的网格，从上到下第 $r$ 条水平线和从左到右第 $c$ 条垂直线的交点称为格点 $(r,c)$。网格中任意两个水平或垂直相邻格点之间的线段称为一条边，每条边有一个非负整数边权。进行 $T$ 次询问（$T$ 次询问的 $k$ 可能不同）：每次给出 $k$ 个**附加点**，每个附加点位于一条从网格边缘向外出发的射线上，不同附加点所在的射线互不相同。所有从网格边缘向外出发的射线按**左上-右上-右下-左下-左上**的顺序依次编号为 $1$ 到 $2n+2m$。每个附加点和最近的格点之间的线段也称为一条边，也有非负整数边权（注意，角上的格点有可能和两个附加点同时相连）。给定每个附加点的颜色（黑色或者白色），请你将网格内每个格点的颜色染成黑白二者之一，并使得所有两端颜色不同的边的边权和最小，输出这个最小的边权和。

数据范围：对于所有数据，$2 \le n,m \le 500$，$1 \le T \le 50$，$1 \le k_t \le \min\{2(n+m),\ 50\}$，$1 \le \sum_{t=1}^{T} k_t \le 50$，$0 \le x \le 10^6$，$1 \le p \le 2(n+m)$，$t \in \{0,1\}$。保证对于每个 $i \in [1,T]$，$p_{i,j}$ 互不相同。

| 测试点编号 | $n,m \le$ | $k_t \le$ |
| --- | --- | --- |
| $1,2$ | $5$ | $50$ |
| $3,4,5$ | $18$ | $2$ |
| $6,7,8$ | $18$ | $50$ |
| $9,10$ | $10^2$ | $2$ |
| $11,12$ | $10^2$ | $50$ |
| $13,14,15,16$ | $500$ | $2$ |
| $17,18,19,20$ | $500$ | $50$ |

**题解**：

考虑网络流建图，按照题目的网格建图，边的最大流量就是边的权值，然后把所有白色端点连接超级源点，最大流量为端点所在射线的权值；所有黑色端点连接超级汇点，最大流量为端点所在射线的权值。根据最小割等于最大流原理，使用网络流求出这个图的最小流，得到答案。

（原文未给出该题的分数档与时间/空间复杂度。）

**易错点**（整理）：
1. 目标是「两端颜色不同的边权和最小」，属于最小割模型；白色附加点接超级源点、黑色附加点接超级汇点，源汇方向接反会得到错误的对偶问题。
2. 附加点接入超级源/汇的边容量取**端点所在射线的权值**（即 `x3`），不是格点之间边的权值 `x1`/`x2`。
3. 角上的格点可能同时与两个附加点相连，两条附加边的边权要分别计入；同一组询问内 $p_{i,j}$ 互不相同（射线不重复）。
4. 每次询问都要重建附加点相关的边，注意清空增广后的残量网络。
