### T1 假期计划（holiday）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P8817 |
| 核心考点 | 图论（BFS 最短路）、贪心（前 k 大预处理）、枚举 |
| 难度 | 提高+/省选− |
| 一句话结论 | 预处理每个点「距离 ≤ k+1 且离 1 号点 ≤ k+1」的点权前三大，再枚举 $B,C$ 拼出 $A,D$。 |

**输入格式**（补写标程时实测确认）：第一行 $n,m,k$；第二行 $n-1$ 个整数，依次是 $2 \sim n$ 号点的点权（**1 号点没有点权**）；随后 $m$ 行每行两个整数 $u,v$，表示一条无向边。

**题目大意**：给定 $n$ 个点 $m$ 条边的无向图，每个点有点权。选 4 个互不相同的点 $A,B,C,D$，从 1 号点出发完成行程 $1 \to A \to B \to C \to D \to 1$，每段行程途中可以经过任意点但最多走 $k+1$ 条边。求满足条件的四个点的最大点权和。$n \le 2500$。

**题解**：

由于 $n \le 2500$，可以从每个点出发做一次 BFS 求出两两间最短路；若两点最短路 $\le k+1$，它们就能在行程中相邻出现（记作这两个点「可达」）。

- **40 分（$n \le 20$）**：四层循环枚举 $A,B,C,D$，再验证相邻关系是否都成立。
- **70 分**：只枚举 $A,B,C$。$D$ 可用贪心直接确定：$D$ 必须与 $C$ 可达且与 1 号点可达，所以 $D$ 取满足条件的点中权值最大者。**注意去重**：权值最大的点可能是 $A$ 或 $B$，此时要退到第二大；第二大若仍冲突则退到第三大。因此需要预处理——对每个点 $i$，求出「与 $i$ 可达且与 1 号点可达」的点中权值的前三大，然后三重循环枚举 $A,B,C$，$D$ 取 $C$ 的前三大之一。
- **100 分**：$A$ 的性质与 $D$ 完全对称（$A$ 与 $B$ 可达、且与 1 号点可达），所以 $A$ 一定是 $B$ 的前三大点之一。于是只枚举 $B,C$ 即可：$A$ 取 $B$ 的前三大、$D$ 取 $C$ 的前三大，再检查四个点是否两两不同（$B$ 与 $C$ 的前三大之间可能重合，需逐一判重）。

**复杂度**：BFS 部分 $O(n(n+m))$，枚举部分 $O(n^2)$；与原文一致，总体 $O(n^2)$（忽略 BFS 的 $m$ 项）。

**易错点**（整理）：
1. 前三大必须按「与 $i$ 可达 **且** 与 1 号点可达」筛选后再排序，漏掉后半条会选到不可行的 $D$。
2. 判重时不能只判 $A \ne D$，$A,D$ 都可能与 $B,C$ 撞点，必须四元判重。
3. BFS 距离门限是 $k+1$ 而不是 $k$。

**参考代码**（NOI 风格；本仓库补写）：

```cpp
// ============================================================================
// CSP-S 2022 T1 假期计划（洛谷 P8817）
// ----------------------------------------------------------------------------
// 题意：n 个点 m 条边的无向图，1 号点是家，2..n 号点是景点（各有分数 a[i]）。
//       选 4 个互不相同的景点 A,B,C,D，使得 1->A->B->C->D->1 每一段都
//       最多转车 k 次（即两点间最短路 <= k+1 条边）。求四景点分数和的最大值。
//
// 做法：
//   1) 从每个点 BFS 一遍，只搜到深度 k+1，得到「可达」关系。
//   2) 对每个点 i，预处理候选点 j：dist(i,j) <= k+1 且 dist(1,j) <= k+1，
//      按分数取前三名 top3[i]。为什么前三名够：A 一定在 top3[B] 里，
//      D 一定在 top3[C] 里，最坏情况下前两名被 B、C 或对方占用，第三名必可行。
//   3) 枚举 B、C（要求可达），枚举 A ∈ top3[B]、D ∈ top3[C]，四元互异即更新答案。
//
// 复杂度：BFS O(n(n+m))，枚举 O(9 n^2)。n <= 2500。
// ============================================================================
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 2505;

int n, m, K;
long long a[MAXN];          // a[i] 仅对 i >= 2 有意义（1 号点是家，没有分数）
vector<int> g[MAXN];
short dist[MAXN][MAXN];     // dist[s][t]：最短路；-1 表示 > K+1 或不可达
int top3[MAXN][3];          // 每个点分数前三的合法候选，0 表示不存在

int main() {
    freopen("holiday.in", "r", stdin);
    freopen("holiday.out", "w", stdout);

    if (scanf("%d %d %d", &n, &m, &K) != 3) return 0;
    for (int i = 2; i <= n; ++i) scanf("%lld", &a[i]);   // 注意只有 n-1 个数
    for (int i = 0; i < m; ++i) {
        int u, v;
        scanf("%d %d", &u, &v);
        g[u].push_back(v);
        g[v].push_back(u);
    }

    const int lim = K + 1;                 // 一段行程最多 lim 条边

    // ---------- 1) 每个点为起点的 BFS（只搜到 lim 层） ----------
    static int q[MAXN];
    for (int s = 1; s <= n; ++s) {
        for (int i = 1; i <= n; ++i) dist[s][i] = -1;
        int head = 0, tail = 0;
        q[tail++] = s;
        dist[s][s] = 0;
        while (head < tail) {
            int u = q[head++];
            if (dist[s][u] == lim) continue;       // 不再往下扩展
            for (int v : g[u]) {
                if (dist[s][v] == -1) {
                    dist[s][v] = (short)(dist[s][u] + 1);
                    q[tail++] = v;
                }
            }
        }
    }

    // ---------- 2) 每个点的前三大候选 ----------
    for (int i = 2; i <= n; ++i) {
        top3[i][0] = top3[i][1] = top3[i][2] = 0;
        for (int j = 2; j <= n; ++j) {
            if (j == i) continue;
            if (dist[i][j] == -1) continue;        // 自己与 j 不可达
            if (dist[1][j] == -1) continue;        // j 与家不可达，当不了 A/D
            // 插入排序维护前三
            for (int t = 0; t < 3; ++t) {
                if (top3[i][t] == 0 || a[j] > a[top3[i][t]]) {
                    for (int p = 2; p > t; --p) top3[i][p] = top3[i][p - 1];
                    top3[i][t] = j;
                    break;
                }
            }
        }
    }

    // ---------- 3) 枚举 B、C ----------
    long long ans = -1;
    for (int B = 2; B <= n; ++B) {
        for (int C = 2; C <= n; ++C) {
            if (B == C) continue;
            if (dist[B][C] == -1) continue;
            for (int x = 0; x < 3; ++x) {
                int A = top3[B][x];
                if (!A) break;
                if (A == C) continue;
                for (int y = 0; y < 3; ++y) {
                    int D = top3[C][y];
                    if (!D) break;
                    if (D == A || D == B) continue;   // 四元判重
                    ans = max(ans, a[A] + a[B] + a[C] + a[D]);
                }
            }
        }
    }

    printf("%lld\n", ans);
    return 0;
}
```

**验证**：编译零错误；与独立暴力（$n\le8$ 四层枚举）随机对拍 200 组 + 中规模 40 组，全部一致（本机独立复跑）。⚠️ 2022 年官方测试数据未收录，正确性**仅由对拍支撑**，未经官方数据检验。

### T2 策略游戏（game）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P8818 |
| 核心考点 | 贪心、博弈（对手最优反应）、ST 表 / 线段树 |
| 难度 | 提高+/省选− |
| 一句话结论 | 先手只会取区间内四类数之一（最大/最小非负数、最大/最小负数），后手按先手符号取区间最值。 |

**题目大意**：给定数组 $A,B$。每轮给定 $A$ 的一个区间 $[l_1,r_1]$ 与 $B$ 的一个区间 $[l_2,r_2]$：先手在 $A$ 区间中选一个数 $x$，后手在 $B$ 区间中选一个数 $y$（各自知道对方的最优策略），本轮得分 $x \cdot y$。先手想最大化得分、后手想最小化得分，求最优策略下的得分。多轮询问。

**题解**：

先固定先手的选择 $x$：后手必然在 $B$ 区间里选使 $x \cdot y$ 最小的 $y$。先手选数时能预见这一反应。

- **40 分**：直接枚举先手选的 $x$，再扫一遍区间求后手最优反应，即「每行最小值中的最大值」。复杂度 $O(nmq)$。若满足特殊性质 2，复杂度降为 $O(nq)$。
- **65 分（特殊性质 1：$A_i,B_i>0$）**：后手一定取区间最小值，先手一定取区间最大值。用 ST 表或线段树维护 $A$ 的区间最大值、$B$ 的区间最小值，答案即两者相乘。
- **100 分**：把「$A_i,B_i>0$ 取区间最值」的结论推广——
  - 若先手取正数，后手一定取区间**最小**值；
  - 若先手取负数，后手一定取区间**最大**值。

  再据此讨论先手：

  1. 先手取正数：当 $B$ 区间最小值为正时，先手取**最大的正数**；当 $B$ 区间最小值为负时，先手取**最小的正数**（有 0 取 0）。
  2. 先手取负数：当 $B$ 区间最大值为正时，先手取**最小的负数**；当 $B$ 区间最大值为负时，先手取**最小的负数**。

  因此先手只会取区间中四种数之一：最小的负数、最大的负数、最小的非负数、最大的非负数；后手只会根据先手所选数的符号取区间最大值或最小值。用 ST 表维护 $A$ 的「区间最大负数 / 区间最小负数 / 区间最大非负数 / 区间最小非负数」，以及 $B$ 的区间最大 / 区间最小；每轮只有 $4$ 种组合，取最大值即为本轮答案。

**复杂度**：$O(n \log n)$（预处理 + 每轮 $O(1)$）。原文只给了预处理量级，未单独给出总复杂度；多轮询问下整体为 $O(n\log n + q\log n)$。

**易错点**（整理）：
1. 「非负数」与「正数」要分清：0 属于非负数，而 0 在两个方向上的乘法表现都要单独考虑。
2. 区间内不存在某类数（例如没有负数）时，该方案要置为 $-\infty$ 跳过，不能直接参与取 max。
3. 后手的最值要固定按「先手符号」选择，不能无条件取区间最小。

**参考代码**（NOI 风格；本仓库补写）：

```cpp
// CSP-S 2022 T2 策略游戏（洛谷 P8818）
// ----------------------------------------------------------------------------
// 题意：数组 A[1..n]、B[1..m]。每轮给区间 [l1,r1]、[l2,r2]：
//       小 L 先在 A 区间选 x，小 Q 再在 B 区间选 y，得分 x*y。
//       L 最大化、Q 最小化，求最优策略下的得分。多组询问。
//
// 关键结论：
//   固定 x 后，Q 一定取使 x*y 最小的 y：
//     x >= 0 时取 B 区间最小值；x < 0 时取 B 区间最大值。
//   于是本题变成 max_{x in A区间} f(x)，f(x) 关于 x 单调（分段）：
//     - 非负段：f(x)=x*minB，只需看「最小非负数」与「最大非负数」两个端点；
//     - 负数段：f(x)=x*maxB，只需看「最小负数（最负）」与「最大负数（最接近 0）」。
//   因此先手只需考虑 4 种数，ST 表 O(1) 查每类极值 + B 的区间最大/最小。
//
// 注意：某类数不存在时用哨兵 INF / -INF 表示，绝不能让哨兵参与乘法。
// 复杂度：O((n+m) log n) 预处理，O(1) 每次询问。
// ============================================================================
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
const int LOG = 18;
const long long INF = (long long)2e18;    // 2e18 + 2e18 = 4e18 < 9.2e18，不会溢出
const long long NEG = (long long)-2e18;

int n, m, q;
long long A[MAXN], B[MAXN];

struct SparseMax {
    long long st[LOG][MAXN];
    void build(long long *src, int len) {
        for (int i = 1; i <= len; ++i) st[0][i] = src[i];
        for (int j = 1; j < LOG; ++j)
            for (int i = 1; i + (1 << j) - 1 <= len; ++i)
                st[j][i] = max(st[j - 1][i], st[j - 1][i + (1 << (j - 1))]);
    }
    long long query(int l, int r) const {
        int j = 31 - __builtin_clz((unsigned)(r - l + 1));
        return max(st[j][l], st[j][r - (1 << j) + 1]);
    }
};

struct SparseMin {
    long long st[LOG][MAXN];
    void build(long long *src, int len) {
        for (int i = 1; i <= len; ++i) st[0][i] = src[i];
        for (int j = 1; j < LOG; ++j)
            for (int i = 1; i + (1 << j) - 1 <= len; ++i)
                st[j][i] = min(st[j - 1][i], st[j - 1][i + (1 << (j - 1))]);
    }
    long long query(int l, int r) const {
        int j = 31 - __builtin_clz((unsigned)(r - l + 1));
        return min(st[j][l], st[j][r - (1 << j) + 1]);
    }
};

// A 的四类极值表
SparseMin aMinNeg;      // 最小负数（最负）
SparseMax aMaxNeg;      // 最大负数（最接近 0）
SparseMin aMinNonNeg;   // 最小非负数
SparseMax aMaxNonNeg;   // 最大非负数
// B 的区间最值
SparseMin bMin;
SparseMax bMax;

long long tmp[6][MAXN];

int main() {
    freopen("game.in", "r", stdin);
    freopen("game.out", "w", stdout);

    if (scanf("%d %d %d", &n, &m, &q) != 3) return 0;
    for (int i = 1; i <= n; ++i) scanf("%lld", &A[i]);
    for (int i = 1; i <= m; ++i) scanf("%lld", &B[i]);

    for (int i = 1; i <= n; ++i) {
        tmp[0][i] = (A[i] < 0 ? A[i] : INF);    // aMinNeg
        tmp[1][i] = (A[i] < 0 ? A[i] : NEG);    // aMaxNeg
        tmp[2][i] = (A[i] >= 0 ? A[i] : INF);   // aMinNonNeg
        tmp[3][i] = (A[i] >= 0 ? A[i] : NEG);   // aMaxNonNeg
    }
    for (int i = 1; i <= m; ++i) {
        tmp[4][i] = B[i];                        // bMin
        tmp[5][i] = B[i];                        // bMax
    }
    aMinNeg.build(tmp[0], n);
    aMaxNeg.build(tmp[1], n);
    aMinNonNeg.build(tmp[2], n);
    aMaxNonNeg.build(tmp[3], n);
    bMin.build(tmp[4], m);
    bMax.build(tmp[5], m);

    while (q--) {
        int l1, r1, l2, r2;
        scanf("%d %d %d %d", &l1, &r1, &l2, &r2);
        long long lo = bMin.query(l2, r2);   // B 区间最小值
        long long hi = bMax.query(l2, r2);   // B 区间最大值
        long long cand[4] = {
            aMinNeg.query(l1, r1),
            aMaxNeg.query(l1, r1),
            aMinNonNeg.query(l1, r1),
            aMaxNonNeg.query(l1, r1)
        };
        long long best = NEG;
        for (int i = 0; i < 4; ++i) {
            long long x = cand[i];
            if (x <= NEG / 2 || x >= INF / 2) continue;    // 该类数不存在
            long long y = (x >= 0 ? lo : hi);              // Q 的最优反应
            best = max(best, x * y);
        }
        printf("%lld\n", best);
    }
    return 0;
}
```

**验证**：编译零错误；与独立暴力随机对拍 200 组 + 中规模 40 组，全部一致（独立复跑）。⚠️ 无官方数据，仅对拍支撑。

### T3 星战（galaxy）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P8819 |
| 核心考点 | 图论（出度 / 入度）、字符串哈希（集合哈希） |
| 难度 | 省选/NOI− |
| 一句话结论 | 「反攻可行」等价于所有点出度均为 1；用随机权值和维护可合并集合，判定起点集合是否恰为 $\{1..n\}$。 |

**题目大意**：给定 $n$ 个点 $m$ 条边的有向图（虫洞）。支持 4 种操作：修复/摧毁一条边、修复/摧毁一个点的所有入边。每次操作后询问该图是否满足「反攻」条件。

**题解**：

先把题面翻译成图论语言：从每个点出发都能无限次穿梭 $\iff$ 从任意点出发都能走到某个环上；每个点只能有一条从它出发的虫洞 $\iff$ 每个点出度为 1。由出度为 1 的有向图性质（每个点都能走到环上），**反攻可行 $\iff$ 所有点的出度都等于 1**。

- **40 分**：存邻接矩阵，每次操作直接修改并维护各点出度，最后检查 $n$ 个点出度是否都为 1。复杂度 $O(nq)$。
- **60 分（无 4 号操作）**：对每个点维护两个 `set`，分别存完好的入边起点与被摧毁的入边起点。1、2 号操作在 $v$ 的集合间移动 $u$ 并同步修改 $u$ 的出度；3 号操作枚举 $u$ 的所有完好入边逐个摧毁。由于每条边最多被摧毁两次（摧毁两次即说明至少被修复过一次），整体最多摧毁 $m+q$ 条边，配合 `set` 得 $O((m+q)\log n)$。
- **100 分**：`set` 方案在 4 号操作上退化——把坏集合整体搬回好集合时，必须逐条枚举更新起点的入度，超时。

  改用**集合哈希**：取一个足够大的质数 $P$，令 $p_i = P^i$（实际需取模）。集合 $\{1,3,4,5\}$ 的哈希值即 $p_1+p_3+p_4+p_5$，唯一对应；删边就是减 $p_u$，加边就是加 $p_7$，都是 $O(1)$。

  设点 $i$ 的好虫洞起点集合哈希为 $s_i$、坏集合为 $t_i$：

  - 3 号操作后：$s'_i = 0,\ t'_i = s_i + t_i$；
  - 4 号操作后：$s'_i = s_i + t_i,\ t'_i = 0$。

  引入哈希的真正目的是**免去逐点维护出度**：把所有虫洞的起点存成一个可重复集合（期望恰好是大小 $n$ 的不重复集合 $\{1..n\}$），把初始状态的总哈希记为 $Q$，例如起点为 $\{1,1,2,3,5,5,5\}$ 时 $Q = 2p_1+p_2+p_3+3p_5$。则答案为 YES 当且仅当 $Q = p_1+p_2+\cdots+p_n$。

  $Q$ 的维护同样 $O(1)$：1 号操作 $Q \mathrel{-}= p_u$；2 号操作 $Q \mathrel{-}= s_u$；3 号操作 $Q \mathrel{+}= p_u$；4 号操作 $Q \mathrel{+}= t_u$。

  > **校注（重要）**：原文只给了 $Q$ 的四个维护式，**漏掉了坏集合 $t$ 的同步更新**。必须补上：1 号操作 $s_v \mathrel{-}= p_u,\ t_v \mathrel{+}= p_u$；3 号操作 $s_v \mathrel{+}= p_u,\ t_v \mathrel{-}= p_u$。否则「先 1 号摧毁某条边、再 4 号整体修复该点入边」时，$t_v$ 里根本没有这条边，它永远修不回来。$Q$ 的四个式子本身是对的。

**复杂度**：$O(n+m+q)$。哈希带模运算，实践中需用双模数或大随机权值降低碰撞概率。

**易错点**（整理）：
1. 该哈希是概率算法，单模数在毒瘤数据下可能被卡，建议双模数或 `unsigned long long` 自然溢出 + 随机底数。
2. 3 号操作是「摧毁 $u$ 的**所有入边**」，$Q$ 上体现为 $+p_u$；4 号是「修复 $u$ 的所有入边」，体现为 $+t_u$——方向别写反。
3. 目标状态是所有点出度为 1，对应起点集合恰为 $\{1,2,\dots,n\}$，而不是「每个点入度都是 1」。

**参考代码**（NOI 风格；本仓库补写）：

```cpp
// CSP-S 2022 T3 星战（洛谷 P8819）
// ----------------------------------------------------------------------------
// 题意：n 个点、m 条有向边（虫洞）。四种操作：
//   1 u v : 摧毁边 u->v          3 u v : 修复边 u->v
//   2 u   : 摧毁据点 u（即摧毁 u 的所有「还未被摧毁」的入边）
//   4 u   : 修复据点 u（即修复 u 的所有「已被摧毁」的入边）
// 每次操作后回答：是否能反攻（YES/NO）。
//
// 结论：反攻可行 <=> 每个点的出度恰好为 1。
//   （出度为 1 的有向图，从任意点沿唯一出边必走进一个环，可无限穿梭；反之，若
//    某点出度不为 1，要么无边可走、要么切换虫洞不唯一，均不满足条件。）
//
// 做法：维护所有「可用虫洞」的起点可重集合 S（按起点计权）。初始 S 中每个 u
//       出现 outdeg(u) 次。反攻可行 <=> S 恰为 {1,2,...,n} 各一次。
//       集合哈希：给点 i 随机权 p[i]（64 位），S 的哈希 Q = Σ_{u∈S} p[u]；
//       目标 T = Σ p[i]。每次操作 O(1) 更新 Q，判 Q == T 即可。
//       s[u] = u 的可用入边的起点权值和；t[u] = u 的已摧毁入边的起点权值和。
//         op1: s[v] -= p[u], Q -= p[u]
//         op2: t[u] += s[u], Q -= s[u], s[u] = 0
//         op3: s[v] += p[u], Q += p[u]
//         op4: s[u] += t[u], Q += t[u], t[u] = 0
// 复杂度：O(n + m + q)，unsigned long long 自然溢出。
// ============================================================================
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 100005;
typedef unsigned long long ull;

int n, m, q;
ull p[MAXN];    // 每个点的随机权
ull s[MAXN];    // 可用入边（起点）权值和
ull t[MAXN];    // 已摧毁入边（起点）权值和

int main() {
    freopen("galaxy.in", "r", stdin);
    freopen("galaxy.out", "w", stdout);

    scanf("%d %d", &n, &m);

    mt19937_64 rng(chrono::steady_clock::now().time_since_epoch().count());
    ull target = 0;
    for (int i = 1; i <= n; ++i) {
        p[i] = rng();
        target += p[i];
    }

    ull Q = 0;                                  // 全部可用虫洞的起点哈希
    for (int i = 0; i < m; ++i) {
        int u, v;
        scanf("%d %d", &u, &v);
        s[v] += p[u];
        Q += p[u];
    }

    scanf("%d", &q);
    while (q--) {
        int op;
        scanf("%d", &op);
        if (op == 1 || op == 3) {
            int u, v;
            scanf("%d %d", &u, &v);
            // 单条边的摧毁/修复要同时维护「坏集合」t，否则 4 号操作无法把它修复
            if (op == 1) { s[v] -= p[u]; t[v] += p[u]; Q -= p[u]; }
            else         { s[v] += p[u]; t[v] -= p[u]; Q += p[u]; }
        } else {
            int u;
            scanf("%d", &u);
            if (op == 2) { t[u] += s[u]; Q -= s[u]; s[u] = 0; }
            else         { s[u] += t[u]; Q += t[u]; t[u] = 0; }
        }
        puts(Q == target ? "YES" : "NO");
    }
    return 0;
}
```

**验证**：编译零错误；与独立暴力随机对拍 200 组 + 中规模 180 组，全部一致（独立复跑）。注意：本解**依赖题面保证**——操作 1、3 给出的边必然分别处于可摧毁 / 已损毁状态；若喂入违反该保证的数据（对已修复的边再次修复），集合哈希会重复累加而判错。⚠️ 无官方数据，仅对拍支撑。

### T4 数据传输（transmit）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P8820 |
| 核心考点 | 树链问题、动态 DP、广义矩阵乘法 + 倍增 |
| 难度 | 省选/NOI− |
| 一句话结论 | 按 $k=1/2/3$ 分类，把路径上的 DP 转移写成 $(\min,+)$ 广义矩阵，用倍增沿「朝上 / 朝下」两段分别合并。 |

**题目大意**：给定一棵 $n$ 个结点的树，点有点权。在树上移动时一次最多跳 $k$ 条边（$1 \le k \le 3$），每次落脚都要付出该点的点权（起点、终点都算）。$Q$ 次询问，每次求从 $s$ 到 $t$ 的最小总花费。

**题解**：

$k$ 很小（$1 \le k \le 3$），按 $k$ 分类讨论：

- $k=1$：不能跳过任何点，只能沿简单路径直接走。
- $k=2$：落脚点必然都在 $s \to t$ 的简单路径上。想绕开路径上的下一个点 $u$ 而拐进 $u$ 的儿子 $v$ 是没意义的——从 $v$ 仍只能走到 $u$ 的下一个点 $w$，而从当前点可以直接到 $w$。
- $k=3$：同理，走到下一个点的儿子或孙子都没意义，落脚点只会是简单路径上的点，或这些点的邻接点。

分档做法：

- **8 分**：DFS 枚举下一个落脚点（建议先预处理距离 $\le k$ 的点集）。
- **24 分（$k=1$）**：答案就是树上路径点权和。求 LCA 后用差分求路径和。
- **44 分（$k=2$，$n$ 较小）**：把路径拉出来做线性 DP。设 $f[i]$ 为从起点出发、最后落在路径第 $i$ 个点的最小花费，$t_i$ 为第 $i$ 个点点权，则
  $$f[i] = \min(f[i-1], f[i-2]) + t_i$$
  （原文此处写作 $\min(f[i-1],f[i-1])$，为重复笔误，按 $k=2$ 的语义应为 $\min(f[i-1],f[i-2])$——**校注**。）答案为路径末点的 $f$。
- **76 分（$k=3$，$n$ 较小）**：对路径上每个点的**邻接点** $i$ 设 $g[i]$ 表示「从起点出发、最后停在第 $i$ 个点的邻接点」的最小时间（示意图见原文）。设 $c_i$ 为 $i$ 的邻居的最小处理时间，则有
  $$f[x_i] = \min\{f[x_{i-1}], f[x_{i-2}], f[x_{i-3}], g[x_{i-2}], g[x_{i-1}]\} + a[x_i]$$
  $$g[x_i] = \min\{f[x_{i-1}], f[x_{i-2}], g[x_{i-1}]\} + c[x_i]$$
  每次询问要访问路径上所有点及其邻接点，复杂度 $O(nq)$。
- **100 分**：用**倍增**预处理 DP 转移，把合并代价降到 $O(\log n)$。重定义矩阵乘法为
  $$a_{i,j} = \min_k \{b_{i,k} + c_{k,j}\}$$
  即 $(\min,+)$ 广义矩阵乘法，满足结合律。

  - $k=2$ 时转移写成 $2\times 2$：
    $$\begin{bmatrix} f_i \\ f_{i-1} \end{bmatrix} = \begin{bmatrix} a_i & a_i \\ 0 & \infty \end{bmatrix} \cdot \begin{bmatrix} f_{i-1} \\ f_{i-2} \end{bmatrix}$$
  - $k=3$ 时若直接用 $5\times 5$ 矩阵，单次乘法需 $5^3$ 次操作，无法接受。**简化 DP 方程**后：$g[x_i]$ 与 $f[x_{i-1}]$ 到 $x$ 的距离都是 1，二者只需保留较小值；同理 $g[x_{i-2}]$ 与 $f[x_{i-2}]$ 也只需保留较小值。令 $f[x_i][t]$ 表示从起点到距离 $x_i$ 为 $t$ 个单位的点的最小点权和：
    $$f[x_i][0] = \min\{f[x_{i-1}][0], f[x_{i-1}][1], f[x_{i-1}][2]\} + a[x_i]$$
    $$f[x_i][1] = \min\{f[x_{i-1}][0], f[x_{i-1}][1]\} + c[x_i]$$
    $$f[x_i][2] = \min\{f[x_{i-1}][1], f[x_{i-2}][0]\}$$
    由于在 $x_{i-1}$ 处已用 $f[x_{i-2}][0]$ 更新过 $f[x_{i-1}][1]$，可直接取 $f[x_i][2] = f[x_{i-1}][1]$。于是只需 $3\times 3$ 转移矩阵：
    $$\begin{bmatrix} f[x_i][0] \\ f[x_i][1] \\ f[x_i][2] \end{bmatrix} = \begin{bmatrix} a[x_i] & a[x_i] & a[x_i] \\ 0 & c[x_i] & \infty \\ \infty & 0 & \infty \end{bmatrix}\begin{bmatrix} f[x_{i-1}][0] \\ f[x_{i-1}][1] \\ f[x_{i-1}][2] \end{bmatrix}$$
    倍增维护左侧的矩阵 $A_{x_i}$，初始列向量为起点 $x_0$ 的向量：
    $$\begin{bmatrix} f[x_0][0] \\ f[x_0][1] \\ f[x_0][2] \end{bmatrix} = \begin{bmatrix} a[x_0] \\ \infty \\ \infty \end{bmatrix}$$

  由于是**树上路径**，DP 转移的起点与终点不能互换，因此要把路径拆成「朝上」和「朝下」两部分分别用倍增计算 DP 值，维护的矩阵也需要用两个倍增数组分别维护朝上 / 朝下的矩阵信息。

**复杂度**：$$O\big((q+n)\log n \cdot k^3\big)$$

**易错点**（整理）：
1. 路径必须拆成朝上 / 朝下两段，两段的矩阵方向相反；合并顺序错了会得到反向路径的答案。
2. 广义矩阵乘法的单位矩阵是「对角为 0、其余为 $\infty$」，初始化容易写错。
3. 起点和终点的点权都要计入，初始化列向量只对 $f[x_0][0]$ 赋值、其余为 $\infty$。
4. $k=3$ 时不要直接用 $5\times 5$，必须先化简到 $3\times 3$ 才能过时限。

**参考代码**（NOI 风格；本仓库补写）：

```cpp
// CSP-S 2022 T4 数据传输（洛谷 P8820）
// ----------------------------------------------------------------------------
// 题意：树上 n 个点，点权 a[i]。一次移动最多跳 k 条边（k<=3），每次落脚都要
//       付出落脚点权值（起点、终点都算）。q 次询问 s->t 的最小总花费。
//
// 关键观察（沿简单路径 x0=s, x1, ..., xL=t 走）：
//   * 落脚点只需是「路径上的点」或「路径上某点的邻居」。
//     跳到路径点的孙子辈一定不优：k=3 时从当前点可直接跳到再往后的路径点。
//   * 状态：dp[t] 表示「最后一次落脚点距当前路径点为 t」时的最小花费，t=0,1,2。
//     t=2 只是距离记账，用来支持「连跳三步」。
//
// 转移（从 x_{i-1} 到 x_i，记 a=a[x_i]，mn=mn[x_i] 为 x_i 邻居的最小点权）：
//   dp'[0] = a  + min(dp[0], dp[1], dp[2])
//   dp'[1] = min(dp[0], dp[1] + mn)
//   dp'[2] = dp[1]
// 写成 (min,+) 广义矩阵：
//   | a   a   a  |
//   | 0   mn  INF|
//   | INF 0   INF|
// 初值 dp = (a[s], INF, INF)，答案 = 路径走完后 dp[0]。
//
// k=2： | a  a |       k=1：直接路径点权和（前缀和 + LCA）。
//       | 0 INF|
//
// 树上路径要拆成「朝上」和「朝下」两段，矩阵不可交换，因此需要两套倍增表：
//   upB[j][u] = M[top] ⊗ ... ⊗ M[u]（2^j 个，自下而上应用）
//   upE[j][u] = M[u] ⊗ ... ⊗ M[top]（2^j 个，自上而下应用）
// 复杂度 O((n + q) log n * k^3)，k<=3。
// ============================================================================
#include <bits/stdc++.h>
using namespace std;

const int MAXN = 200005;
const int MAXLOG = 18;                 // 2^17 = 131072，2^18 > 2e5
const long long INF = (long long)1e18; // 最大真实花费 2e5*1e9 = 2e14

int n, q, K;
long long a[MAXN];
vector<int> g[MAXN];

int dep[MAXN], par[MAXN];
int anc[MAXLOG][MAXN];
long long mnv[MAXN];        // 邻居最小点权
long long sumw[MAXN];       // 根到该点的点权和（k=1 用）

int D;                      // 矩阵阶数：k=2 用 2，k=3 用 3
struct Mat {
    long long v[3][3];
};
Mat ID;                     // (min,+) 单位矩阵：对角 0，其余 INF

inline Mat mul(const Mat &A, const Mat &B) {
    Mat R;
    for (int i = 0; i < D; ++i)
        for (int j = 0; j < D; ++j) {
            long long best = INF;
            for (int t = 0; t < D; ++t)
                best = min(best, A.v[i][t] + B.v[t][j]);
            R.v[i][j] = best;
        }
    return R;
}

// 每套表 18 * 2e5 * 9 * 8B ≈ 259MB，两套共约 518MB（本题内存限制 1GB）
Mat upB[MAXLOG][MAXN];
Mat upE[MAXLOG][MAXN];
Mat Mof[MAXN];              // 每个点自己的转移矩阵

inline void applyVec(long long *vec, const Mat &A) {
    long long res[3];
    for (int i = 0; i < D; ++i) {
        long long best = INF;
        for (int t = 0; t < D; ++t) best = min(best, A.v[i][t] + vec[t]);
        res[i] = best;
    }
    for (int i = 0; i < D; ++i) vec[i] = res[i];
}

int lca(int u, int v) {
    if (dep[u] < dep[v]) swap(u, v);
    int dif = dep[u] - dep[v];
    for (int j = 0; j < MAXLOG; ++j)
        if (dif >> j & 1) u = anc[j][u];
    if (u == v) return u;
    for (int j = MAXLOG - 1; j >= 0; --j)
        if (anc[j][u] != anc[j][v]) { u = anc[j][u]; v = anc[j][v]; }
    return par[u];
}

int main() {
    freopen("transmit.in", "r", stdin);
    freopen("transmit.out", "w", stdout);

    if (scanf("%d %d %d", &n, &q, &K) != 3) return 0;
    for (int i = 1; i <= n; ++i) scanf("%lld", &a[i]);
    for (int i = 1; i < n; ++i) {
        int u, v;
        scanf("%d %d", &u, &v);
        g[u].push_back(v);
        g[v].push_back(u);
    }

    // ---------- 建树（迭代 BFS，避免递归爆栈） ----------
    for (int i = 1; i <= n; ++i) mnv[i] = INF;
    par[1] = 0; dep[1] = 0; sumw[1] = a[1];
    {
        static int que[MAXN];
        int head = 0, tail = 0;
        que[tail++] = 1;
        while (head < tail) {
            int u = que[head++];
            for (int v : g[u]) {
                if (v == par[u]) continue;
                par[v] = u;
                dep[v] = dep[u] + 1;
                sumw[v] = sumw[u] + a[v];
                que[tail++] = v;
            }
        }
    }
    // 邻居最小点权（包含父亲与所有儿子）
    for (int u = 1; u <= n; ++u)
        for (int v : g[u]) mnv[u] = min(mnv[u], a[v]);
    if (K == 3) for (int u = 1; u <= n; ++u) if (mnv[u] == INF) mnv[u] = INF;

    if (K == 1) {
        // ---------- k = 1：只能沿路径逐点走 ----------
        for (int u = 0; u <= n; ++u)
            for (int j = 0; j < MAXLOG; ++j) anc[j][u] = 0;
        for (int i = 1; i <= n; ++i) anc[0][i] = par[i];
        for (int j = 1; j < MAXLOG; ++j)
            for (int i = 1; i <= n; ++i) anc[j][i] = anc[j - 1][anc[j - 1][i]];
        while (q--) {
            int s, t;
            scanf("%d %d", &s, &t);
            int l = lca(s, t);
            printf("%lld\n", sumw[s] + sumw[t] - 2 * sumw[l] + a[l]);
        }
        return 0;
    }

    // ---------- 建矩阵 ----------
    D = (K == 2 ? 2 : 3);
    for (int i = 0; i < D; ++i)
        for (int j = 0; j < D; ++j) ID.v[i][j] = (i == j ? 0 : INF);

    for (int u = 0; u <= n; ++u)
        for (int i = 0; i < D; ++i)
            for (int j = 0; j < D; ++j) Mof[u].v[i][j] = ID.v[i][j];
    for (int u = 1; u <= n; ++u) {
        Mat &m = Mof[u];
        m.v[0][0] = m.v[0][1] = m.v[0][2] = a[u];
        m.v[1][0] = 0;
        m.v[1][1] = (K == 2 ? INF : mnv[u]);
        m.v[1][2] = INF;
        m.v[2][0] = INF;
        m.v[2][1] = 0;
        m.v[2][2] = INF;
    }

    // ---------- 倍增预处理 ----------
    for (int u = 0; u <= n; ++u) anc[0][u] = par[u];
    for (int u = 0; u <= n; ++u) { upB[0][u] = Mof[u]; upE[0][u] = Mof[u]; }
    for (int j = 1; j < MAXLOG; ++j) {
        for (int u = 0; u <= n; ++u) {
            int mid = anc[j - 1][u];
            anc[j][u] = anc[j - 1][mid];
            upB[j][u] = mul(upB[j - 1][mid], upB[j - 1][u]);   // 上段 ⊗ 下段
            upE[j][u] = mul(upE[j - 1][u], upE[j - 1][mid]);   // 下段 ⊗ 上段
        }
    }

    // ---------- 回答询问 ----------
    while (q--) {
        int s, t;
        scanf("%d %d", &s, &t);
        int l = lca(s, t);
        long long vec[3] = {a[s], INF, INF};

        int d1 = dep[s] - dep[l];          // 朝上：parent(s) ... l
        int cur = par[s];
        for (int j = 0; j < MAXLOG; ++j)
            if (d1 >> j & 1) {
                applyVec(vec, upB[j][cur]);
                cur = anc[j][cur];
            }

        int d2 = dep[t] - dep[l];          // 朝下：child(l) ... t
        if (d2 > 0) {
            Mat P = ID;
            cur = t;
            for (int j = 0; j < MAXLOG; ++j)
                if (d2 >> j & 1) {
                    P = mul(P, upE[j][cur]);
                    cur = anc[j][cur];
                }
            applyVec(vec, P);
        }
        printf("%lld\n", vec[0]);
    }
    return 0;
```
