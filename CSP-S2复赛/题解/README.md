### 总览分册的结构

| 章节 | 内容 |
| --- | --- |
| 分册入口 | 5 份年份分册的跳转表 |
| 一 | 说明与来源（5 篇原文链接、转写口径、版权） |
| 二 | 五年 20 题总览表（洛谷题号 / 核心算法 / 难度）+ **验证状态总表** |
| 三 | 按算法分类索引（贪心 / DP / 图论 / 字符串 / 数据结构 / 模拟）+ 难度递增练习顺序 |
| 四 | 待办与后续 |

每题包含：题名与英文目录名、洛谷题号、核心考点、难度、一句话结论、题目大意、**分档题解**（保留原文的分数档，如「40 分 / 65 分 / 100 分」）、复杂度、易错点、参考代码。年份分册里另加「本场速览」表与「页内跳转」，方便在一场 4 题之间跳。

## 源文件与重新生成

分册与合订本都由同一批分片生成，**改内容只改分片，不要直接改产物**：

```
题解/
├── 分册/                              # 交付物①：按年份拆分（自动生成）
│   ├── 00-总览与索引.md               #   说明 + 总览表 + 验证状态 + 分类索引
│   └── 2025.md 2024.md 2023.md 2022.md 2021.md
├── CSP-S复赛真题题解（2021-2025）.md   # 交付物②：合订本（自动生成）
├── README.md                          # 本文件
├── _build.py                          # 构建脚本：一次生成上面两种形态
├── _check_links.py                    # 校验：所有相对链接与页内锚点是否可达
├── _head.md                           # 前言：说明 + 总览表 + 分类索引
├── _tail.md                           # 结尾：待办与后续
└── _parts/
    ├── 2025.md  ├── 2024.md  ├── 2023.md  ├── 2022.md  └── 2021.md
```

重新生成并自检：

```bash
cd CSP-S2复赛/题解
python3 _build.py        # 合订本 + 分册全部重写
python3 _check_links.py  # 74 条相对链接/锚点全部可达才算通过
```
