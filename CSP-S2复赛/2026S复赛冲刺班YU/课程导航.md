区间工具的选择顺序（先问，再选）：

```text
只有区间和？
→ 前缀和

很多区间加，最后统一看？
→ 差分

静态区间 max/min/gcd，查询很多？
→ ST 表

中途有单点修改？
→ Fenwick 或线段树（按信息类型）

区间修改 + 区间查询？
→ 线段树 + lazy

二维矩形覆盖面积？
→ 扫描线（先认识）
```

## 先修关系

课件顺序不等于学习顺序。四节课之间真实存在的依赖是：

```text
建图 / DFS
   ↓
DFN（理解子树连续）
   ↓
并查集 ──→ Kruskal ──→ 最短路
   ↓
前缀和 / 差分 ──→ 二分答案
   ↓
朴素 DP ──→ 前缀和优化 ──→ bitset / 最值优化
   ↓
ST 表 ──→ 线段树 ──→ lazy / 扫描线
```

层级越靠上，越应该先做到"关掉课件能独立写"。缺先修时补先修，比在缺先修的情况下背 ST 或 lazy 的模板更有用；对应可运行代码见[范例代码](../备考/范例代码/README.md)，工具触发条件见[考场工具箱](../备考/考场工具箱/README.md)。

## 课程资料的边界

- 课件中的环境、IDE、目录结构、`freopen` 习惯属于**培训经验**，不是考试规则；规则以当年官方通知、准考证与题面为准，见[赛制与考场纪律](../../CSP-JS通用/赛制与考场纪律.md)。
- 课件里的题型统计与"重点预测"是历史归纳，不构成押题。
- 课堂讲过不等于会写：判断标准仍是独立解释、手算、独立实现与自测，见[掌握验收与复盘](../备考/考场工具箱/09_掌握验收与复盘.md)。
