## 怎么读一个工具

每项都按同一条顺序展开：**解决什么问题 → 一个小例子逐步变化 → 为什么这样做不会漏解或重复 → 代码每步对应什么 → 复杂度与边界 → 关掉说明自己解释一遍**。

不要从模板开始背。例如：差分先理解"起点生效、终点后撤销"；Dijkstra 先跟踪堆中新旧距离的替换；bitset 先画可达集合整体平移。优先级只决定先学谁，已写进本目录的工具都保持可查。

## 三个使用约束

- **07／08 含思路与题解提示**，在未见题模拟前翻阅，会把"能想到"变成"见过"；先做，再看。
- **06 的提示分级 P0–P4** 用于记录"用了几级提示"，与"这道题会不会"分开记。
- **本目录不产出成绩与进度**：等级 0–3 只是掌握程度描述，实际结论以独立实现、对拍与评测记录为准。

## 掌握等级

| 等级 | 判据 |
| --- | --- |
| 0 | 只听过名字 |
| 1 | 能看懂小例子 |
| 2 | 能手算并解释为什么 |
| 3 | 能关掉说明独立写、自己测过 |

只有到 3 且隔日复测仍成立，才算稳定；当天看着参考代码写出来，不构成 3。
