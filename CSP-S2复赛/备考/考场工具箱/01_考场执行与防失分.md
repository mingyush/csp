# 考场执行与防失分

> 更新：2026-10-19。建议打印或考前默写；本文是练习清单，入场携带物品以官方规定为准。

[返回总导航](README.md)

## 240 分钟怎样分配

| 时间（相对开考）   | 动作               | 留下什么                |
| ---------- | ---------------- | ------------------- |
| 0–15 分钟    | 扫四题、读完整输出格式和子任务表 | 每题一个候选做法、复杂度、能覆盖的条件 |
| 15–100 分钟  | 做最有把握的题或子任务      | 至少一份编译、自测通过的源程序     |
| 100–170 分钟 | 兑现第二个可靠得分点       | 可回退的稳定版本；不按题号硬耗     |
| 170–220 分钟 | 修复已知错误，补低成本子任务   | 新版与稳定版核对；收益不明就停止改动  |
| 220–240 分钟 | 全部最终检查           | 最终路径中的源码逐份编译、检查输入输出 |

这是练习用时间框架，可随题目调整；最后 20 分钟检查应保留。同一方向 15–20 分钟无实质进展，立即重估。

## 秒决定继续还是换题

1. 我能用一句话说清输出要求吗？尤其是多问、字典序、严格大于、取模。
2. 我能手算一个例子并写出最慢的正确做法吗？
3. 最小子任务允许多少次操作、多少内存？特殊性质如何在输入中判断？
4. 我能在接下来 15 分钟实现、编译、自测吗？不能就缩小目标或换题。

## 五类失分检查

| 类别       | 先检查                      | 必做动作                           |
| -------- | ------------------------ | ------------------------------ |
| CE 编译失败  | 分号、括号、头文件、变量名、语言标准       | 保存后重编译，确认退出成功；旧可执行文件能跑不代表新源码正确 |
| RE 崩溃或异常 | 数组越界、空容器、递归深度、除零         | 用最小规模、链、极端下标测试；先判断范围再访问        |
| TLE 超时   | 循环次数、重复查询、未推进的指针、频繁 endl | 用最大规模估算和实测；把重复计算预处理            |
| WA 答错    | 漏题意条件、严格/非严格、初始化、溢出      | 从反例逐步手算；改后重跑旧反例                |
| 输出与文件错误  | 多输出一行、调试语句、文件名/目录/重定向    | 在最终目录跑一遍，人工打开实际输出文件            |

`long long ans = a*b` 不能防止两个 int 先相乘溢出，需 `1LL*a*b`。链状树递归可能爆栈；普通图只传父节点不足以防止环，需访问标记。

## 最后 20 分钟交卷核查

- [ ] 当前编辑的文件已保存；最终源码在要求目录，不是仅保存在桌面或备份中。
- [ ] 逐题核对英文题名、大小写、扩展名；目录里仅保留要求的程序源文件。
- [ ] 按题面要求选择文件输入输出或标准输入输出；需要 `freopen` 时，两处文件名都已核对。
- [ ] 在 NOI Linux 中重新编译最终源码，编译成功后才运行；不拿旧二进制当结果。
- [ ] 样例、最小例、边界例通过；完整输出格式正确，去掉调试输出。
- [ ] 类型能容纳中间乘法、累加与无穷大；数组长度按最大实际下标计算。
- [ ] 最后一次修改后重新验证；工作备份放在提交目录外。

## 考务信息从哪来

考场时间、考点、准考证下载窗口、目录命名与禁带物品，逐年逐省都会变；本文只给**需要提前核对哪几项**，具体数值一律以当年官方通知、准考证和考场现场说明为准：

| 核对项 | 要问清楚的 | 常见出错 |
| --- | --- | --- |
| 时间与考点 | 开考时刻、建议到达时刻、考点地址 | 只看开考时间，低估路上与安检耗时 |
| 证件 | 报名所用证件、是否需要打印准考证 | 只带电子版或只带复印件 |
| 目录与命名 | 顶层目录命名规则、下层是否按题目英文名 | 把练习目录结构直接照搬 |
| 编译环境 | 是否要求 NOI Linux 编译通过、有无指定标准 | Windows 上能过就认为考场也能过 |
| 禁带物品 | 书籍、草稿纸、电子设备的具体范围 | 按"以前可以"携带 |

赛制差别、入场与离场规则见 [赛制与考场纪律](../../../CSP-JS通用/赛制与考场纪律.md)；文件读写、提交目录与爆零清单见 [防爆零与提交检查清单](../../../CSP-JS通用/复赛通用/防爆零与提交检查清单.md)。
