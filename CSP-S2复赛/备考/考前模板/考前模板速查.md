# CSP-S 考前模板速查

> 用途：考前一天把"有把握的模板"过一遍触发条件与边界，不是用来临时背新算法。
> **任何代码文件、电子设备或纸质资料都不得带入考场**；这里的内容只用于考前学习。

配套完整函数：[`templates.cpp`](templates.cpp)（7 个函数，注释精简）· [`templates_中文详注版.cpp`](templates_中文详注版.cpp)（逐段中文讲解，适合第一次读懂）

## 用哪一版

| 场景 | 打开 |
| --- | --- |
| 想确认某个函数怎么写、接口是什么 | `templates.cpp` |
| 想弄懂为什么这么写、什么时候不能用 | `templates_中文详注版.cpp` |
| 已经在考场上 | 都不打开，凭记忆写 |

两个文件都是**函数库，没有 `main()`**，不是某道题的完整程序。抄用时只取需要的函数，并补齐它依赖的 `#include <bits/stdc++.h>`、`using namespace std;`、`using ll = long long;`，再按题意写读入输出。把整个合集当作一题答案必然编译不过或逻辑错误。

编译环境提示：`<bits/stdc++.h>` 是 GCC 专有头文件，NOI Linux 自带；macOS 自带 clang 没有它，需换成对应标准头文件才能通过语法检查。这与[万能头文件与命名冲突避坑](../../../CSP-JS通用/复赛通用/万能头文件与命名冲突避坑.md)里列的兼容性问题同源。

## 触发条件与边界

| 模板 | 看到什么会想到它 | 它不能直接做什么 | 手算自测 |
| --- | --- | --- | --- |
| 并查集 DSU | 无向连通、合并集合、最小生成树 | 最短路、动态删除边 | `unite(1,2)`、`unite(2,3)` → `find(1)==find(3)` |
| Dijkstra | **非负权**图、单源最短路 | 负权边、最长路 | `1→3(1)`、`3→2(2)`、`1→2(5)` → `dist[2]=3` |
| 树状数组 Fenwick | 单点增减，频繁求前缀／区间和 | 通用区间最小值、任意区间赋值 | `add(1,5)`、`add(4,6)` → `sum(4)=11` |
| 快速幂 | `a^b mod p` | `b` 为负、无取模的大整数幂 | `modPow(2,10,1000000007)=1024` |
| 拓扑排序 | 有向图先后依赖、DAG | 无向连通、一般最短路 | `1→2→3` → `[1,2,3]` |
| KMP 前缀函数 | 前后缀、周期、单模式匹配 | 多模式匹配不能靠它替代自动机 | `prefixFunction("ababaca")` → `[0,0,1,2,3,0,1]` |
| Manacher | **连续**回文子串、最长回文长度 | 回文子序列、回文构造 | `"abba"→4`；`"abc"→1`；`"abacaba"→7` |

## 三处最容易写错的地方

- **下标基准**：模板里图与 Fenwick 一律按 `1..n` 编号；题面给 `0..n-1` 时要么整体平移，要么改 `lowbit` 的循环起点，混用会出现死循环或少算第一项。
- **整数范围**：`dist`、`ans`、DP 值用 `long long`；中间乘法写 `1LL*a*b`——`long long ans = a*b` 挡不住两个 `int` 先相乘。
- **Manacher 的哨兵**：该版本用 `@ # $` 作分隔与边界，原串含这三个字符时会算错；字母串通常安全，自造数据要注意。

## 考场优先级

先说清"这题我能稳定写到哪一档"，再决定是否引入新模板：

1. 审题找最省力的得分点；
2. 写能独立运行、输出契约完整的正确版本；
3. 数据范围超出时才换算法或加优化；
4. 留出独立编译与逐题检查的时间。

考前只挑 2–3 个"学过但容易写错"的模板复现一遍；完全陌生的高级算法不适合在最后一天硬背，代价是挤掉已有题目的检查时间。
