# 2026S 复赛模拟（XES）

模考题目、标程、题解与题面处理工具的公共存放处。

| 路径 | 内容 |
| --- | --- |
| `模考1/T1` ~ `T4` | 题面 Markdown（公式可渲染）+ `images.json` 图片转写清单 |
| `模考1/题面预览.html` | 由 `tools/convert/preview.py` 生成的预览页 |
| `模考2/T2_谁能下到100层_可视化闯关.html` | 模考 2 T2 的交互式闯关讲解（单文件、离线可用） |
| `CSP-S 复赛模考 1 标程 & 题解/` | 模考 1 各分数档标程（含部分分做法）与题解 PDF |
| `CSP-S 复赛模考 2 标程 & 题解/` | 模考 2 同上；其中的 `勘误.md` 说明 T2 复杂度与 T3 距离恒等式的条件 |
| `tools/convert/` | 题面 HTML→Markdown 转换、图片转文字、预览与自检 |

## 标程命名与题号

逐题代码统一使用 `T题号_题名（分数档，做法）.cpp`，按文件名排序时先按 T1–T4 分组；原有分数档、做法说明与代码内容保持不变。整卷题解与讲义 PDF 保留原名。

| 题号 | 模考 1 | 模考 2 |
| --- | --- | --- |
| T1 | 配对数组 | 截取密信 |
| T2 | 安全接线 | 谁能下到100层 |
| T3 | 字符串生成器 | 站岗 |
| T4 | 极差之和 | 种萝卜 |

例如 `T1_配对数组（100 分，差分数组）.cpp` 与 `T2_谁能下到100层（100 分，单调栈）.cpp`。同一道题有多个分数档，可对照当前能完成的做法选择阅读。

个人作答代码与成绩记录不在本库维护。
