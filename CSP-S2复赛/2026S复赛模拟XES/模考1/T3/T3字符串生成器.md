# 字符串生成器

> 时间限制：1s　内存限制：256M

## 题目描述

你需要实现一个字符串生成器，根据一个规则串和一个模板串，来生成一个字符串。

具体地，给定一个长度为 $n$ 的、仅由字符 $\texttt{0}$ 和 $\texttt{1}$ 构成的规则串 $s$，以及一个长度为 $m$ 的、由小写字母构成的模板串 $t$。生成器要生成一个长度为 $n + m - 1$ 的、由小写字母构成的字符串 $w$，并且对于每个下标 $i$（$1 \le i \le n$），都满足：

- 若 $s_i = \texttt{1}$，则 $w$ 的子串 $w_i w_{i+1} \cdots w_{i+m-1}$ 必须**等于** $t$；
- 若 $s_i = \texttt{0}$，则 $w$ 的子串 $w_i w_{i+1} \cdots w_{i+m-1}$ 必须**不等于** $t$。

这里，两个等长字符串满足**等于**关系是指：它们在每一位上的字符都相同，即对任意下标 $1 \le k \le m$，都有 $w_{i+k-1} = t_k$；同理，两个等长字符串满足**不等于**关系，则是指它们不满足上述相等条件，即：存在至少一个下标 $1 \le k \le m$，使得 $w_{i+k-1} \neq t_k$。

由于满足条件的字符串 $w$ 可能有多个，你需要生成其中字典序最小的那一个。如果不存在满足条件的字符串，输出 $-1$。

对于两个等长字符串，从左到右比较，第一个不同的位置上字符更小的字符串的字典序更小，例如：$\texttt{aab} < \texttt{ab}$。

## 输入格式

第 $1$ 行，一个仅含 $\texttt{0}$、$\texttt{1}$ 的字符串 $s$，表示规则串。

第 $2$ 行，一个由小写字母构成的字符串 $t$，表示模板串。

## 输出格式

输出一行一个字符串，表示字典序最小的满足条件的字符串 $w$；若不存在，输出 $-1$。

## 输入输出样例

### 样例 #1

**输入#1**

```text
1010
ab
```

**输出#1**

```text
ababa
```

### 样例 #2

**输入#2**

```text
11
ab
```

**输出#2**

```text
-1
```

## 说明提示

**【样例解释 1】**

规则串 $s = \texttt{1010}$，模板串 $t = \texttt{ab}$，需要生成长度 $4+2-1=5$ 的字符串 $w$。

- $s_1=\texttt{1}$：$w_1 w_2 = \texttt{ab}$；
- $s_2=\texttt{0}$：$w_2 w_3 \neq \texttt{ab}$；
- $s_3=\texttt{1}$：$w_3 w_4 = \texttt{ab}$；
- $s_4=\texttt{0}$：$w_4 w_5 \neq \texttt{ab}$。

可以验证 $w = \texttt{ababa}$ 满足全部条件，且字典序最小。

**【样例解释 2】**

$s_1=\texttt{1}$ 要求 $w_1 w_2=\texttt{ab}$，$s_2=\texttt{1}$ 要求 $w_2 w_3=\texttt{ab}$，即 $w_2$ 既要等于 $\texttt{b}$ 又要等于 $\texttt{a}$，矛盾，故无解。

## 数据范围

对于全部数据，$1 \le n, m \le 10^6$，$s$ 仅含字符 $\texttt{0}$、$\texttt{1}$，$t$ 仅含小写字母。
