## 使用建议

1. **先做后看**：整卷限时 3.5 小时（4 题），做完再对题解，避免边看边写。
2. **按分数档复盘**：`../题解/` 与模拟卷标程按“分数档 + 做法”命名，定位自己是卡在部分分还是正解。
3. **只缺答案的年份**：2021—2022 试卷以在线题库为准，题解合订本中仍保留逐题讲解。
