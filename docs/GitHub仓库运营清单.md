## 一、为什么需要这份清单

GitHub 的曝光有三个入口，仓库里的文档只能解决其中一个：

| 入口 | 决定因素 | 能靠文件改吗 |
| --- | --- | --- |
| 站内搜索 | 仓库名、description、topics、README 关键词、star 数、更新时间 | ❌ 一半要在网页设置 |
| topic 标签页 | `topics` 是否命中别人在点的标签 | ❌ 网页设置 |
| 站外引流 | 洛谷／知乎／公众号／B站／QQ 群 | ❌ 靠人投放 |

下面是逐项的可粘贴配置。

## 二、About 面板（仓库首页右上角 ⚙️）

### Description（约 200 字符，中英双关键词）

```text
CSP-J/S 学习资料库：2013—2025 初赛/复赛真题、S 组 2021—2025 逐题题解、考点频次统计与备考清单 | CSP-J/S (China) past papers, solutions & study notes
```

要点：
- **前 60 字符**是搜索结果里实际显示的部分，所以「CSP-J/S + 真题 + 题解」必须排在最前；
- 带上英文词（past papers / solutions）能吃到英文检索，也让非中文用户看懂这是什么；
- 年份范围写死（2013—2025），搜「2025 CSP 真题」时能命中。

### Website

```text

```

（没有独立站点时，指向「最新 Release」比留空好——访客少一步找下载。）

## 三、功能开关

| 开关 | 位置 | 建议 | 理由 |
| --- | --- | --- | --- |
| **Discussions** | Settings → General → Features | ✅ 开启 | 0 issue 的仓库看起来像弃坑；Discussion 里的报错与讨论会被搜索引擎索引，也能把一次性访客变成参与者 |
| Issues | 同上 | ✅ 保持开启 | 已有，别关 |
| Wiki | 同上 | ❌ 关闭 | 现在是空的，空 Wiki 反而降低可信度；内容都在 `docs/` 里 |
| Projects | 同上 | ❌ 关闭 | 同上 |
| Social preview | Settings → General → Social preview | 上传 `assets/social-preview.png`（1280×640） | 链接被贴到公众号／知乎／群里时，有图比没图点击率高得多 |
| Allow forking | Settings → General → Danger Zone 上方 | ✅ 保持开启 | fork 数本身是热度信号 |

**开启 Discussions 后**建两个分类就够：`Q&A`（题目求助）和 `Ideas`（资料建议）。第一个讨论可以自己发一条：「题解勘误集中帖」，把已有勘误列进去——让新访客看到这里有人在维护。

## 四、Release：让不装 Git 的人也能拿资料

### 步骤

```bash
# 1. 打包（产物在 dist/，已被 .gitignore 忽略）
python3 tools/make_release.py

# 2. 打 tag 并推送
git tag -a v2026.10 -m "2026 年 10 月资料快照"
git push origin main --tags

# 3. 网页：Releases → Draft a new release → 选 tag v2026.10
#    上传 dist/*.zip，标题与说明用下面模板
```

### Release 说明模板

```markdown
## 2026 年 10 月资料快照

本次更新：题解拆为总览 + 5 份年份分册；新增复赛临考指南与模考 3 分档标程。

**不想 clone 的，直接下附件：**

| 附件 | 内容 | 大小 |
| --- | --- | --- |
| `csp-s1-papers.zip` | J1 + S1 初赛真题（2013—2025） | 见附件 |
| `csp-s2-solutions.zip` | S 组复赛 2021—2025 逐题题解（含分册） | 见附件 |
| `csp-s2-papers.zip` | S 组复赛真题、冲刺班与模拟考 | 见附件 |
| `csp-full.zip` | 全仓库快照 | 见附件 |

完整变更见 [CHANGELOG](../blob/main/CHANGELOG.md)。发现问题请提 Issue。
```

### 为什么要做这件事

仓库约 178MB，`git clone` 对网络差的同学是硬门槛；**附件下载量是可观测的传播指标**，比 star 更早反映「有没有人真的在用」。

## 五、站外投放：决定天花板的其实是这一步

GitHub 只是落点。中文 OI 圈的流量在下面这几个地方，而且**季节性极强**：

| 时间窗 | 事件 | 该发什么 |
| --- | --- | --- |
| 8 月底—9 月第 2 周 | 初赛备考期（流量峰 1，全年最高） | 「2013—2025 J1 全部真题」「S1 五年考点频次图」 |
| 9 月第 3 周 | 初赛考完当天 | 「2026 初赛 J1/S1 真题 + 逐题答案」——抢 24 小时 |
| 10 月第 2 周 | 复赛备考期（流量峰 2） | 「20 题分档题解」「防爆零清单」 |
| 10 月下旬 | 复赛考完 | 「2026 复赛 T1—T4 题解」——抢 72 小时 |
| 其余时间 | 平峰 | 补旧年份、修勘误，攒素材不发帖 |

### 渠道优先级

1. **洛谷讨论区 / 犇犇**：目标人群 100% 命中，但规则严——**必须是干货帖，不能纯广告**。写法：贴一张考点频次图 + 三段方法，末尾一句「完整资料在这里」。
2. **知乎**：搜「CSP-J/S 怎么准备」「信息学竞赛入门」下已有问题写长回答，末尾放链接。新问题没人看，去老问题下补答。
3. **微信公众号**：找 OI 类号（备考、竞赛升学向）投稿或请求转载，比自建号快。
4. **B站**：备考 vlog／讲题视频的简介与置顶评论，成本高但长尾最好。
5. **QQ 群 / 贴吧**：只发「有 XX 需求的自取」，别刷屏，容易被踢。

### 让别人替你传播（最省力的一招）

不要群发广告，去私信 2—3 个**已经在写 CSP 内容**的博主／公众号，话术：

```text
老师您好，我在维护一个 CSP-J/S 资料库 github.com/mingyush/csp，
里面 2013—2025 的 J1 真题是全的，S 组复赛 2021—2025 有逐题分档题解，
还有一张五年考点频次统计图（可自由取用，MIT）。
您写相关文章如果需要素材可以直接拿去，不用署名。
有收录错误也欢迎告诉我。
```

要点：**先给东西，再提请求**；明确说可以自由使用（LICENSE 已经允许）；不要求转发。被引用一次胜过自己在群里发十次。

| 指标 | 现在（2026-10-27） | 说明 |
| --- | --- | --- |
| Star | 76 | 存量 |

| Watcher | 1 | 几乎没人期待更新——这是最该补的一项，靠 Release + CHANGELOG 节奏感来养 |
| Issue | 0 | 看起来像没人用，开 Discussions 后可缓解 |
| Release | 0 | 没有版本锚点，访客无法判断「这库还在维护吗」 |

真正要盯的**不是 star 总量，而是「每次考季窗口的增量」**。如果 2027 年 9 月窗口能带来 50+ star，说明渠道打通了；如果只有个位数，问题在投放而不是内容。

## 七、风险项

- **第三方材料**：`CSP-S2复赛/2026S复赛冲刺班YU/`、`2026S复赛模拟XES/`、`参考资料/hello-algo*.pdf` 均为他人版权内容。已在 [NOTICE.md](../NOTICE.md) 声明「仅学习参考、权利人可要求 48 小时内移除」，但**公开托管本身仍有被投诉的可能**。若收到投诉，优先删除争议文件而不是争辩，保住整个仓库。
- **个人隐私**：仓库公开，任何准考证、成绩、证书、个人训练记录都不得提交（`.gitignore` 已挡 `MY/`）。
- **真题准确性**：CCF 不公开第一轮原件，早期初赛卷与 2025 卷来自社区整理，务必在文首保留来源与免责说明。
