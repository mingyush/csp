# 项目文档治理与隐私隔离

> 更新日期：2026-09-12
> 适用范围：公开 CSP 学习资料仓库

## 一、项目边界

资料按是否适合公开共享，使用两个独立 Git 项目隔离：

| 项目 | 可存放内容 | 禁止存放内容 |
| --- | --- | --- |
| 公开 `csp` | 真题、参考答案、通用知识点、备考方法、公开课程资料、项目治理文档 | 身份材料、成绩、证书、个人目标、个人训练记录及其他可识别个人的信息 |
| 私有个人项目 | 个人证书、成绩、训练卷、打卡、错题记录和个人计划 | 无需重复存放的公开题库与通用资料 |

公开仓库的判断标准：换一位考生使用，内容是否仍然完整适用，且不包含任何个人识别信息。不能同时满足时，文件只能进入私有项目。

## 二、目录职责

```text
csp/
├── README.md          # 总导航、年度信息与核心资料入口
├── docs/              # 公开仓库治理规则
├── CSPJ/              # CSP-J 通用资料
├── CSPS/              # CSP-S 通用资料
├── NOI/               # 官方大纲与竞赛环境资料
└── 参考资料/           # 第三方公开资料，必须标注来源
```

- 真题目录同时存在多个版本时，必须提供 README，说明来源、可信度和推荐使用顺序。
- 攻略文档按“长期总纲、趋势分析、阶段执行、临考速查”分工，避免重复维护规则和结论。
- 个人化分数目标与进度不得写入通用攻略，只保留设置目标的方法。

## 三、隐私防护

公开仓库 `.gitignore` 固定忽略 `MY/`，但忽略规则不能替代提交前检查。

每次提交前执行：

```bash
git status --short
git diff --cached --check
git diff --cached --name-only
```

重点检查文件名和内容是否包含：

- 姓名、证件号、学校、照片、签名、二维码、准考证号；
- 个人成绩、证书、入围材料、承诺书；
- 含个人信息的 PDF、Word、Excel、图片及其预览文件；
- 本地工具配置、编辑器目录与可再生缓存。

## 四、历史清理记录

2026-09-12 已完成以下处理：

1. 从公开仓库提取个人目录及其自身历史，建立独立私有项目。
2. 对公开仓库所有本地分支和标签执行历史过滤，删除个人目录及相关 Git 对象。
3. 清除本地遗留快照引用与 reflog，并重新打包对象库。
4. 在公开仓库加入 `MY/` 忽略规则，清理当前文档中的失效目录引用。
5. 公开远程只保留清理后的 `main` 历史；任何旧克隆都不得直接推回，应重新克隆或基于新历史迁移改动。

## 五、后续维护清单

- 新增资料：确认来源、版权、适用组别、年份和是否含个人信息。
- 更新赛制：优先引用 NOI/CCF 官方通知，并区分全国规则与各省细则。
- 发布前：检查 Markdown 本地链接、`git diff --check` 和未跟踪文件。
- 敏感文件误提交：立即停止继续推送，先迁移私有副本，再过滤全部相关路径并强制更新远程。
- 历史被重写后：通知所有协作者重新克隆，防止旧历史再次合并进入公开仓库。
