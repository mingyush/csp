# 复赛考前检查清单

> 适用范围：CSP-J2 与 CSP-S2 共用。考前的"备齐东西"与"定死习惯"不受组别影响，本节规则不区分组别。
> 证件、文具、入场时间等安排各省、各考点有差别，以准考证和考点通知为准。本清单是通用项，按实际情况增删。

考前一周能改变结果的，只剩两种丢分：东西没备齐、习惯没定死。知识上的差距短期补不了，这些漏洞短期足够补完。打印出来逐项打勾，考前一晚再过一遍。

## 一、考生要定死的 5 项

- [ ] **文件读写模板定稿**。`freopen` 两行闭眼能敲出来；从今天起每次模拟用同一份，不临场改写法。写法与目录结构见 [防爆零与提交检查清单](防爆零与提交检查清单.md) 第二、三、六节。
- [ ] **Linux 流程过三遍**。至少在 NOI Linux 里完整写三道题，熟悉编译、运行、看输出与 Windows 下的差异。环境见 [`NOI-Linux 装机及使用`](../../NOI/NOI-Linux/NOI-Linux2.0装机及使用.md)。
- [ ] **对拍脚本背熟**。数据生成器 + 暴力程序 + 对比，十行左右。它能把"样例过了但不确定对不对"变成"确定对不对"，对应 [防爆零清单](防爆零与提交检查清单.md) 第六节里的"造过一组 n=1、一组最大数据"。
- [ ] **手造数据验证**。样例过了不算过，再造两组小数据手算——这是全场性价比最高的几分钟。
- [ ] **计时靠钟不靠手机**。考场不能带手机，平时模拟就用钟表计时。"单题时间预算"这条线（分钟级分配见 [复赛分钟级时间表](复赛分钟级时间表.md)），做到眼睛扫一眼时钟就能判断。

## 二、家长要落实的 4 项

- [ ] **证件与文具，提前确认**。准考证怎么领、是否带身份证件、能带什么，以准考证和考点通知为准；今天查清楚，别拖到考前。
- [ ] **路线倒推一遍**。考试日通常是周末，早高峰不堵，但考点周边停车难；按入场时间倒推，至少提前 45 分钟到。
- [ ] **中午提前看一个吃饭的地方**。上午场出考场后别现找；别吃太饱。
- [ ] **考完那句问话换一换**。别问"考得怎么样"，改问"时间分配执行得怎么样"——前者只能换来"还行"，后者能对出卡在哪一段。

## 三、考前一周的"三不"

- **不换编辑器**：临场换工具只会增加不适应。
- **不学新算法**：考场上用得上的概率不大，还要搭进去本来就紧的熟练度。这几天练的是"已会的东西更快更稳"，不是新东西。
- **不熬夜刷题**：睡眠直接影响临场判断，熬夜的边际收益为负。

## 四、考前一晚与考试当天早

| 节点 | 做法 |
| --- | --- |
| 考前一晚 | 只看不写。清单过一遍，模板过一眼，早点睡。这天写新代码没有收益，只增加焦虑 |
| 考试当天早 | 吃平常的早饭。进考场试机时把模板敲一遍——不是检查电脑，是把手热了 |
