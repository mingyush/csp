# 复赛分钟级时间表

> 适用范围：CSP-J2（08:30—12:00，210 分钟）与 CSP-S2（14:30—18:30，240 分钟）共用同一套分配逻辑，S 组多出的 30 分钟见第六节。
> 具体入场、试机、收卷时间以准考证和考点通知为准。本表是通用节奏，可按强弱微调，建议先通读四题、卡住时按预算换题、最后 10 分钟只检查；表内时段是预算，并非每题都要用满。

## 一、先看清这 210 分钟

4 题平均 52 分钟一道，听起来宽裕。**平均分配是考场上最贵的错误**：第一题可能 30 分钟拿满，第四题花 90 分钟也可能 0 分。

问题不是"每题花多久"，而是"这几分钟放哪道题上最值钱"。

## 二、分钟级时间表

| 时间段 | 分钟 | 动作 |
| --- | --- | --- |
| 08:30—08:50 | 20 | **读题**。一行代码都别写。四道题各用一句话概括，每题在纸上写三行：输入、输出、数据范围。第三行决定你能拿几分 |
| 08:50—09:00 | 10 | **排序**。按"多久能拿到分"排，不按题号排（A 能拿满、B 会写暴力、C 只会特判） |
| 09:00—09:40 | 40 | **第一题，硬上限 40 分钟**。前 10 分钟用笔在纸上写流程，别直接敲键盘。样例过了不算完，自己造两组小数据手算一遍 |
| 09:40—10:25 | 45 | **第二题，25 分钟见分晓**。25 分钟没过样例，先把暴力写完存好转第三题。别把第三题的时间吃掉——这是最常见的崩盘方式 |
| 10:25—10:35 | 10 | **停。是真的停**。在座位上喝水、放松视线，遵守考场纪律；顺手把已写好的两题重编译一遍，确认没被改坏 |
| 10:35—11:25 | 50 | **第三题，只要暴力分**。O(n²) 能过就交 O(n²)，别一上来想正解；卡满 20 分钟就再降一档，能特判几个点就特判几个点 |
| 11:25—11:50 | 25 | **第四题，只看最小那档数据**。多数人这题 0 分。翻到题面最后看 n≤10 那档写个暴搜，能过几分是几分，纯赚 |
| 11:50—12:00 | 10 | **不写新代码**。① 四个源文件在不在、名字对不对　② 文件读写开关状态对不对　③ 四份重编译看有没有报错　④ 过了样例的代码一个字都别改 |

最后 10 分钟的检查项，文件读写与文件名的坑见 [防爆零与提交检查清单](防爆零与提交检查清单.md) 第一、二、六节；突发处理见 [考场急救卡](复赛考场急救卡.md)。

## 三、看到数据范围，就知道写什么

完整对照表（含内存、子任务分档）见 [防爆零与提交检查清单](防爆零与提交检查清单.md) 第五节。考场上够用的速判：

| 数据范围 | 能写的做法 |
| --- | --- |
| n ≤ 10 | 全排列、暴搜 |
| n ≤ 20 | 状压 DP 或折半搜索 |
| n ≤ 100 | O(n³)，区间 DP、Floyd |
| n ≤ 1000 | O(n²)，普通 DP |
| n ≤ 1e5 | O(n log n)，排序、二分、线段树 |
| n ≤ 1e6 | O(n)，前缀和、双指针 |
| n ≤ 1e18 | 数学、快速幂、找规律 |

**反过来也有用**：你写的复杂度和范围对不上，就说明这题现在拿不到满分——先拿暴力分，别硬刚。这一个判断，比多想十分钟有用。

## 四、卡住时的三条规矩

1. **连续 40 分钟无进展就换题**。到点保存、转下一题；表内较长时段可用于已有进展的编码和验证。
2. **样例过了、手造数据不过，停手**。先写暴力，两份程序跑同一组随机数据对拍；肉眼盯代码定位不了错（对拍写法见 [防爆零清单](防爆零与提交检查清单.md)）。
3. **只剩 20 分钟还是 0 分，立刻写特判**。先让这题不是 0 分。

这三条的价值，是把"要不要放弃"变成事先定好的动作。考场上临时做这个决定通常做错——因为不甘心。更细的突发处理见 [考场急救卡](复赛考场急救卡.md)。

## 五、先写暴力不是认输，是算账

```
两题满分 + 两题暴力   ≈  200 + 60  = 260 分
一题死磕 + 三题 0 分   ≈  100 + 0   = 100 分
```

差别不是"保守"和"激进"，是 260 和 100。

CSP 是 OI 赛制，交上去没有任何反馈，你判断不了"再调十分钟能不能出正解"。复赛不是"会不会"的考试，是"210 分钟能拿多少分"的考试。

## 六、S 组多出来的 30 分钟

全给第三、第四题，别摊到前两题。前两题是必须拿满的，多给也提不了多少；三四题的正解常值 60—70 分，是唯一值得"多想一会儿"的地方。另外 S 组下午考，中午别吃太饱（家长事项见 [考前检查清单](复赛考前检查清单.md) 第二节）。

## 七、考前模拟节奏

- 做 **2 次整场模拟**，严格 08:30 掐表、中途不加时；大概率会崩，崩了正好暴露问题。
- 中间几天 **只练暴力**：近三年真题的三、四题全用最笨的方法写一遍，目标是快，不是过。
- 第二次模拟只对照本表，看哪一段超时了。
- 考前一晚 **只看不写、早点睡**；具体纪律见 [考前检查清单](复赛考前检查清单.md) 第三、四节。

## 八、家长能帮的三件事

1. 打印本表贴书桌旁。不用讲道理，看得见就行。
2. 模拟考那天只报 **08:50、09:40、10:25** 三个时间点，别问"写完几题了"。
3. 考前一周不改代码习惯、不换编辑器、不改模板（与 [考前检查清单](复赛考前检查清单.md) 的"三不"一致）。
