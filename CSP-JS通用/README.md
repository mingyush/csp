## 二、什么材料放这里

一条判据：**只对某一个组别或某一轮成立的，留在组内；换组别、换轮次仍然成立的，放这里。**

| 材料特征 | 归属 |
| --- | --- |
| 赛制、考场纪律、证件与禁带要求 | 通用（四组） |
| 文件重定向、提交目录、爆零清单 | 通用（两轮复赛） |
| STL 等语言级工具用法 | 通用（两轮复赛） |
| 答题卡填涂 | 通用（两轮初赛，本库现有上海版） |
| 知识点体系、难度评级、分题策略 | 组内（J 与 S 深度不同） |
| 历年真题、逐题题解、机构模拟卷 | 组内（按年份和组别区分） |

三级目录名沿用四组一致的 `真题 / 模拟 / 备考`；通用目录不套用这一层，因为它没有"年份"和"组别"两个维度。

## 三、维护约定

- 通用内容只在这里改一次。组内文档遇到通用部分，写成"见通用清单"并给出相对链接，不复制正文。
- 通用目录下的文件不属于第三方资料堆：第三方原书留在 `参考资料/`，讲义 PDF 留在课程原始目录，本目录只做索引和自编整理。
- 新增通用材料时，同步更新本页表格与根目录 [README](../README.md) 的两处索引。
