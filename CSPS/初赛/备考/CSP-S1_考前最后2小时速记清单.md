## 0～20 分钟：复杂度 + C++ / 位运算

### 1. 常见复杂度

| 代码 / 算法 | 复杂度 |
|---|---:|
| 一次循环 `1..n` | `O(n)` |
| 两层独立 `1..n` | `O(n²)` |
| `i *= 2` / `i /= 2` | `O(log n)` |
| 二分 | `O(log n)` |
| 排序 | 通常 `O(n log n)` |
| DFS / BFS | `O(V+E)` |
| Dijkstra + heap | `O((V+E)logV)` |
| Kruskal | `O(E log E)` |
| 并查集 | 近似 `O(1)` |
| 哈希查询 | 平均 `O(1)`，最坏 `O(n)` |
| 堆插入 / 删除 | `O(log n)` |
| 线段树查询 / 修改 | `O(log n)` |
| Trie 插入 / 查询 | `O(|s|)` |
| KMP | `O(n+m)` |

特别警惕：

```cpp
for (int i = 1; i <= n; i *= 2)
```

复杂度：

\[
O(\log n)
\]

而：

```cpp
for (int i = 1; i <= n; i++)
    for (int j = i; j <= n; j += i)
```

总次数：

\[
n+\frac n2+\frac n3+\cdots+\frac nn
=O(n\log n)
\]

**不是 `O(n²)`。**

### 2. 递归式快速判断

\[
T(n)=2T(n/2)+O(n)
\Rightarrow O(n\log n)
\]

\[
T(n)=2T(n/2)+O(n^2)
\Rightarrow O(n^2)
\]

\[
T(n)=T(n/2)+O(1)
\Rightarrow O(\log n)
\]

---

### 3. 位运算必记

```cpp
x & 1          // 判断奇偶
x << k         // × 2^k
x >> k         // / 2^k（非负整数）
(x >> k) & 1   // 第 k 位
x & (x - 1)    // 删除最低位的 1
```

XOR：

```text
a ^ a = 0
a ^ 0 = a
a ^ b ^ a = b
```

优先级不确定时：

> **加括号，不靠记忆猜。**

# 20～45 分钟：树 + 数据结构

## 1. 二叉树遍历

### 前序

```text
根 → 左 → 右
```

### 中序

```text
左 → 根 → 右
```

### 后序

```text
左 → 右 → 根
```

关键：

> **前序 / 后序确定根，中序确定左右子树。**

---

## 2. BST 二叉搜索树

性质：

```text
左子树 < 根 < 右子树
```

BST **中序遍历一定有序**。

---

## 3. 完全二叉树

数组下标从 1 开始：

```text
父亲：i / 2
左儿子：2i
右儿子：2i + 1
```

如果节点数为 `n`：

```text
i <= n / 2
```

通常才可能有孩子。

---

## 4. Heap 堆

### 小根堆

```text
父节点 <= 子节点
```

堆顶最小。

### 大根堆

```text
父节点 >= 子节点
```

堆顶最大。

注意：

> **堆不是 BST。**

堆只保证父子关系，不保证：

```text
左子树 < 根 < 右子树
```

---

## 5. Trie

一句话：

> **Trie 是前缀树。**

若有：

```text
apple
app
apply
```

它们会共享前缀：

```text
app
```

复杂度通常和字符串长度有关：

\[
O(|s|)
\]

---

## 6. 线段树

只记四件事：

```text
① 围绕“区间”
② 查询 O(log n)
③ 单点修改 O(log n)
④ 空间通常开 4n
```

典型场景：

```text
区间和
区间最大值
区间最小值
```

---

# 45～70 分钟：图论——最高优先

## 1. DFS vs BFS

### DFS

```text
一路走到底，再回退
```

常见：

```text
递归
栈
连通块
搜索
树遍历
```

### BFS

```text
一层一层扩展
```

常见：

```text
队列
无权图最短路
层次
```

---

## 2. 图复杂度

邻接表：

\[
DFS/BFS = O(V+E)
\]

邻接矩阵：

\[
O(V^2)
\]

---

## 3. 拓扑排序

仅适用于：

> **DAG：有向无环图**

经典做法：

```text
找入度 = 0 节点
→ 删除
→ 更新邻居入度
→ 再找入度 = 0 节点
```

如果最后不能删除全部节点：

> 有环。

---

## 4. Dijkstra

适合：

> **非负边权最短路**

核心状态：

```cpp
dist[v]
```

过程：

```text
取当前距离最小的点
→ 用它更新邻居
```

若出现负边：

> 普通 Dijkstra 不可靠。

高频组合：

```text
Dijkstra + priority_queue
```

---

## 5. MST 最小生成树

### Kruskal

一句话：

> **按边权从小到大选边，但不能成环。**

常配：

```text
并查集
```

### Prim

一句话：

> 从一个连通块不断接入最近的新点。

注意：

> MST 求的是连接所有点的最小总代价，不是起点到终点最短路。

---

## 6. 并查集

三个关键词：

```text
find
union
是否同集合
```

典型用途：

```text
判断成环
连通块
Kruskal
```

---

## 7. LCA

最近公共祖先：

> 两个节点共同祖先中，深度最大的那个。

考试若只是给树手算：

> 沿祖先链往上找即可。

# 70～90 分钟：DP + 二分 + 贪心

## 1. 动态规划

看到 DP，先问：

> **`dp[i][j]` 到底表示什么？**

按顺序：

```text
① 状态定义
② 初值
③ 状态转移
④ 循环顺序
⑤ 答案位置
```

---

## 2. 0/1 背包

每件物品：

```text
只能选 0 次或 1 次
```

一维写法：

```cpp
for each item
    for (j = V; j >= w; --j)
```

必须：

> **容量倒序。**

如果正序，很可能会让同一物品使用多次，变成完全背包效果。

---

## 3. LCS

最长公共子序列。

注意：

> **子序列不要求连续。**

典型转移：

如果：

```text
a[i] == b[j]
```

则：

\[
dp[i][j] = dp[i-1][j-1] + 1
\]

否则：

\[
dp[i][j] = \max(dp[i-1][j], dp[i][j-1])
\]

---

## 4. LIS

最长上升子序列。

同样：

> 不要求连续。

---

## 5. 二分

最危险的地方：

```text
边界错 1
```

看到代码先确定：

> **这个二分到底在找什么？**

常见：

```text
第一个 >= x
最后一个 <= x
第一个满足 check 的位置
```

不要机械套：

```cpp
l = mid + 1
r = mid
```

---

## 6. 贪心

遇到题先问：

> “每次取当前最好”真的能保证全局最好吗？

典型能贪：

```text
活动选择
Huffman
Kruskal
部分调度
分数背包
```

典型不能简单贪：

```text
0/1 背包
```

# 90～105 分钟：字符串 + 数学

## 1. KMP

只记三件事：

### ① 用途

> 字符串模式匹配。

### ② `next / prefix` 的核心含义

> 当前前缀中，最长的“相等真前缀 = 真后缀”的长度。

### ③ 复杂度

\[
O(n+m)
\]

最大的意义：

> **文本指针不需要反复回退。**

---

## 2. 排列组合

### 排列：有顺序

\[
A_n^m = \frac{n!}{(n-m)!}
\]

### 组合：无顺序

\[
C_n^m = \frac{n!}{m!(n-m)!}
\]

牢记：

\[
C_n^m = C_n^{n-m}
\]

---

## 3. “至少一个”

优先想到：

> **补集。**

例如“至少一个成功”：

\[
1-P(\text{一个都不成功})
\]

---

## 4. 容斥

两个集合：

\[
|A\cup B|
=
|A|+|B|-|A\cap B|
\]

三个集合：

```text
单个之和
- 两两交集
+ 三者交集
```

---

## 5. GCD

Euclid：

\[
gcd(a,b)=gcd(b,a\bmod b)
\]

例如：

```text
gcd(48, 18)
48 % 18 = 12
18 % 12 = 6
12 % 6 = 0
答案 6
```

---

## 6. 模运算

\[
(a+b)\%p
\]

\[
(a\times b)\%p
\]

可以分别先取模。

但：

> **除法不能直接这么做。**

这时才会涉及逆元。

## 2. 排序表

| 算法 | 平均 | 最坏 | 稳定 |
|---|---:|---:|---|
| 冒泡 | `n²` | `n²` | ✅ |
| 插入 | `n²` | `n²` | ✅ |
| 选择 | `n²` | `n²` | ❌ |
| 快排 | `n log n` | `n²` | ❌ |
| 归并 | `n log n` | `n log n` | ✅ |
| 堆排 | `n log n` | `n log n` | ❌ |

必须特别记：

> **快排最坏 `O(n²)`**  
> **归并稳定**  
> **堆排不稳定**

## 2. 阅读程序

固定流程：

