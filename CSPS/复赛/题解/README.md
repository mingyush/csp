## 源文件与重新生成

主文档由分片合并而成，改完分片后重跑构建脚本即可：

```
题解/
├── CSP-S复赛真题题解（2021-2025）.md   # 交付物（自动生成，勿直接编辑）
├── README.md                          # 本文件
├── _build.py                          # 合并脚本
├── _head.md                           # 合订本前言：说明 + 总览表 + 分类索引
├── _tail.md                           # 合订本结尾：待办与后续
└── _parts/
    ├── 2025.md  ├── 2024.md  ├── 2023.md  ├── 2022.md  └── 2021.md
```

重新生成：

```bash
cd CSPS/复赛/题解
python3 _build.py
```

> 修改内容请改 `_parts/*.md` 或 `_head.md` / `_tail.md`，不要直接改主文档——下次构建会覆盖。
