### T1 密码锁（lock）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P9752 |
| 核心考点 | 枚举 |
| 难度 | 普及− |
| 一句话结论 | 直接枚举全部 $10^5$ 个候选正确密码，逐个判断能否「一次转动」得到给定的全部 $n$ 个状态。 |

**题目大意**：小 Y 有一把五个拨圈的密码锁，每个拨圈上是 $0\sim 9$ 的数字，且是循环的（即 $9$ 拨动一个位置后可以变成 $0$ 或 $8$）。锁车方式是：从正确密码开始随机转动密码锁仅一次，每次以某个幅度仅转动一个拨圈，或者同时转动两个相邻的拨圈；同时转动两个相邻拨圈时幅度相同（例如可以把 $00115$ 转成 $11115$，但不会转成 $12115$）。小 Y 记下了锁车后密码锁的 $n$ 个状态，且这 $n$ 个状态都不是正确密码。问有多少种可能的正确密码，使得每个正确密码都能按照该锁车方式产生这全部 $n$ 个状态。数据范围 $1 \le n \le 8$；特殊性质 A：保证所有正确密码都可以通过仅转动一个拨圈得到给出的 $n$ 个状态。

**题解**：

- **部分分（$n=1$）**：输出样例（$81$）即可。
- **满分做法**：枚举所有可能的密码，然后判断这 $n$ 个状态是否都可以由它得到即可。考虑计算需要花费的时间：密码共有 $10^5$ 个，每个密码通过转动可以得到 $81$ 种不同的状态，因此需要处理的状态共 $8.1\times10^6$ 个，所以完全可以在 $1$ 秒内运行完成。

**复杂度**：枚举 $10^5$ 个候选密码，每个密码生成 $81$ 个可达状态并与输入的 $n$ 个状态比对，总运算量约 $8.1\times10^6$（原文指出可在 $1$ 秒内完成）。

**易错点**（整理）：
1. 转动幅度有 $9$ 种（不含幅度 $0$）。单个拨圈可任选 $1$ 个：$5\times9=45$ 种；两个相邻拨圈同幅度同方向：$4\times9=36$ 种；合计恰好 $81$ 种，三者对不上说明枚举漏了情况。
2. 两个拨圈必须是**相邻**的（只有 $1\text{-}2,2\text{-}3,3\text{-}4,4\text{-}5$ 四组），且必须转动**相同幅度、相同方向**，不能只转其中一个。
3. 判断的是「所有 $n$ 个状态都能由**同一个**正确密码一次转出」，而不是分别判断每个状态的可达密码数再相加。

### T2 消消乐（game）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P9753 |
| 核心考点 | 字符串（栈消除）、性质推导、前缀状态维护 |
| 难度 | 提高 |
| 一句话结论 | 记 $p(i)$ 为「以 $i$ 开头的最短可消除子串右端点」，则答案为 $\sum_i\big(f(p(i)+1)+1\big)$；用「$g(i)$ 与 $g(p(i)+1)$ 只差一处」的性质可在 $O(n)$ 内求出所有 $p(i)$。 |

**题目大意**：小 L 在玩一个一维的消消乐，一次只能消除两个相邻的元素。给定一个长度为 $n$、仅由小写字母构成的字符串 $s$，称一个字符串是**可消除**的当且仅当可以通过若干次操作把它变成空串，其中每次操作可以删除两个相邻的相同字符、删后剩余字符串拼接在一起。求 $s$ 的所有非空连续子串中有多少个是可消除的。数据范围 $1 \le n \le 2\times10^6$；特殊性质 A：字符串中的每个字符独立等概率地从字符集中选择；特殊性质 B：字符串仅由 `a` 和 `b` 构成。

**题解**：

- **部分分（$n \le 800$）**：$O(n^2)$ 枚举每个子串，并在 $O(n)$ 的时间内判断其是否可消除。判定的关键是：遇到两个相邻的相同字符可以直接删除它们，用栈维护即可——对每个字符，若与栈顶字符相同则弹出栈顶，否则将字符入栈；由于若与栈顶不同则不可能进行任何消除，所以单次 $O(n)$ 判定正确。期望得到 $35$ 分。
- **发掘性质**：用 $s[l:r]$ 表示字符串 $s$ 第 $l$ 个字符到第 $r$ 个字符构成的子串。若 $s[l:r]$ 和 $s[l:p]\ (p<r)$ 都是可消除的，则 $s[p+1:r]$ 是可消除的。
  **证明**：考虑使用栈 $O(n)$ 判断的过程。由于 $s[l:p]$ 是可消除的，因此当模拟 $s[l:r]$ 时，考虑完第 $p$ 个字符后栈必然为空，因此 $s[p+1:r]$ 会从空栈开始；而 $s[l:r]$ 可消除，因此 $s[p+1:r]$ 可消除。
- **部分分（$n \le 8000$）**：上述性质告诉我们：虽然从 $i$ 开始的子串有很多都是可消除的，但我们只需要关注**长度最小**的那个就可以了。因为如果 $s[i:j]$ 和 $s[i:k]\ (j<k)$ 都可消除，那么 $s[i:k]$ 可以拆成 $s[i:j]$ 和 $s[j+1:k]$ 这两个可消除的子串，然后使用计数方法进行统计。
  因此记 $p(i)$ 表示 $s[i:j]$ 是可消除的最小的 $j$。当 $n \le 8000$ 时，$p(i)$ 可以使用栈暴力在 $O(n)$ 的时间内计算（对每个 $i$ 从 $i$ 开始扫一遍）。
  最后考虑计数，设 $f(i)$ 表示 $s$ 从 $i$ 开始有多少个子串是可消除的。则这些串可以分为两类：一类是 $s[i:p(i)]$，共一个；另一类是 $s[i:k]\ (p(i)<k)$，由性质可拆成 $s[p(i)+1:k]$，共 $f(p(i)+1)$ 个。最后总答案为
  $$f(1)+f(2)+\cdots+f(n)$$
  这样就在 $O(n)$ 的时间内完成了计数，总复杂度 $O(n^2)$。
- **快速计算 $p(i)$，得到正解**：如果 $s_i = s_{i+1}$，则显然 $p(i) = i+1$；下面考虑 $s_i \ne s_{i+1}$ 的情况。
  考虑到 $s[i+1:p(i)-1]$ 是可消除的，并且 $s_{p(i)} = s_i$，因此可以设 $g(i,c)$ 表示满足 $s[i:j]$ 是可消除的、并且满足 $s_{j+1} = c$ 的最小的 $j$，则不难发现 $p(i) = g(i+1, s_i)$。
  问题归结为如何快速计算 $g(i,c)$。由于 $s[i:p(i)]$ 可消除，因此对于任意的 $k$，如果 $s[p(i)+1:k]$ 可消除，则 $s[i:k]$ 可消除。考察 $g(i,c)$ 与 $g(p(i)+1,c)$ 的差异，不难发现：当 $c \ne s_{p(i)+1}$ 时 $g(i,c) = g(p(i)+1,c)$；当 $c = s_{p(i)+1}$ 时 $g(i,c) = p(i)+1$。因此 $g(i)$ 与 $g(p(i)+1)$ **只有一处差别**，而 $s$ 仅包含小写字母，所以可以对每个 $c$ 遍历来更新 $g(i,c)$。
  设 $\Sigma$ 表示字符集大小，这里只有小写字母，因此 $\Sigma = 26$。时间复杂度为 $O(n\Sigma)$。
- **还可以更快**：由于 $g(i,*)$ 与 $g(p(i)+1,*)$ 只有一处差别，由性质我们可以得到一个更加强大的结论：对于任意的 $i \ne j$ 都满足 $p(i) \ne p(j)$。
  **证明**：假设 $p(i) = p(j) = k,\ i<j$，则 $s[i:k]$ 和 $s[j:k]$ 都可消除，于是 $s[i:j+1]$ 可消除，与 $p(i)$ 的定义矛盾。
  因此 $g(i)$ 可以直接在 $g(p(i)+1,*)$ 上对那唯一的一处不同做修改得到（即共享同一份状态、退出时再撤销修改）。因此对于这一题，时间复杂度可以做到 $O(n)$；如果将题目中的 $\Sigma$ 修改得更大，则可以使用 `map` 做到 $O(n\log\Sigma)$ 的时间复杂度。

**复杂度**：$O(n)$（字符集固定为 $26$ 时可做到线性；一般字符集用 `map` 为 $O(n\log\Sigma)$）。

**易错点**（整理）：
1. $p(i)$ 是**闭区间**右端点，计数递推为 $f(i) = 1 + f(p(i)+1)$，写成 $f(p(i))$ 会重复计数。
2. $g(i,c)$ 中的 $c$ 指的是**右端点右侧**那个字符 $s_{j+1}$，转移要区分 $c = s_{p(i)+1}$ 与 $c \ne s_{p(i)+1}$ 两种情形；$p(i)=n$ 时该位置不存在，必须特判。
3. 两条加速性质（「只有一处差别」与「$p(i)$ 两两不同」）是压 $\Sigma$ 和压空间的关键；直接对每个 $i$ 复制一份长度 $26$ 的状态在 $n = 2\times10^6$ 时存储代价很大。

**参考代码**：原文未提供标程。

### T3 结构体（struct）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P9754 |
| 核心考点 | 模拟（内存布局、地址对齐、递归寻址） |
| 难度 | 提高+/省选− |
| 一句话结论 | 把基本类型也当成「特殊结构体」，结构体记 $\{name, memlist, size, pkz\}$、元素记 $\{name, pos, type\}$，对齐空隙填特殊类型 `non`，操作 3、4 递归下钻，总复杂度 $O(n^2k)$。 |

**题目大意**：模拟一种类 C++ 语言的结构体定义与内存占用。基本类型共 $4$ 种：`byte`、`short`、`int`、`long`，分别占 $1,2,4,8$ 字节。定义结构体**类型**时给出类型名与按序的成员（成员类型 + 名称），成员类型可以是基本类型，也可以是**先前定义过**的结构体类型（定义类型时不占用内存）。对齐规则：基本类型的对齐要求等于其大小；结构体类型的对齐要求等于其成员对齐要求的**最大值**。元素按定义顺序在内存中依次排布且须满足对齐，元素起始地址必须是对齐要求的整数倍。共 $n$ 次操作：$1$ 定义结构体类型（输出「大小 对齐要求」）；$2$ 定义元素（输出起始地址）；$3$ 访问元素 `a.b.c`（输出被访问的**最内层**元素的起始地址）；$4$ 访问内存地址 $addr$（若有基本类型元素占据该地址则按操作 $3$ 的格式输出该元素，否则输出 `ERR`）。数据范围 $1 \le n \le 100$，$1 \le k \le 100$，$0 \le addr \le 10^{18}$，保证任意结构体大小与元素占据的最高地址均不超过 $10^{18}$。

**题解**：

- **部分分（性质 A：没有操作 1）**：没有操作 $1$ 时所有元素都是基本类型，可以考虑使用数组模拟内存（大小不超过 $8n$）。**操作 2**：注意处理内存中的对齐即可。**操作 3**：由于所有类型都是基本类型，定义的时候记录一下就好了。**操作 4**：直接访问内存即可。
- **部分分（性质 B：只有一个操作 1）**：将唯一的结构体当成特殊的基本类型。由于 $k \le 100$，因此内存大小不超过 $800n$，还是可以使用数组模拟。可以标记内存中每个位置的标签（变量名），在定义变量模拟内存分配的时候记录一下，这样操作 3 和操作 4 会好处理一些。需要注意结构体内部的对齐。
- **部分分（性质 C：所有操作 1 中给出的成员类型均为基本类型）**：由于结构体不会嵌套，因此内存大小依旧不会超过 $800n$，写法与性质 B 一致。
- **满分做法：模拟**：由于此题 $n$ 很小，操作 3 和操作 4 最多递归 $n$ 层结构体，每层结构体遍历 $k$ 个变量，时间复杂度仍然只有 $O(n^2k)$，因此可以考虑直接模拟。
  将基础类型看成特殊的结构体，对于每个结构体记录 $\{name, memlist, size, pkz\}$，分别表示结构体名、成员列表、大小、对齐要求。至于因对齐要求产生的空隙，可以填充特殊的类型 `non` 来标记，可以减少一些讨论。对于每个变量记录 $\{name, pos, type\}$，分别表示变量名、内存起始地址以及类型。
  - **操作 1**：新建一个结构体，记录 $\{name, memlist, size, pkz\}$ 即可。
  - **操作 2**：新建一个变量，记录 $\{name, pos, type\}$ 即可。
  - **操作 3**：将字符串看成 $name_1[.name_2[.name_3\dots]]$ 的结构，首先提取 $name_1$，然后在变量列表中暴力寻找起始位置，之后进入递归，每次递归解一层 `.name` 的结构，解到最后一层即可。
  - **操作 4**：首先在变量列表中暴力找到地址 $addr$ 属于哪一个结构体，之后进入递归，最终如果递归到 `non` 则输出 `ERR`，否则输出对应的类型。
  - 补充：实际上如果你的抽象能力足够强，甚至可以将内存也抽象成一个结构体，把内存上定义的变量抽象成表示内存的这个结构体的内容，这样就可以省去对变量的讨论。
- **样例说明（含校注）**：原文样例 $1$ 的解释写作「`short` 类型的成员 `aa` 占据第 $0\sim3$ 字节地址，`int` 类型的成员 `ab` 占据第 $4\sim5$ 字节地址」，与对齐规则及输出 `8 4` 均不符，疑为原文笔误；按规则正确结果应为 `aa` 占第 $0\sim1$ 字节、`ab` 占第 $4\sim7$ 字节，结构体 `a` 大小 $8$、对齐 $4$（**校注**）。

**复杂度**：$O(n^2k)$。

**易错点**（整理）：
1. 结构体的对齐要求是**成员对齐要求的最大值**（不是成员大小的最大值）；元素的起始地址必须能被它自己的对齐要求整除。
2. 地址反查（操作 4）时，对齐留下的「洞」会命中填充的 `non`，此时没有基本类型元素占据该地址，必须输出 `ERR`，不能报错或输出空。
3. 定义结构体**类型**不占用内存，只有定义**元素**才占内存；且所有元素从地址 $0$ 起按定义顺序依次排布，元素之间的对齐也要处理。

**参考代码**：原文未提供标程。

### T4 种树（tree）

| 项目 | 内容 |
| --- | --- |
| 洛谷题号 | P9755 |
| 核心考点 | 二分答案、贪心（树上调度）、前缀和 |
| 难度 | 提高+/省选− |
| 一句话结论 | 二分最少天数 $m$，对每棵树算出「最晚可种日 $t_i$」，倒序（从第 $m$ 天往前）贪心安排；令 $t'_i=\min\big(t_i,\min_{u\in son(i)}(t'_u-1)\big)$ 后可去掉优先队列，判定做到 $O(n)$。 |

**题目大意**：给定一棵 $n$ 个结点的树（$1$ 号结点连接森林入口），第 $i$ 块地的树高度至少要长到 $a_i$。每天可以选择一个**未种树且与某个已种树地块直接相邻**的地块，种一棵高 $0$ 的树（若所有地块都已种过，则当天不进行操作），特别地第 $1$ 天只能在 $1$ 号空地种树。对每块地，从被种下当天起每天生长：在第 $x$ 天（$x$ 从整个任务第一天算起），$i$ 号地块的树长高 $\max(b_i + x \times c_i,\ 1)$ 米。求至少多少天能完成任务。数据范围 $1 \le n \le 10^5$，$1 \le a_i \le 10^{18}$，$1 \le b_i \le 10^9$，$0 \le |c_i| \le 10^9$，保证存在方案能在 $10^9$ 天内完成任务。

**题解**：

- **部分分（性质 B：树是一条链，且结点 1 的度数为 1）**：不难发现此时种树的序列是唯一的——第 $i$ 天只能将树种在结点 $i$，因此设 $v_i$ 表示结点 $i$ 的树长到至少 $a_i$ 所需的天数，则答案为 $\max\{v_i+i\}$。
  树的生长曲线有三种：常数列（对应 $c_i=0$）、等差数列（对应 $c_i>0$）、先等差数列后常数列（对应 $c_i<0$）。无论是哪种情况，树每天的高度都是单调递增的，因此可以使用二分答案计算 $v_i$；当然，使用数学方法计算也是可以的。这样就在 $O(n)$ 或者 $O(n\log W)$ 的时间复杂度内完成，其中 $W = 10^9$ 为答案上限。
- **二分答案 + 优先队列**：题目具有明显单调性，因此可以二分答案，将题目变成判定性问题。于是目标是判断能否在 $m$ 天内完成任务。
  由于树生长也具有单调性（累计高度随天数单调递增），因此设 $t_i$ 表示使结点 $i$ 的树至少长到 $a_i$ 高度、最迟需要在哪一天种下去；同样 $t_i$ 可以通过数学方法或者二分答案得到。
  由于要求满足连通的限制，正着做（时间正序）越往后越多结点可能不满足要求，不好处理；考虑**倒过来做**（时间倒序），越往后越多结点满足要求。因此可以从叶子结点开始，按照 $t_i$ 从大到小的顺序贪心地选择种树的时间。由于树结构必须先选儿子再选父亲，因此这个过程可以通过**优先队列**完成（每次取出当前可选的 $t_i$ 最大的结点安排到最靠后的空闲天，儿子选完后再把父亲加入待选队列）。
  复杂度：二分的时间复杂度为 $O(\log W)$，判断需要用优先队列的时间复杂度为 $O(n\log n)$ 或 $O(n\log n + n\log W)$（取决于 $t_i$ 的计算方法）。因此可以在总时间复杂度 $O(n\log n\log W)$ 或 $O(n\log(nW)\log W)$ 下完成此题。
- **二分答案（去掉优先队列）**：虽然使用优先队列已经足够通过这个题了（但是可能被卡常），不过可以进一步思考能否将优先队列也去掉，答案是可以的。
  依旧倒序做。使用优先队列的原因：因为树结构，必须先选儿子再选父亲，儿子选完之后将父亲结点加入待选队列。那有没有办法突破树结构的限制呢？注意到两点：
  1. 越往后选越有可能满足要求；
  2. 父结点必须晚于子结点选。

  而使用优先队列的目的是为了找到 $t_i$ 最大的结点，那么一个自然的想法是让父结点的 $t_i$ 比所有子结点的都要小就可以了，也就是令
  $$t'_i = \min\Big(t_i,\ \min_{u \in son(i)}(t'_u - 1)\Big)$$
  这样我们就可以无视树结构，直接贪心选最大的（把结点按 $t'$ 从大到小依次安排到第 $m, m-1, \dots$ 天）了，自然也就不需要优先队列了。实际上此时满足条件当且仅当对于任意的 $j$ 都满足：满足 $t'_i \ge j$ 的 $i$ 的数量不超过 $j$，这可以自然地使用**前缀和**做到线性。
  综上所述，我们可以去掉优先队列，达成最快 $O(n\log W)$ 的时间复杂度。当然如果 $t_i$ 也二分的话时间复杂度会变成 $O(n\log^2 W)$。

**复杂度**：$O(n\log W)$（$t_i$ 用数学方法直接算）或 $O(n\log^2 W)$（$t_i$ 也二分）。

**易错点**（整理）：
1. 前向贪心（每天种「最晚可种日 $t_i$ 最小」的结点）存在反例，必须**倒序**贪心：从第 $m$ 天往前，每次选当前可种结点中 $t_i$ 最大者。
2. $t_i$ 依赖二分出的天数上限 $m$，判定函数内部必须按当前的 $m$ 重新计算所有 $t_i$，不能复用外层的缓存。
3. 生长公式是**逐日增量** $\max(b_i + x\cdot c_i, 1)$ 米，累计高度是 $x$ 的单调函数；$c_i<0$ 时增量最终被 $1$ 兜底成为「先等差后常数」，求「还需多少天」时不要漏掉这个下界 $1$。
