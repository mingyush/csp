## 三、按算法分类索引

### 3.1 贪心（14 题中出现频率最高，务必扎实）

| 题目 | 贪心要点 |
| --- | --- |
| 2025 T1 社团招新 | 先取每人最大满意度，超额部分按「损失最小」改派 |
| 2025 T2 道路修复 | Kruskal 选边 + 枚举乡镇集合；预处理压掉排序 |
| 2024 T1 决斗 | 排序后从小到大配对，答案即众数频次 |
| 2024 T2 超速检测 | 按右端点排序的区间覆盖贪心 |
| 2024 T3 染色 | DP 转移化简为全局加 + 单点取 max |
| 2023 T4 种树 | 倒序贪心（从第 $m$ 天往前选 $t_i$ 最大者） |
| 2022 T1 假期计划 | 前三大预处理的「贪心替补」思想 |
| 2022 T2 策略游戏 | 先手只取四类数，后手按符号取最值 |
| 2021 T1 廊桥分配 | 编号最小的空闲廊桥；前缀和合并两区 |
| 2021 T3 回文 | 双栈顶配对，能取 `L` 就取 `L` |

### 3.2 动态规划

| 题目 | 形态 |
| --- | --- |
| 2022 T4 数据传输 | 动态 DP + $(\min,+)$ 广义矩阵 + 树上倍增（最硬） |
| 2024 T3 染色 | 区间/线性 DP，贪心优化到 $O(n+a)$ |
| 2025 T4 员工招聘 | 三维计数 DP + 容斥 |
| 2021 T2 括号序列 | 区间 DP（$f$ 匹配 / $g$ 不匹配两套状态） |
| 2025 T1 社团招新 | 35 分档为三维背包式 DP（$O(n^3)$） |

### 3.3 图论

| 题目 | 考点 |
| --- | --- |
| 2025 T2 道路修复 | 最小生成树（Kruskal）+ 并查集 |
| 2022 T1 假期计划 | 多次 BFS 求全源最短路 |
| 2022 T3 星战 | 出度为 1 的判定 + 集合哈希 |
| 2021 T4 交通规划 | 平面图最小割 / 网络流对偶建图 |

| 2021 T2 括号序列 | 超级括号序列的定义化区间 DP |
