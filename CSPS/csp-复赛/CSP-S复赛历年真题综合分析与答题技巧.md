## 第一部分：历年复赛整体分析

### 1.1 整体结构回顾

CSP-S复赛（第二轮认证·提高级）采用固定的四题结构，**总时长4小时**，每题100分，共400分：

| 题号 | 常见难度定位                     | 分值 | 建议用时  |
| ---- | -------------------------------- | ---- | --------- |
| T1   | 不一定是签到题，偶有图论/贪心难题 | 100  | 40-60分钟 |
| T2   | 综合性较强，题型多变              | 100  | 60-80分钟 |
| T3   | 中高难度，图论/贪心/字符串常见     | 100  | 80-100分钟 |
| T4   | 压轴题，DP为主，也见高级数据结构   | 100  | 剩余时间  |

> ⚠️ **与CSP-J最大的区别**：CSP-J的T1-T4难度梯度非常规律（签到→中等→中高→压轴），但CSP-S**不保证T1简单**——历年多次出现T1即考图论BFS、复杂贪心的情况（如2022年T1"假期计划"）。因此S组选手应**通读全部四题后再决定作答顺序**，而不是机械按T1→T4顺序推进。

### 1.2 按年份统计核心考点（2019-2025）

| 年份 | T1(核心)        | T2(核心)          | T3(核心)        | T4(核心)              |
| ---- | --------------- | ------------------ | --------------- | ---------------------- |
| 2019 | 递归、位运算     | 树形结构、栈        | 贪心、树形结构    | 动态规划、容斥（另有T5划分/T6树的重心，见下方历史说明） |
| 2020 | 模拟、日期计算   | 位运算、集合        | 图论、拓扑排序    | 模拟、博弈              |
| 2021 | 贪心、模拟       | 动态规划            | 贪心、双指针      | 图论、最短路            |
| 2022 | 图论、BFS        | 贪心、ST表          | 图论、哈希        | 动态规划、矩阵快速幂     |
| 2023 | 枚举             | 字符串、栈          | 模拟、内存对齐    | 二分、树形结构           |
| 2024 | 贪心、排序       | 几何、凸包          | 动态规划、组合数学 | 数据结构、平衡树         |
| 2025 | 贪心             | 最小生成树、并查集   | 字符串、计数（字符串自动机级） | 动态规划       |

**年份特点分析：**

- **2019年**：CSP-S复赛首年，沿用NOIP传统赛制——一试T1-T3、二试T4-T6，分两天各3小时（详见下方"2019年特殊赛制"说明）
- **2020年**：赛制统一为4题4小时，T1模拟签到，T4"模拟+博弈"为较少见的压轴类型
- **2021年**：图论首次单独压轴T4（交通规划-最短路），T2首次以纯DP面貌出现
- **2022年**：**T1直接考图论BFS**，是S组"T1未必简单"的典型例证；T4矩阵快速幂优化DP，难度显著提升
- **2023年**：题型整体转向"细节+模拟"（结构体内存对齐、种树二分），DP罕见地缺席T4
- **2024年**：T2首次考几何（凸包），T4首次考平衡树，体现S组对高级数据结构的全面要求
- **2025年**：T1回归贪心签到定位，但T3难度直逼T4（字符串自动机级别），T3、T4连续两题图论/DP以外的高阶考点

### 1.4 近年趋势分析

#### 🔥 2023-2025年重要变化

| 趋势                     | 具体表现                                      | 影响                   |
| ------------------------ | ---------------------------------------------- | ---------------------- |
| **T1不再是绝对签到题**   | 2022图论BFS、2024贪心+排序                      | 需要更全面的算法基本功  |
| **T3难度持续攀升**       | 2025年T3字符串自动机级别，逼近传统T4难度         | 不能轻视T3的复习投入    |
| **高级数据结构权重上升** | 2024年T4平衡树、历年ST表/并查集/Trie树反复出现   | 需系统掌握"非DP"数据结构 |
| **图论贯穿全卷**         | 7年中T1-T4合计出现图论相关考点达6次              | 图论是S组的核心必修模块 |
| **T2题型高度不固定**     | 7年7种不同主题，无重复模式                       | 复习需广度优先，不能押题 |

#### 📊 考点重要性排序（基于7年频次）

**必掌握（高频+压轴权重高）：**

1. **动态规划** - T4主流（43%），且常与矩阵快速幂、容斥等技巧结合
2. **图论算法** - 最短路、MST、拓扑排序、树上问题贯穿T1-T4，出现率最高的模块
3. **贪心算法** - T1/T3高频（均43%/29%），S组贪心常需严谨证明而非直觉

**重要掌握（中频+失分点集中）：**

4. **高级数据结构** - 并查集、ST表、Trie、平衡树、线段树，历年反复出现
5. **字符串算法** - KMP、字符串哈希、Trie/AC自动机，2023、2025年多次涉及
6. **数学与组合** - 容斥、快速幂、组合计数，常作为DP的辅助技巧出现

**了解掌握（低频但曾出现）：**

7. **计算几何** - 凸包（2024），出现频率不高但一旦命中难度不低
8. **博弈论** - 偶尔出现（2020），了解基本博弈模型即可

## 第二部分：分题型答题技巧与策略

### 2.1 通读策略：先扫题，再定序

由于CSP-S的T1-T4难度不总是递增，**拿到试卷后建议先用10-15分钟通读全部四题**，标记每题的算法方向和自己的把握程度，再按"最有把握的题优先"的原则安排作答顺序，而不是死板地从T1做到T4。

### 2.2 图论类题目

- **建图前先想清楚状态定义**：很多"看似最短路"的题实际是分层图/状态最短路（如"最多用一次免费边"类问题需要把`(节点, 是否用过免费边)`作为状态）
- **优先想清楚数据范围对应的复杂度上限**：n≤1000可以考虑Floyd(O(n³))，n≤10^5必须Dijkstra+堆或更优
- **并查集是"隐藏工具人"**：很多不直接是"最小生成树"的题目，只要涉及"连通性判断/合并"就该第一时间想到并查集

### 2.3 动态规划类题目（T4高频）

- **状态设计优先于代码实现**：先用文字/数学语言明确`dp[i][j]`表示什么，再考虑转移方程，避免边写代码边纠结语义
- **警惕"伪装的DP"**：S组的DP常与矩阵快速幂（加速递推）、容斥原理（去除重复计数）、组合数学（计数类DP）结合，识别这层包装是拿到高分的关键
- **滚动数组/空间优化放在最后**：先写出正确的高维DP拿部分分，再考虑用滚动数组优化空间/被卡常时再优化

### 2.4 贪心类题目

- **贪心必须有说服自己的证明思路**（哪怕不写在草稿纸上），S组的贪心陷阱远多于CSP-J，直觉性贪心很容易被特殊数据卡掉
- **贪心+数据结构维护是常见组合**：优先队列维护当前最优、单调队列/单调栈维护决策候选，历年T1-T3的贪心题几乎都需要配合一种数据结构

### 2.5 高级数据结构与字符串类题目

- **平衡树/线段树/树状数组是"送分利器"**：这些结构一旦识别出适用场景，代码往往是模板级别的，考前务必练熟带修改的区间查询模板
- **字符串题优先判断是否需要预处理结构**：涉及大量子串匹配、多模式串查询时，第一反应应是Trie树或AC自动机而非暴力匹配
- **哈希是万能兜底手段**：想不出正解时，字符串哈希/双哈希常常能拿到大量部分分甚至满分

## 第三部分：备考策略与资源

### 3.1 时间分配策略（4小时/240分钟）

| 阶段         | 建议用时     | 说明                                       |
| ------------ | ------------ | ------------------------------------------ |
| 通读四题     | 10-15分钟    | 判断难度、标记算法方向、决定作答顺序          |
| 最有把握的题 | 60-90分钟    | 优先拿满，不局限于T1                        |
| 次有把握的题 | 60-90分钟    | 争取满分或高部分分                          |
| 剩余两题     | 剩余时间     | 先写暴力/部分分做法保底，再冲优化           |
| 检查         | 15-20分钟    | 核对文件名、freopen、输出格式、边界情况       |

### 3.2 考场基本规则（与CSP-J复赛完全一致）

CSP-J/S两组同属"第二轮认证"，考场规则完全通用，包括：

- 必须使用 `freopen` 进行文件输入输出重定向
- 提交文件夹以准考证号命名，子文件夹以题目英文目录名命名（见各年真题PDF"目录"一栏，如`club`/`road`）
- 提交源程序文件名、可执行文件名须与题目要求完全一致（均为英文小写）
- `main`函数返回值类型必须是`int`，正常结束返回值必须是0

> 完整的考场防爆零清单和调试技巧，可参考 [CSPJ/csp-j复赛/CSP-J复赛知识点梳理2025.md](../../CSPJ/csp-j复赛/CSP-J复赛知识点梳理2025.md) 中"防止爆零"章节，该部分规则J/S两组通用。

### 3.3 分层次备考建议

#### 🥉 保省三/省二策略（目标：拿到2-3题的主要分值+其余题部分分）

- 优先打牢图论（最短路、MST、并查集、拓扑排序）和基础DP（背包、区间DP、树形DP）
- 掌握常见暴力/部分分套路：枚举、折半枚举、简单模拟，保证至少两题接近满分

#### 🥈 冲省一策略（目标：三题满分+一题较高部分分）

- 系统训练高级数据结构：线段树、树状数组、平衡树、ST表、Trie/AC自动机
- 强化DP进阶技巧：矩阵快速幂优化、容斥原理、状态压缩、数位DP
- 大量刷近5年真题，严格限时4小时完整模拟，培养"先扫题再定序"的考场习惯

## 📌 总结

### 🎯 备考核心要点

1. **通读全卷再定序**：CSP-S的T1未必是签到题，先判断难度再决定作答顺序
2. **图论是第一必修课**：7年间出现率最高，最短路、MST、并查集、树上问题需信手拈来
3. **DP是压轴题最大概率的方向**：但要警惕矩阵快速幂、容斥等"包装"
4. **高级数据结构不能偷懒**：线段树、树状数组、平衡树、Trie/AC自动机至少要能写出模板
5. **贪心必须有依据**：S组的贪心陷阱多，直觉贪心容易被卡

**最终目标**：以图论和高级数据结构打底，DP专项突破，贪心求稳，力争三题满分、一题拿到高部分分！
