# CSP-S1（提高组第一轮/初赛）备考指南与答题技巧

## 一、考试形式总览

CSP-S1为笔试，时长 **2小时（120分钟）**，满分 **100分**，全部为客观题（机读卡/在线作答，无需编写完整程序）。

| 题型               | 题量        | 分值                | 说明                                       |
| ------------------ | ----------- | ------------------- | ------------------------------------------ |
| 单项选择             | 15题        | 30分（每题2分）     | 全部为单项选择（四选一），考查计算机基础、数据结构、算法、数论与组合等 |
| 阅读程序（理解程序） | 3篇，共18小题 | 40分                | 每篇程序6小题，判断题约1.5分/题，单选题约3分/题 |
| 完善程序（程序填空） | 2篇，共10小题 | 30分                | 给出程序功能描述与代码框架，每处空缺从4个选项中选择正确代码片段 |

**与CSP-J1的关键差异**：CSP-S1覆盖的知识深度明显高于J1——单项选择部分会直接考查数据结构与算法的**时间复杂度分析**、**图论**、**高级数据结构**等大学计算机专业课内容；阅读程序和完善程序的代码量更长、逻辑更绕（常见如分层图、树上倍增、字符串自动机等），对代码阅读速度和调试式思维要求更高。

## 二、历年高频考点清单

### 2.1 单项选择高频考点

- **进制与编码**：二进制/八进制/十六进制转换、原码补码反码、格雷码
- **数据结构基础理论**：栈/队列/链表的性质、二叉树的遍历与性质、堆的插入删除、并查集、Trie树的结点数、哈希表冲突解决（线性探测/拉链法）
- **图论基础理论**：最小生成树（Kruskal/Prim思想）、最短路（Dijkstra适用条件）、拓扑排序方案数、树的LCA性质、完全图边权和
- **算法复杂度分析**：递归式求解（主定理思想）、分治/DP的复杂度估计、渐进符号比较
- **排序与查找**：各排序算法的时间/空间复杂度和稳定性对比、二分查找变形
- **数论与组合**：容斥原理、快速幂、GCD/LCM、简单计数问题
- **计算机组成与操作系统常识**：CPU/内存/缓存基础概念、进程与线程、逻辑门电路（历年偶尔涉及，占比不高但易失分）

### 2.2 阅读程序高频考点

- **递归与回溯**：全排列生成、DFS剪枝、递归树状态数分析（历年常考"改变某一行代码后输出是否变化"）
- **交互式/博弈类模拟程序**：如猜数、博弈策略模拟，重点考查对函数调用次数、边界条件的追踪能力
- **分治与折半枚举（meet-in-the-middle）**：数组一分为二后分别DFS再合并统计的经典套路（2025年第三篇即此套路）
- **定宽无符号位运算**：`unsigned short`/`unsigned int` 下的移位与异或，依赖溢出截断行为（2023、2024年连续出现）
- **数据结构操作模拟**：堆、并查集、线段树、猜数/抛鸡蛋分块策略等结构在给定代码中的运行轨迹
- **易错点**：静态数组是否清零、全局变量初值、边界 `k==n+1` 类判断、`long long`溢出、负数取模与负进制方向
- **固定题型**：「删除/修改某一行代码，输出或正确性是否变化」——判断该行是否位于关键路径（剪枝、清空标记数组、去重）

### 2.3 完善程序高频考点

- **最短路/分层图**：如"选择一条免费边"类的状态最短路（`dist[u][used]`型二维Dijkstra，2025年第一题）
- **次短路**：`dis1`/`dis2` 双距离数组的 Dijkstra 变形，含路径还原（2024年第二题）
- **二分答案+计数**：如"两个有序序列合并后的第 k 小"，用二分 + `upper_bound` 统计排名（2022、2024年连续出现）
- **DAG 路径计数 + 贪心逐位定**：字典序第 k 小的路径（2023年第一题）
- **动态规划状态设计**：背包类、区间DP、树形DP的转移方程填空
- **分治贡献统计**：跨中点的左右段贡献合并（2023年第二题"所有子段最大值之和"）
- **贪心+数据结构结合**：优先队列/单调队列维护贪心过程
- **编码论/信息论思想题**：如"最少测试次数确定坏品"（覆盖码/汉明码思想），近两年（2024、2025）多次出现，属于难点，建议专项训练

> 逐年套路对照表见同目录《CSP-S1初赛历年真题考点分析与命题趋势.md》第五节。

## 三、分题型答题技巧

### 3.1 单项选择（30分，建议用时25分钟）

1. **排除法优先**：遇到把握不大的选项，先判断"是否绝对成立"，凡是有反例的选项直接排除，减少犹豫时间。
2. **优先做有把握的题**：先扫一遍全部15题，标记完全确定的，再回头攻克模糊的，避免在单一难题上卡死影响后面阅读程序的时间。
3. **理论题善用特例验证**：复杂度、图论类选择题，代入 n=1、n=2 等小规模特例往往比死记结论更可靠。
4. **不会就用排除法蒙**：单选题排除2个错误选项后再猜，比空着不选期望得分更高。

### 3.2 阅读程序（40分，建议用时50分钟）

1. **先通读程序整体结构，再答题**：不要边读代码边做题，容易只见树木不见森林；先花1-2分钟理清函数调用关系和数据流向。
2. **判断题优先用代入法验证**：给定小规模输入（如n=3、n=4）手动模拟运行，比纯靠代码直觉更准确，尤其是递归和状态转移类程序。
3. **复杂度分析题看循环嵌套与递归树**：数清循环层数、递归分支数和深度，套用等比数列求和或主定理估算。
4. **"删除某行代码是否影响结果"类题目**：重点判断该行是否在**关键路径**上（如剪枝、清空标记数组），而不是简单看它"看起来有没有用"。
5. **控制时间，不要在一题上死磕**：单题分值不高（1.5-3分），实在想不通先跳过标记，做完全部题目后再回头，避免影响完善程序的作答时间。

### 3.3 完善程序（30分，建议用时40分钟）

1. **先读题目功能描述，再看代码框架**：明确算法整体思路（如"这是状态最短路"、"这是区间DP"）后再定位空缺，避免逐行硬啃。
2. **利用变量命名和上下文强约束选项**：如变量名为 `dist`、`used`、`INF`，函数签名和上下文数据类型往往能直接排除不匹配的选项。
3. **交叉验证空缺之间的逻辑一致性**：完善程序的多个空往往互相关联（如状态定义在①确定后，②③④都要与之自洽），做完全部空后建议整体复查一遍逻辑闭环。
4. **边界与初值优先检查**：完善程序题目中，"初始化为0还是INF"、"循环边界是`<`还是`<=`"是最常见的坑。

## 四、备考策略

### 4.1 时间规划建议（考前2-3个月起步）

| 阶段           | 时长   | 重点内容                                             |
| -------------- | ------ | ------------------------------------------------------ |
| 基础巩固       | 3-4周  | C++语法、STL、复杂度分析、进制转换等CS基础理论           |
| 数据结构与图论 | 3-4周  | 树、图、并查集、堆、字符串（KMP/Trie/哈希）理论与代码实现 |
| 真题限时训练   | 2-3周  | 按120分钟限时完整刷近5年真题，逐题复盘错因               |
| 冲刺查漏       | 1周    | 整理错题本、复习高频易错点（蒙题策略、边界处理）   |

### 4.2 得分优先级建议

- **保证单选拿到20分以上**：这部分题量固定、性价比高，多刷理论题比死磕阅读程序更划算。
- **阅读程序至少完成2/3题目的正确率**：三篇程序难度递增，第一篇通常最简单，务必保证前两篇高正确率。
- **完善程序不必强求全对**：10个空缺互相关联，做错1-2个不会拖累其他空，遇到实在无法判断的空可结合选项"代码风格一致性"直觉判断。

### 4.3 常用真题资源

- **本仓库真题**：见 `CSPS/csp-s初赛真题/` 目录下 2021—2025 年真题（2025 年为社区整理版，附干净试卷版可限时模拟）；目录索引见该目录 `README.md`
- **考点优先级**：见同目录《CSP-S1初赛历年真题考点分析与命题趋势.md》——按五年频次统计决定复习顺序，避免平均用力
- **洛谷**：搜索"CSP-S 初赛"或访问对应年份模拟赛/题单
- **NOI官网**：https://www.noi.cn/ 关注权威的复赛/晋级规则通知（初赛原题不公开发行，仅第一轮成绩公示）
