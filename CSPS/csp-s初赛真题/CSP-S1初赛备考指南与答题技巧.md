# CSP-S1 2026 初赛备考指南与答题技巧

> 定位：长期备考总纲，负责知识结构、训练方法和阶段规划。近五年考频见[《历年真题考点分析与命题趋势》](CSP-S1初赛历年真题考点分析与命题趋势.md)，临考执行表见[目录导航](README.md)。

本目录 2021—2025 资料的训练基线为 120 分钟、100 分：单项选择 15 题共 30 分，阅读程序 3 篇共 40 分，完善程序 2 篇共 30 分。2026 正式题型以当年试卷和本省通知为准。

## 一、先诊断，再排计划

选择一套从未完整做过的 2022—2025 试题，严格计时 120 分钟。除总分外，记录各板块得分、用时、蒙对题和未完成题。

| 诊断结果 | 优先动作 |
| --- | --- |
| 单选正确率低 | 用第二节清单定位知识缺口；每天 30 分钟结论默写 + 15 道专项选择 |
| 阅读程序丢分多 | 每天精读一篇程序，先画调用链与变量表，再手算小样例 |
| 完善程序丢分多 | 先识别算法与状态含义，再填空；按图论、DP、二分/分治分专题训练 |
| 会做但超时 | 做 25/50/40 分钟分段限时，训练两轮作答与跳题标记 |
| 涂卡或计算失误 | 每次模拟固定留 5—10 分钟检查，并把“失误题”同样纳入回测 |

不要用网上流传的跨省分数线区间替代个人目标。第一轮进入第二轮的资格由各省根据当年成绩确定；目标分应参考所在省正式通知、本人近三套模拟的稳定分和安全余量。

## 二、知识结构与掌握标准

### A 级：必须熟练

| 模块 | 内容 | 达标标准 |
| --- | --- | --- |
| 复杂度 | 渐进记号、循环求和、递归树、主定理、常见算法复杂度 | 看到代码或递推式，2 分钟内给出时间/空间复杂度并说明依据 |
| 树与图 | 遍历、二叉树性质、BST、堆、并查集、最短路、MST、拓扑排序、连通性、LCA 基础 | 能手算小图/小树，并说清算法适用条件 |
| 组合与数论 | 排列组合、容斥、鸽巢、卡特兰、GCD/LCM、快速幂、同余与基础概率 | 能列式而不是凭直觉选答案 |
| C++ 语义 | 表达式优先级、作用域、递归、数组/指针/引用、STL、整数溢出、位运算 | 能逐行跟踪变量值，识别未初始化、越界和类型转换风险 |
| 程序阅读 | 循环、递归、DFS/BFS、排序、二分、DP、贪心的执行过程 | 能画调用链/状态表，用小数据验证结论 |

### B 级：高频提分

| 模块 | 内容 | 达标标准 |
| --- | --- | --- |
| 字符串与哈希 | KMP `next`/前缀函数、Trie、字符串哈希、开放定址与拉链法 | 能手算短串和一次完整插入/查找过程 |
| DP 与搜索 | 0-1 背包、区间/状态 DP 基础、回溯剪枝、记忆化 | 能先写出状态含义，再判断转移和初值 |
| 算法变形 | 分层图、次短路、二分答案、折半枚举、路径计数 | 能从变量名与代码结构识别套路 |
| 计算机基础 | 进制、补码、编码、CPU/内存/缓存、进程/线程、Linux 常用命令、编译流程 | 结论题 30 秒内完成 |

### C 级：有余力再补

- 冷门编码构造、复杂数据结构内部实现、偏门系统知识。
- 只在近年一套卷出现且本人从未学过的难专题；考前一周不新开大块。
- 训练重点是读懂给定实现，不要求把所有复赛级算法独立写成完整程序。

## 三、三类题的稳定打法

### 3.1 单项选择

1. 第一轮先做结论明确、计算短的题；超过 90 秒仍无思路就标记跳过。
2. 图论、组合、复杂度题先写公式或画小图，不在脑内完成多步计算。
3. 对“必然、一定、任意”类选项主动找最小反例；对程序语义题检查类型、边界和初始化。
4. 不留空项；最后检查题号与答题卡是否对齐。

### 3.2 阅读程序

1. 先写一句程序目标，再标出入口函数、关键状态、循环/递归边界和返回值。
2. 为数组或关键变量建立小表格；遇到递归用 n=2/3 的小输入画调用树。
3. “删除/修改一行”题分别检查正确性、终止性、复杂度和副作用，不把“样例不变”当成“结果总不变”。
4. 复杂度把每个阶段分开计算，排序、枚举、双指针和递归最后取主导项。

### 3.3 完善程序

1. 先读功能说明和输入输出，给算法命名；再为 `dp`、`dist`、`vis` 等变量写出准确含义。
2. 按“初始化 → 循环条件 → 状态转移 → 答案返回”顺序填，不必拘泥空号顺序。
3. 用类型、作用域、单调性、边界和前后空的一致性排除选项。
4. 全部填完后用最小合法输入走一遍；每空独立计分，但相互关联的错误可能连锁影响判断。

## 四、阶段计划

| 剩余时间 | 训练重点 | 每周建议 |
| --- | --- | --- |
| 8—12 周 | 补齐 A 级知识，建立手算能力 | 3 次专题学习 + 2 次程序阅读 + 1 套分段真题 |
| 4—7 周 | A 级查漏，推进 B 级高频 | 2 套整卷或等量分段训练，全部完成 24 小时回测 |
| 2—3 周 | 近五年真题、限时与稳定性 | 每周 2—3 套整卷；同一弱项连续错两次即回专题 |
| 8—13 天 | 只补高频弱项，固化时间策略 | 1—2 套保留卷 + 错题重做，不再扩展冷门知识 |
| 7 天以内 | 执行冲刺文档 | 见[7 天计划](CSP-S1_2026初赛考前7天冲刺日程.md)或[3 天计划](CSP-S1考前3天突击过关计划.md) |

一套卷的复盘时间至少为作答时间的一半。复盘只写答案没有价值，必须记录“考点—错因—正确依据—回测日期”。

## 六、考场执行

- 建议基线：单选 25 分钟、阅读 50 分钟、完善 40 分钟、检查 5 分钟；以最近三套模拟的稳定结果微调。
- 两轮作答：第一轮拿确定分并标记疑问，第二轮处理计算长或逻辑复杂的题。
- 草稿纸固定分区，题号写在每段计算前；修改答案时同步检查答题卡。
- 最后 5—10 分钟只做题号、漏涂、多涂、修改痕迹和个人信息检查，不再重新推导整道难题。
