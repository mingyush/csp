# CSP-S1 初赛考前 3 天突击过关计划（2026）

> 适用范围：2026 年 9 月 19 日（周六）CSP-S1（提高组第一轮/初赛），考前最后 3 天冲刺
> 目标定位：短期突击「过关」——稳定拿到各省晋级复赛所需分数，而非冲击满分
> 配套阅读：本仓库《CSP-S1初赛备考指南与答题技巧.md》（长期知识地图，本计划为 3 天冲刺版）

---

## 一、先想清楚：过关需要多少分

| 项目 | 内容 |
| --- | --- |
| 考试形式 | 笔试，120 分钟，满分 100 分，全客观题（涂答题卡/在线作答，不写完整程序） |
| 题型结构 | ① 单项选择 15 题 × 2 分 = **30 分**；② 阅读程序 3 大题 ≈ **40 分**（判断+单选）；③ 完善程序 2 大题 ≈ **30 分**（每空 3 分） |
| 晋级规则 | 第一轮成绩由各省划定分数线晋级第二轮（复赛），分数线各省不同 |

**分数线参考**（历年大致区间，仅作定位）：
- 强省（浙江、江苏、广东、山东等）：常年 **45~55 分**；
- 多数省份：**30~45 分**；
- 部分省份：低于 30 分即可晋级。

**3 天的策略不是"考满分"，而是"把能稳拿的分全拿住"**：

| 板块 | 满分 | 突击目标 | 说明 |
| --- | --- | --- | --- |
| 单项选择 | 30 | **20+** | 知识点可背、可用排除法，是 3 天最大的提分点 |
| 阅读程序 | 40 | **24+** | 不必逐行看懂，靠小数据代入 + 复杂度定位 + 排除法 |
| 完善程序 | 30 | **12+** | 最后做，先定算法，再靠变量名/上下文约束选答案 |

合计目标 **55 分左右**较稳，保底 40 分。

## 二、三天总策略（按性价比排序）

1. **单选优先**：30 分题量固定、可背结论、有排除法兜底 → 第一天全部拿下。
2. **阅读程序不恋战**：三篇难度递增，前两篇务必稳住正确率；拿不准先跳过。
3. **完善程序放最后**：多空互相关联，先读功能描述判断算法，再整体定位。

**每日节奏**（每天约 6~8 小时，分三段）：
- 上午：记忆型知识点速背（基础 / 数论 / 复杂度 / 图论）
- 下午：真题与专项演练
- 晚上：复盘错题 + 睡前再扫一遍「速查卡」（第六节）

## 三、Day 1（倒数第 3 天）：单选主攻——背结论，吃下 30 分的大头

> 今日目标：把单选里能背的结论全部过一遍，做到「见到题 10 秒内有思路」。

### 上午（约 2.5h）：进制 / 编码 / 计算机常识

- **进制转换**：十进制 ↔ 二进制 / 八进制 / 十六进制；背熟 2^0 ~ 2^16 幂值；二进制小数转十进制。
- **原码 / 反码 / 补码**：正数三码相同；负数补码 = 反码 + 1 = 按位取反 + 1；8 位补码范围 −128~127；补码把减法变成加法。
- **编码**：ASCII、Unicode/UTF-8、格雷码（相邻两码只差一位）。
- **存储单位**：bit/Byte/KB/MB/GB/TB 按 1024 换算。
- **组成与系统常识**：CPU、内存、缓存、寄存器；进程 vs 线程；逻辑门（与/或/非/异或）——占比不高但易丢分。

### 下午（约 2.5h）：数据结构性质 + 数论组合

- **排序**：复杂度与稳定性表（见第六节 6.2，必背）。
- **树**：完全二叉树第 i 层最多 2^(i−1) 个结点、n 结点深度 ⌊log₂n⌋+1、叶子数 = 度为 2 的结点数 + 1；二叉搜索树中序遍历 = 有序；前/中/后序遍历互推。
- **堆**：完全二叉树；插入/删除 O(log n)，建堆 O(n)。
- **哈希**：线性探测、二次探测、拉链法；负载因子概念。
- **Trie / KMP**：Trie 结点数 = 不同前缀数（含根）；KMP next 数组含义。
- **并查集**：路径压缩 + 按秩合并，近似 O(α(n))。
- **数论**：快速幂、GCD/LCM、素数判定与筛法、同余、逆元思想。
- **组合**：排列 P(n,k)、组合 C(n,k)、容斥原理、隔板法、错排、卡特兰数（见第六节 6.5）。

### 晚上（约 1.5h）：单选限时刷 + 建错题清单

- 用 2022、2023 年真题「单项选择」部分（各 15 题）**各限时 25 分钟**刷一遍；
- 标记「做错的」和「蒙对的」，当晚把对应结论补进第六节速查卡，形成自己的易错清单。

> **Day 1 自测**：从速查卡随机抽 10 条结论，能默写 8 条以上即过关。

## 四、Day 2（倒数第 2 天）：大题主攻——复杂度 / 图论 + 阅读程序 + 完善程序

### 上午（约 2.5h）：复杂度分析 + 图论基础

- **复杂度**：主定理三情形（见 6.6）；递归树；常见算法复杂度速记。
- **图论**：完全图边数 n(n−1)/2；MST 的 Kruskal O(E log E) / Prim O(V²)；最短路 Dijkstra（非负权）/ Bellman-Ford（可负权）/ Floyd O(V³)；拓扑排序（仅 DAG，方案数可能不唯一）；LCA（倍增法思想）。

### 下午（约 2.5h）：阅读程序方法论 + 真题实战

**方法论（5 条）**：
1. 先通读整体调用链，再答题，别边读边做；
2. 判断题：代入 n=2/3/4 小数据手动模拟；
3. 复杂度题：数循环层数 × 递归分支/深度，套等比数列或主定理；
4. "改一行是否影响结果"：看该行是否在关键路径（剪枝 / 清空标记数组 / 去重）；
5. 拿不准先跳过，最后排除法。

**实战**：精做 2024、2025 年阅读程序。重点吃透 2025 的两类高频套路：
- 「猜数 / 抛鸡蛋」类模拟：追踪函数调用次数与边界（`cnt_broken`、`cnt_check` 计数逻辑）；
- 「折半枚举 meet-in-the-middle」类：数组一分为二分别 DFS 再排序合并统计（2025 阅读程序第三题）。

### 晚上（约 1.5h）：完善程序方法 + 高频套路专项

**方法论（4 条）**：
1. 先读题目功能描述 → 判断算法（分层图最短路 / DP / 贪心 + 堆 / 信息论编码）；
2. 靠变量名与类型排除：`dist`/`used`/`INF`、二维状态 `d[u][used]`、转移下标；
3. 多空互相自洽：状态定义定下后，后面所有空都朝它对齐，做完整体复查闭环；
4. 边界/初值优先检查：0 还是 INF、`<` 还是 `<=`。

**两套必练高频套路**：
- **分层图最短路**（"免费边 / 减半边"，`dist[u][used]` 二维 Dijkstra）——2025 完善程序第一题即此套路；
- **信息论 / 编码题**（"最少测试次数确定缺陷生产线"，组合计数 + 码字生成）——2024、2025 连续出现，务必看懂 2025 完善程序第二题的 `count_patterns` 与 `prev_permutation` 生成码字逻辑。

## 五、Day 3（倒数第 1 天）：全真模拟 + 复盘 + 定策略

### 上午（约 2.5h）：全真限时模拟

- 用 **2025 或 2024 真题**，严格 120 分钟限时，按真实节奏：
  - 单选 25 分钟 → 阅读程序 50 分钟 → 完善程序 40 分钟 → 检查 5 分钟。
- 中途不查资料、不中断、不跳题。

### 下午（约 2h）：逐题复盘

- 只复盘三类题：①做错的 ②蒙对的 ③用时超标的；
- 把每道错题对应的知识点回填进第六节速查卡，形成「我的易错清单」。

### 晚上（约 1.5h）：定蒙题策略 + 考前准备

**考场纪律（5 条）**：
1. 单选：排除 2 个明显错误项后再猜，**绝不空题**；理论题代入 n=1/2 特例验证；
2. 阅读程序：不在一篇死磕，前两篇稳住正确率，第三篇拿基础分；
3. 完善程序：最后做，实在不会的凭「代码风格一致性 / 变量命名」猜；
4. 全程留 5~10 分钟检查答题卡涂写（题号对齐、不串行）；
5. 卡壳超 2 分钟立刻跳过，先拿能拿的分。

**考前准备清单**：
- 证件、准考证、2B 铅笔、橡皮、黑色签字笔；
- 确认考点/考场与交通路线，提前到场；
- 作息正常，当晚 10:30 前睡，不熬夜。

## 六、高频必背结论速查卡（睡前反复扫）

### 6.1 进制与编码

| 结论 |
| --- |
| 2^0=1, 2^8=256, 2^10=1024≈10³, 2^16=65536, 2^20≈10⁶, 2^30≈10⁹, 2^32≈4.3×10⁹ |
| int 范围 −2^31 ~ 2^31−1（约 −21亿~21亿）；long long 范围 −2^63 ~ 2^63−1（≈±9.2×10^18） |
| 负数补码 = 按位取反 + 1；8 位补码范围 −128~127 |
| 格雷码：相邻两个码之间只相差 1 个二进制位 |

### 6.2 排序算法（复杂度 / 稳定性）

| 算法 | 平均 | 最坏 | 空间 | 稳定性 |
| --- | --- | --- | --- | --- |
| 冒泡 | O(n²) | O(n²) | O(1) | 稳定 |
| 插入 | O(n²) | O(n²) | O(1) | 稳定 |
| 选择 | O(n²) | O(n²) | O(1) | 不稳定 |
| 归并 | O(n log n) | O(n log n) | O(n) | 稳定 |
| 快速 | O(n log n) | O(n²) | O(log n) | 不稳定 |
| 堆 | O(n log n) | O(n log n) | O(1) | 不稳定 |
| 希尔 | ~O(n^1.3) | O(n²) | O(1) | 不稳定 |
| 计数/基数 | O(n+k) | O(n+k) | O(k)/O(n+k) | 稳定 |

### 6.3 树

| 结论 |
| --- |
| 第 i 层最多 2^(i−1) 个结点（根为第 1 层）；深度 k 的满二叉树共 2^k−1 个结点 |
| n 个结点的完全二叉树深度 = ⌊log₂n⌋ + 1 |
| 叶子数 n0 = 度为 2 的结点数 n2 + 1 |
| 完全二叉树从 1 编号：左孩子 2i、右孩子 2i+1、父结点 ⌊i/2⌋ |
| 遍历：前序(根左右)、中序(左根右)、后序(左右根)；「中序 + 前/后序」可唯一还原树 |
| 二叉搜索树(BST)：中序遍历为升序 |
| 哈夫曼树：带权路径长度最小，构建用贪心 + 小根堆 |

### 6.4 图

| 结论 |
| --- |
| 无向完全图边数 n(n−1)/2；有向完全图 n(n−1)；树边数 = 顶点数 − 1 |
| MST：Kruskal O(E log E)（按边排序 + 并查集）、Prim O(V²)（稠密图优） |
| 最短路：Dijkstra（**不可负权**，O((V+E)logV)）、Bellman-Ford（可负权、可判负环，O(VE)）、Floyd（多源，O(V³)） |
| 拓扑排序：仅 DAG 存在，方案数可能 > 1（Kahn 入度法） |
| 邻接矩阵 O(V²) 空间 vs 邻接表 O(V+E) 空间 |

### 6.5 数论与组合

| 结论 |
| --- |
| P(n,k) = n!/(n−k)!；C(n,k) = n!/(k!(n−k)!) |
| C(n,k) = C(n,n−k)；C(n,k) + C(n,k+1) = C(n+1,k+1) |
| 容斥原理：\|A∪B∪C\| = Σ\|A\| − Σ\|A∩B\| + \|A∩B∩C\|（对应"不能被 2/3/5 整除"类题） |
| 错排 D(n) = (n−1)(D(n−1)+D(n−2))，D(1)=0, D(2)=1 |
| 卡特兰数 1,1,2,5,14,42…：合法括号序列、n 元素出栈序列数、n 个不同键的 BST 数 = C(2n,n)/(n+1) |
| 快速幂 O(log n)；GCD 辗转相除 O(log n)；LCM = a·b / gcd(a,b) |
| 1..n 中不能被 a 整除的个数 = n − ⌊n/a⌋（多因子用容斥） |

### 6.6 复杂度（主定理 + 常见速记）

**主定理** T(n) = a·T(n/b) + f(n)：
- f(n) = O(n^{log_b a − ε}) → **O(n^{log_b a})**
- f(n) = Θ(n^{log_b a}) → **O(n^{log_b a} · log n)**
- f(n) = Ω(n^{log_b a + ε}) 且 af(n/b) ≤ cf(n) → **O(f(n))**

**直接套用**：
| 递推式 | 复杂度 |
| --- | --- |
| T(n) = 2T(n/2) + O(n) | O(n log n)（归并） |
| T(n) = T(n/2) + O(1) | O(log n)（二分） |
| T(n) = 2T(n/2) + O(n²) | O(n²)（2025 真题第 11 题） |
| 斐波那契朴素递归 / DP | O(2^n) / O(n) |

**常见算法复杂度**：二分 O(log n)；归并/堆排/快排(平均) O(n log n)；冒泡/插入/选择 O(n²)；全排列枚举 O(n!)；子集枚举 O(2^n)；建堆 O(n)；哈希表平均 O(1)。
