## 三、使用提示

- **真题不含官方原件**：CCF 不公开发布第一轮试题，历年试题均为社会/教培或社区整理版，如与权威渠道有出入以官方为准。
- **限时强度**：模拟请严格按 120 分钟执行，时间分配 25 / 50 / 40 / 5（单选 / 阅读 / 完善 / 检查）。
- **复盘方式**：错题按「考点 | 错因 | 避免方式」三列登记，回填到速查卡，不要只记答案。
